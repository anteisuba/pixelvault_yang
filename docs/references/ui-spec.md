## 1. 页面骨架（桌面）

- 整页铺 `ground`。左边 64 宽的细图标栏落在灰底上，只放图标：AN 字标、黑色「新对话」、对话 / 库 / 画廊 / 搜索、最底下头像。点「对话」从栏旁浮出对话列表（300 宽；一行 = 小封面 + 标题 + 时间，出图中的那一行底下一道细线）。
- 对话和台**合成一整块白板**（`panel`、圆角 20、`ring`），中间一道细线可拖宽窄（对话栏最窄 360；沿用 9f-4 的拖线：吸默认宽、拖过头变淡松手收起、双击回默认宽、键盘挪，owner 2026-10-25 定不换 `react-resizable-panels`）。板里不再套卡。
- 对话顶上：助手头像 + 标题；点标题就地改名，⛔ 分隔线。点头像对话**完全收起、不占边**，头像浮到台的左上角（有新消息带小点），再点展开。
- 台条**一直在**，竖着浮在台右边：图片 · LoRA · 视频 · 3D · 画布；同时只开一个台。⛔ 台顶上的切换条、⛔ 台标题（「图片工作台」）。
- 库只有整页（§9 库）；别处要用库都弹正中的框。
- 代码：外壳 `studio/shell/StudioShell.tsx`（灰底 + 白板 `SHELL_BOARD_CLASS`，板里整屏高靠 `bench-screen-h` 扣掉上下 8）、左栏 `StudioConversationList.tsx`（64 图标栏 + 浮出的对话列表）、台条与收起后的头像 `StudioShellBench.tsx`（点当前那颗台 = 收台）。左栏「搜索」要搜什么还没定，先不放。
- 手机端等电脑端做完再定，不在本文范围。

## 2. 文案

- 中文，短，动词开头。按钮 2–5 个字：「生成」「做视频」「从角色选」「加进提示词」「用这句」。⛔「确定」「提交」这类空词。
- 对人称「你」。助手用第一人称、口语、一两句说完：「四张都是正、侧、背。第 3 张的尾鳍比例最对。」
- 中文和英文、数字之间留一个空格：「第 3 张」「NAI v4.5」。几个参数并排用「 · 」隔开：「3:4 · 1K · 4 张」。
- 图的名字是「图\_N」，图上、对话里、查看器里都一样；提示词里引用写「@图9」「@Denia」。
- 时间写相对的：刚刚、2 分钟、1 小时、昨天、周二。占位只写一句：「和助手说…」「描述你想要的画面…」「搜索」。
- 出错写发生了什么和后果，跟一个动作：「Kling 超时了，额度没扣」+「重试」。
- 产品和模型名照原样：NovelAI、NAI v4.5、Illustrious XL、Kling、Fish Audio。
- 不要：⛔ 副标题和说明句（让布局说话）；⛔「暂无数据」；⛔「按 Enter 发送」之类操作提示；⛔ 示例按钮、「继续创作」「查看操作教程」、对话里的建议按钮；⛔ emoji 和感叹号。

## 3. 颜色

### 3.1 意思

- **黑 = 动作。** `primary` 底 `on-primary` 字只给每块板唯一的主按钮（台里的「生成」、弹窗里的确认）、发送、「新对话」、底部黑条。
- **强调色 `highlight` 只有两个意思：选中了、正在进行。** 素档蓝 `#3346e8`，暗房米白 `#ecebe7`（和线上暗房主色一样，⛔ 橙）。
  - 选中了：挑选时格子右上角的勾（`on-highlight` 勾）、@ 引用（`highlight-soft` 底 `highlight` 字）、焦点环、被提到时的外圈。
  - 正在进行：图格底边的进度条、对话行底下那道细线、「2/4」角标、有新结果的小点。生成中那圈「边即进度」照线上用前景色 `ink`（`loading.md`）。
  - 设好了不算：设好的参数药丸仍是浅灰（㉕）。⛔ 拿它做装饰、大块底色、给普通按钮上色。
- **状态色** `success` / `warning` / `danger` 只配图标和一句话，要底色用对应的 `-soft`；红色实心只给弹窗里的删除键。⛔ 整块变红。
- 所有正文对底色 ≥ 4.5:1，两档都算过（数写在规范页每个颜色的说明里）。`ink-3` 只放在 `panel` / `fill` / `fill-strong` 上，⛔ 放在 `raise` 上（暗房 4.44）。

### 3.2 层次

- 板：`ground`（壳）→ `panel`（白板）→ `fill`（板里的分组块：列表行、搜索框、附件、药丸）→ `fill-strong`（切换条轨道、图没出来的占位、点开的药丸）。当前那一行 `row-selected`；你的消息气泡 `bubble`。
- 浮起来的两档：`raise`（白药丸、图标键、切换条的白格、查看器上的键，配 `soft` / `seg`）；`float`（菜单、模型选择器、药丸的弹层、从库里挑的框、查看器、删除弹窗、画布工具条，配 `pop`）。素档两档都是白；暗房各亮一档——暗底上影子看不见，靠亮度分层。
- **暗房里叠一层亮一档**：`ground` → `panel` → `fill` / `float` → `fill-strong` → `raise`。`float` 和 `fill` 同色（线上 `--popover` 和 `--muted` 也同是 `#191a1d`），所以浮层里的浅底块（搜索框、药丸、当前那一行、小签）从 `fill-strong` 起，再叠一层的（选中行里的字母小方块、灰底上的头像）用 `raise`；素档不变。代码里这一档是自动的：`globals.css`「叠一层亮一档」那段在暗房里把浮层（popover / dropdown / select / dialog / alert-dialog，以及自写浮层挂的 `data-float`）里的 `--muted` / `--accent` 改成 `fill-strong`，浮层里照常写 `bg-muted`。

## 5. 尺寸、圆角、阴影

- 间距 4 一档，中间可以有 2 的半档（`space-0.5` … `space-8`，名字和 Tailwind 数字一致）。
- 控件高度：默认 32（药丸、主按钮、图标键、菜单项、行里的动作、头像）；36（切换条、搜索框、开关所在的那一行、空状态里的动作）；40（首页发送、语音条、底部黑条）；图上按钮 28；对话过程药丸 24；图上编号 20；角标 16。面板头 52，行里的封面 44。
- 能点的东西命中区 ≥ 32（手机 44，手机端另定）。
- 圆角：外圈 = 内圈 + 内距。**全圆**：按钮、药丸、圆钮、头像、开关、搜索框、切换条（轨道和白格）、角标、语音条。其余：图上编号和 @ 引用 6；参考图缩略图、菜单项、挑选框左栏的行 8；对话列表的行、模型选择器的行 10；图格、菜单、弹层、标签列表的行、画布节点卡 12；视频 / 3D 预览区 14；台输入框 16；对话输入框、气泡、弹窗 18；白板、柔影白卡（助手卡、空状态）、底部黑条 20；首页输入框 22；挑选框、查看器 24。
- 阴影只有这九种，浮得越高越重（暗房里影子几乎看不见，`pop` / `card` 靠一圈 `line-strong` 认边）。⛔ 自己配阴影。

## 6. 动效

- 时长、曲线、弹簧三档、液态展开、换内容一糊全照 ui-defaults §4。⛔ 照搬样件里的 400ms+ 和别的曲线。
- 具体怎么动：切换条照 `liquid-segmented.tsx` 两边弹簧；从药丸弹出的菜单从药丸放大出来、关上缩回；弹窗从按下的那颗键长到正中（`growFromPointer`）；图格悬停时动作药丸淡入上移 4px；新内容在自己那一格里由糊变清；模型选择器选中多渠道型号时那一行撑开、渠道切换条依次淡入、换渠道白格滑过去。
- 同一时刻只有一样在动。⛔ 发光、渐变、晃动。每条都要有减少动效的退路：直接到位。

## 7. 图标

- 只用 Phosphor，只从 `@/components/icons` 拿；同一个意思全站一个字形。
- 粗细 **regular**（现在默认 bold，改 `IconDefaults.tsx`）。尺寸：台条 18，图标键 17，圆钮和菜单项 16，药丸和搜索框 15，黑条和键上的勾 14，行里的小台标 13，空状态 28；颜色跟字走，默认 `ink-2`。
- 台的字形固定：图片 `Image` · LoRA `Swatches` · 视频 `VideoCamera` · 3D `Cube` · 画布 `Graph` · 配音间 `Waveform`；「收起台」用 `ArrowLineRight`（桶里还没有，做时加一条 re-export）。

## 8. 交互

- **悬停**：任何底色上叠同一层 `hover-overlay`，⛔ 另配 hover 色；只在有鼠标时出现。**按下**缩到 0.98。**焦点**：`focus` 环，⛔ 去掉焦点环。
- **禁用**：变淡、不藏；不支持的能力干脆不渲染。
- **缺 API key**：⛔ 禁用。点没配 key 的模型先不选中，就地弹 `QuickSetupDialog`，验证通过才选上；点「生成」缺 key 同样就地弹（CLAUDE.md Hard Rule 8）。
- **结果**：点了当场有结果的（下载、保存、复制、上传）写在键上；后台跑完的浮底部黑条；删东西弹居中小弹窗。
- **一个主按钮**：一块板上只有一个黑色主按钮。

## 9. 组件

一个组件一段：长什么样、用在哪、不许怎么做、代码里换哪个文件。规范页每张卡同名。

### 按钮

### 输入

- **搜索框 `SearchField`**：浅灰药丸，没边。
- **切换条 `Segmented`**（⑦）：浅灰轨道（`fill-strong`），选中的是浮起来的白格（`raise` + `seg`）；滑动手感照 `liquid-segmented`。比例、清晰度、张数、库里最常用的那一项筛选都用它。
- **开关 `Switch`**：32×20，关着 `fill-strong` 轨道，开着黑色 `primary`，圆钮 16 `knob` + `seg`；多数放在一行里（图标 + 名字 + 开关，36 高，整行能点）。⛔ 旁边写「开启后……」；⛔ 用勾选框代替。代码里 `switch.tsx` 换皮。
- **滑杆 `Slider`**：黑色胖条，没有钮，黑色那段就是值，按住哪里拖哪里，值写在右边（等宽）；拖过头的橡皮筋照 `RUBBER_BAND`。用在 LoRA 权重、步数 / CFG、引导强度这类参数行。
- **比例 `RatioPicker`**（㉚）：规格药丸点开后一排切换条，每格一个小框 + 比例字；清晰度、张数同一种，一个弹层里只有这一种控件。
- **标签框 `TagTextField`**（㉘）：标签是一段逗号隔开的字，⛔ 一个个框；删就像删字（拖选 ⌫、⌘A、双击选整个标签、⌥⌫ 删前一个标签）。权重写在字里、浅灰（`blue hair:1.2`），光标停在标签上 ⌘↑ / ⌘↓ ±0.05，发出去时自动换成各家写法（NAI `{}` / PixAI `()`），⛔ 界面上出现原生写法。光标所在的标签底下淡淡一块 `fill-strong`。补全、⌘ + 点看详情照旧。只看的地方也写成字。代码里 `StudioTagChipField` 换成它，存储（`parseTagChips` / `serializeTagChips`）不动；LoRA 触发词不在此列。
- **上传 / 拖放 `DropZone`**（㉞）：拖着停在一块上，那一块描一圈黑虚线、铺浅灰，中间写松手去哪（「松手加到参考图」）；输入框、素材库、LoRA 训练集等十几处同一个；传的时候那一格走「边即进度」。代码：盖在宿主上的那一层是 `ui/drop-overlay.tsx`（`DropOverlay`，文案在 `DropZone` 命名空间）；本身就是虚线框的落点（LoRA 训练集、挑图框上传键、视频台素材提示）停上去换成 `border-foreground bg-muted`。
