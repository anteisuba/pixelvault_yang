## 1 · 域定义

侧栏属于 **品牌脊柱**（`brand-dna.md`「应用壳、全局导航位置与导航行为」），**不是业务域皮肤**。因此：

- 它的长相由本文一处定义，**不吸收任何单个业务域的性格**（不像画布，也不像 LoRA）。
- 它的设计目标是 **安静、恒定、永不抢戏** —— 主区永远是作品/画布。

| 负责                                         | 不负责                             |
| -------------------------------------------- | ---------------------------------- |
| 告诉你在哪 · 让你去别处 · 通往个人主页与设置 | 任何业务操作、生成、参数、账户数字 |

**最高频任务**：在 7 个工具之间来回切。整个设计围绕这一条优化。

## 2 · 方向：分段浮岛（owner 2026-08-18 拍板）

**B 的结构 + C 的材质**：

- **结构（B）**：推挤式分段面板；三段「去处 / 工具 / 账户」，段间用留白分不用线；整栏只有**一个**运动主体 —— 会滑的活动指示器。
- **材质（C）**：壳底浅灰，侧栏与主卡各成一片浮在上面；边界靠**几何**（缝 + 圆角 + 投影），不靠发丝线。

落选：A 静轨（主区零回流，但常驻标签消失）· 纯 B（两个白面层次弱）· 纯 C（长列表仍是一坨）。

> 指针：本节是**应用壳**的「侧栏灰底 + 主卡」，与**工作台脊柱**（配音间 / 图像 / 视频 / LoRA 四个工作台共用的 `.workbench-ground` 灰底地台 + `.workbench-card` 白卡，owner 2026-09-03）是两层不同的东西——壳套着工作台，工作台自己再套一层灰底+白卡。工作台脊柱见 `../ui-defaults.md` §2.2 与 `src/app/globals.css`。

## 3 · 尺寸

|                | 桌面 ≥1024                      | 平板 768–1023      | 手机 <768          |
| -------------- | ------------------------------- | ------------------ | ------------------ |
| 轨宽 · 展开    | **144**（容器 160 含 8px 外沟） | — 无竖轨           | — 无竖轨           |
| 轨宽 · 收起    | **40**（容器 56）               | —                  | —                  |
| 行高           | 36                              | 顶栏 44            | 顶栏 44            |
| 图标           | 16                              | 20（面板格）       | 20（面板格）       |
| 收起态点击目标 | 32 × 32（fine pointer 下限）    | 面板格 72 高       | 面板格 72 高       |
| 对比现状       | 192 / 48 → **144 / 40**         | 44 死轨 → **撤销** | 44 死轨 → **撤销** |

桌面导航默认收起为窄图标栏，用户主动打开后显示完整导航；应用内切页保留开关选择，刷新后重新收起，不从 cookie 恢复展开状态。

⚠ **收起态标签原地糊掉**（2026-10-08 侧栏原型 v1 起，覆盖原先的 `display:none`）：
淡出 + `blur-xs`，收起后 `shrink-0` + `text-clip` + `pointer-events-none`，让按钮把它**裁掉**
而不是压扁 —— 只靠 `truncate` 裁会被 `text-overflow` 截成「G.」「P.」这种单字（2026-08-18
真机上出过），所以收起档必须换成 `text-clip`。⛔ 别退回 `[&>span]:hidden`：糊掉那一拍就没了。

**收展时图标不动**（owner 2026-10-08）：行高（36）、内沟（4px，`--sidebar-rail-gutter`）、
按钮内距（`p-2`）两档同值，按钮宽度跟着轨一起收（40 − 4 − 4 = 32，16px 图标正好居中）。
⛔ 收起档不换 `size-8!` / `p-0!` / `justify-center`。段标题收起时也只糊掉、⛔ 不收走高度
（`-mt-8` 那套会让下面的图标全往上跳），那一行留成段间空白。

**⚠ 触屏的 44px 触摸目标下限仍然成立** —— 只是 <1024 不再有竖轨去承载它，改由顶栏按钮
（44 高）与面板格（72 高）满足。

**⚠ 撑宽侧栏的是一个英文字符串，不是布局。** 三语标签实测（14px Geist）：

| locale | 最长标签                | 宽度                      |
| ------ | ----------------------- | ------------------------- |
| zh     | 卡片管理                | 56px                      |
| ja     | ギャラリー / プロンプト | 70px                      |
| en     | **Card Management**     | **119px（600 字重 124）** |

所以收宽度的第一步是**改标签**，不是压别的元素：

| key                     | 现状              | 改为        | 理由                                         |
| ----------------------- | ----------------- | ----------- | -------------------------------------------- |
| `en.Navbar.links.cards` | `Card Management` | **`Cards`** | 路由本来就叫 `/cards`；zh 也只是「卡片管理」 |

⚠ `en.StudioTools.comingSoon`（`Coming Soon` → `Soon`）曾是这张表的第二行；2026-09-17 owner 拍板删掉「敬请期待」分组后，该键已随组一起删除。

两处一改，132 / 144 / 156 三档在三语下**零截断**（原型逐档实测）。**取 144**：比日文地板（约 122px）留 ~20px 余量，不至于以后加一个稍长的标签就崩。
⚠ 改 `src/messages/*.json` **禁用正则**，必须逐键对比（跨 256KB 的 `.*?` 会静默删掉别处的键，全量闸门照过）。

## 4 · 令牌（全部 node 确定性计算，禁目测、禁信 review agent 算术）

| 用途              | 值                    | 底        | 对比度    | 判定               |
| ----------------- | --------------------- | --------- | --------- | ------------------ |
| 壳底 ground       | `#e4e7ec`             | —         | —         | 面                 |
| 浮卡 / 浮片       | `#ffffff`             | `#e4e7ec` | **1.24**  | ⚠ **不承重**       |
| 未选中标签 14px   | `#454c55`             | `#e4e7ec` | 7.01      | ✅                 |
| 激活标签 14px/600 | `#0b0e12`             | `#ffffff` | 19.34     | ✅                 |
| 段标题 11px 大写  | `#555d67`             | `#e4e7ec` | 5.38      | ✅                 |
| 激活竖条 3×18     | `#0b0e12`             | `#e4e7ec` | **15.60** | ✅                 |
| Focus 环 2px      | `#0b0e12`             | `#e4e7ec` | 15.60     | ✅                 |
| Hover 底          | `rgba(11,14,18,.055)` | `#e4e7ec` | —         | 与 active **反向** |

### 4.1 · 两条不许推翻的算术结论

1. **hover 和 active 必须反极性。** 初稿让 hover 用「更白的底」、active 用纯白浮片 —— 算出来 **1.1:1**，就是把「hover 任一项都长得像当前项」这个现存 bug 换身浅色衣服重犯。定案：**hover 往暗走（墨 5.5%）、active 往亮走（白浮片）**。
2. **浅壳里「面对面」到不了 3:1。** 白卡 vs 灰底 = 1.24（试到 `#dce1e8` 也只有 1.31）。因此 **任何状态语义都不许压在面色差上**：
   - 壳与内容的分离 → **几何**（10px 缝 + 14px 圆角 + 投影）。几何没有对比度阈值。
   - 状态语义 → 墨竖条（15.60:1）+ 墨色跃迁（7.01 → 19.34）+ 字重（400 → 600）。

**激活态三个信号叠加**：白浮片（材质）+ 墨竖条（承重）+ 字重墨色（承重）。撤掉任意一个承重信号都算破坏本文。

## 5 · 动效

2026-10-08 owner 定稿侧栏原型 v1（`1SN6YY7TTUvm2c85JWgNAd`）后的动效表 —— 展开收起的**行为**不变（点钮 144 ↔ 40、推挤主卡、刷新重新收起），只换动法：

| 动作                       | 时长 / 弹簧                                          | 动的属性                     |
| -------------------------- | ---------------------------------------------------- | ---------------------------- |
| 白浮片 + 竖条滑到新行      | `--spring-slot`（≈ `SPRING.slot`）                   | **transform** · 宽高         |
| 悬停浅灰块跟着光标         | 同上                                                 | **transform** · 宽高         |
| 墨色 / 底色变化            | `--duration-fast`                                    | color · background           |
| 收展 · 桌面（推挤）        | `--spring-expand`（≈ `SPRING.expand`）               | ⚠ width                      |
| 标签 / 段标题 / 账号名糊掉 | `--duration-base`                                    | opacity · filter             |
| 收起后悬停一项             | Radix Tooltip（黑底名字，右侧）                      | —                            |
| 画布子项长出 / 收回        | `SPRING.expand`（motion）                            | height · opacity · filter    |
| 账号菜单从触发行长出       | `--spring-slot`，收回 `--duration-fast`              | clip-path · opacity · filter |
| <1024 面板落下 / 收起      | Radix Sheet 默认                                     | transform · opacity          |
| `prefers-reduced-motion`   | 弹簧退回 `--duration-base` 线性档，全局再压到 0.01ms | 全部瞬时                     |

几件事同时起步：轨宽弹簧、字糊掉、浮片贴着走，⛔ 不排队、⛔ 不错开。透明度与模糊⛔ 不走弹簧（过冲会把它们推出终点）。⛔ 发光、⛔ 渐变。

**曲线与时长一律取 `src/constants/motion.ts` / `globals.css @theme` 的 token，壳内不得出现裸 ms。**

⚠ **桌面收展仍动 `width`** —— 这是选 B 结构就付的代价（只有落选的 A 能物理消掉）。缓解：只在收展这一个动作发生，**切工具时不触发**；`will-change` 只在过渡期间挂。

⚠ **收展途中白浮片逐帧贴着按钮走**：`useNavIndicator` 的 ResizeObserver 一量就把浮片标成 `activeTracking`，CSS `.shell-nav-slider--tracking` 关掉弹簧；换了当前项（路由变）才走弹簧滑。⛔ 两层弹簧叠着跑 —— 浮片会落后按钮半拍、露出一截。

### 5.1 · 交互态（五个，都不靠颜色单打独斗）

| 态            | 表达                                                                                                            |
| ------------- | --------------------------------------------------------------------------------------------------------------- |
| 静息          | 墨 `#454c55`                                                                                                    |
| Hover         | 底色**变暗** 5.5% + 墨色加深 + 图标 `scale(1.05)`；底色由一块**跟着光标在行间滑的浅灰块**承担，不是每行各自开关 |
| Focus-visible | 2px 墨环 inset                                                                                                  |
| 激活          | 白浮片 + 墨竖条 + 600 字重                                                                                      |
| 切换中        | 白浮片 transform 滑向新目标                                                                                     |

**幽灵块细则**：首次进入列表 → 就位后淡入，**不从别处滑过来**；划过当前激活项 → 让位（白浮片赢，不在它下面压暗块）；`pointerType !== 'mouse'` → 不触发（触屏没有 hover，否则会糊一块在那）。

⚠ **收起 40 档：看不见的东西一律不许接住鼠标。** 2026-09-20 owner 真机撞到过——分组标题收起态只 `opacity-0` + `-mt-8`（shadcn 默认写法），仍然 `pointer-events: auto`，那块 28px 高的透明标题**压在上一组最后一项身上**（实测重叠 24px，`elementFromPoint` 命中的是标题不是链接），于是那一项悬停有反馈却点不动。`SidebarGroupLabel` 收起态带 `pointer-events-none`（2026-10-08 起 `-mt-8` 已去掉，标题原地糊掉）；糊掉的标签、账号名、品牌名同样带。⛔ 不改成 `hidden`——会把糊掉那一拍掐掉。⚠ 消费方也不许用 `pointer-events-auto` 把它翻回来（tailwind-merge 会让后者赢），`AppSidebar.test.tsx` 有一条扫描用例守着整棵轨。

## 6 · 断点行为（一套组件三档）

**只有两档**（owner 2026-08-18 为 <1024 选了方向 M2，不再需要平板第三形态）：

| 断点           | 形态                                                                                            | 依据                                     |
| -------------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------- |
| **≥1024 桌面** | 竖轨 144 ↔ 40，在流中，展开**推挤**主卡                                                         | 宽度充裕，常驻标签的认路价值大于回流成本 |
| **<1024**      | **没有竖轨**。顶栏 44px，中间一颗「当前位置」按钮，点开从顶部落下一张面板（工具 / 去处 / 账户） | 见下方五条                               |

**<1024 为什么不照搬桌面竖轨**（这五条都不是审美问题）：

1. **没有 hover** —— 桌面版一半的交互设计是那块跟随光标的幽灵块，触屏上它不存在。
2. **左上是右手拇指最差可达区** —— 最高频的「切工具」被放在最难够的角落。
3. **宽度比高度贵** —— 44px 竖轨吃掉 375 的 12%，永久占用。
4. **触摸目标要 44px** —— 桌面收到 40/32，手机反而要回到 52/44。**越小的屏轨越宽**，形态本身就不对。
5. **导航层级不同** —— 手机上几乎只有切工具是高频，桌面那种两段平铺是把低频与高频按同权重摆着。

⚠ **断点必须留在 1024。** 别为了让平板拿到桌面竖轨而下调到 768 —— `use-mobile.ts` 记着：
768–1023 挂桌面侧栏会把 studio 内容裁出视口。M2 天然覆盖整个 <1024。

⚠ **<1024 的激活态用墨色填充块，不是桌面的白浮片。** 没有 hover 就不需要反极性那套，
而深色块在 375 上更容易一眼认出。

**<1024 的账户与设置**（2026-09-20 D11 ④ 改写）：导航形态仍是**现有的顶部落下面板**，不新开第二种载体；但账户不再住在面板里 —— 顶栏胶囊右端那颗头像挂的是与桌面**同一颗** `AccountMenu`（语言 / 设置 / 退出登录都在里面）。⛔ 面板里不再有「我」区、也不再有最底那一行「设置」；「我的主页」在「去处」段里，与桌面同一条清单。详见 §8。

落选：M1 底部工具坞（切工具一次点击、落在拇指区，但 owner 2026-08-07 刚删过底部 TabBar）·
M3 边缘手势（与画布 pan、画廊/素材横滑直接冲突）。

**⛔ 不得再出现第二套导航组件。** 桌面与移动的条目清单必须来自**同一个数据源**（`src/constants/navigation.ts`）。历史教训：`AppSidebar` 曾有一个桌面独有的分组，`MobileCollapsedRail` 没有 —— 那几个入口在小屏**不可达**，就是两份手工清单漂移的直接后果。

**导航不再有折叠分组。** 2026-09-17 owner 拍板删除「敬请期待」组：`/studio/enhance` 与 `/studio/analyze` 只是 `ToolPlaceholder` 占位页（能力实际在画布视频节点里），整条路由与入口一并删除；故事板是真实页面，已并入「去处」组。

**唯一的子项：画布面板入口**（owner 2026-10-08 画布换皮 + 侧栏第 3 题选 A）。停在画布路由、画布挂着时，「画布」下面长出六个子项（添加节点 / 节点 / 当前项目 / 历史对话 / 角色 / 素材库，`SHELL_NAV_CANVAS_ENTRIES`；哪几个在侧栏只看这一张列表），点一个开画布左侧面板、再点收起；它们是**按钮不是链接**。

- **展开 144**：缩进的几行、每行带名字，**一整块浅灰**（`bg-sidebar-accent`）包住；开着的那一个**白底**（`sidebar-active-surface` + `shadow-sidebar-chip` + 墨字）+ `aria-pressed`。⛔ 借路由的激活白浮片与竖条（那一块只属于当前路由）。
- **收起 40**：同一块浅灰包住一列图标，名字随轨糊掉，悬停出黑色名字提示。
- **进出**：进画布时从「画布」那一行底下长出来（高度 0 → auto，`SPRING.expand`，内容由糊变清），离开画布反着收回。⛔ 逐个错开。
  这不是折叠分组：不能手动展开收起，离开画布即消失。细节见 `node-canvas-v2.md` §16。

- **菜单内容**自上而下：头部（头像 · 名字 · @用户名）→ 分隔线 → 语言（**一行分段条** EN / JA / ZH，复用 `LiquidSegmented`；owner 2026-10-08 侧栏原型 v1，⛔ 不再展子菜单）→ 设置 → 分隔线 → 退出登录（红字）。⛔ 不放额度、不放 key 数、⛔ 不挂红点 / 角标 —— 那三样各有各的页（沿用 D3 ④ 收口）。⛔ 不做退出二次确认。
- **⛔ 没有「外观」那一行**：这个应用**没有主题切换机制**（无 next-themes / setTheme / 任何挂 `.dark` 的开关），画板上那一行 owner 2026-09-20 明确本轮不做。⛔ 不许画一颗点了没反应的。
- **语言**与设置 → 偏好走**同一条路**（`src/hooks/use-locale-switch.ts`）：当前值、落点（当前地址 + 原样带回 query）、三档名册都只有一份；切换 = next-intl `router.replace(href, { locale })`。⛔ 菜单里不另存一份当前值，否则「界面显示的」和「服务端认得的」会开始漂。当前项靠**墨色选中块 + 反色字 + `aria-checked`** 说话，⛔ 不只靠颜色。
  - ⚠ 键盘：Radix 菜单吃掉 Tab、方向键只在菜单项之间走，分段条里的格子键盘到不了 —— 所以整行是一颗 `menuitem`，焦点落在这一行上按 ←/→ 换语言；`onSelect` 拦掉「选完就关」。
- **收起 40**：底部只剩头像，是一颗**真 `button`**，tooltip「账号」，菜单锚到右侧。⚠ 那一档它是**唯一**的账号入口，键盘必须到得了。

- **引导锚点 `data-onboarding="apiKey"` 挂在账号触发器上**，⛔ 不在菜单内容里 —— 菜单只在打开后才挂载，挂进去就是死锚点（`OnboardingTooltip` 找不到目标只能把气泡居中）。
- **动效**（2026-10-08 侧栏原型 v1，覆盖 D11 ④ 的 `lift`）：菜单从触发行**长出来** —— 靠触发器那条边不动，另一条边走 `--spring-slot` 推出去（clip-path，四边多放 1.5rem 给投影）+ 由糊变清；侧栏展开往上、收起 40 往右、手机顶栏往下（按 Radix `data-side`）。收回反着走、`--duration-fast`。⛔ 不缩放（菜单是底行的延伸，缩放会读成独立弹窗）。底行 hover / pressed 只过渡背景色，⛔ 不动字重、⛔ 行不抖。全部带 `motion-reduce:` 降级。浮层动效住在 `ui/dropdown-menu.tsx` 的 `motionPreset`（`zoom` 默认 / `grow` 账号菜单，keyframes 在 `globals.css` 的 `menu-grow` / `menu-shrink`），⛔ 不在调用方用 className 覆盖。
- ⚠ **底色仍走侧栏的反极性**：hover 往暗（`--sidebar-accent`）、pressed / 菜单打开更暗（`--sidebar-accent-strong`）、激活浮片往亮（`--sidebar-active-surface`）。⛔ 账号入口不许自己破例。
- **<1024 同形**：顶栏胶囊右端那颗头像挂**同一颗** `AccountMenu`。⛔ 抽屉里因此不再有「我」区、也不再有最底那一行「设置」—— 两个入口并存就是下一次漂移的起点。

**「我的主页」的地址是静态的 `/u/me`**（owner 2026-09-20 拍板）。那条路由在服务端解析当前用户后**就地渲染**个人主页（`app/[locale]/(main)/u/me/page.tsx`），⛔ **不 redirect 到 `/u/<username>`**。

- ⛔ **不要让壳在渲染时按 `useMyProfile()` 拼地址。** 上一版这么做过（条目带一个 `dynamicHref` 标记 + 解析层，解析不出就不产出这一项），真机在日语档看得见**侧边栏当着用户的面回流一次**——列表过几秒多出一行。运行时依赖已整层删除，⛔ 别再引回来。
- ⭐ **就地渲染而不是跳转，是为了激活态**：地址栏停在 `/u/me`，静态清单认得出这一项就是当前位置；跳到 `/u/<username>` 的话落地 URL 带着用户名，只能把刚删掉的运行时解析接回来。判据上它也与仓库既有的 `me` 约定同构——`/api/users/me/profile` 同样是就地返回当前用户，不跳到 `/api/users/<username>/profile`。
- ⚠ 同一个页面两个地址，所以 `/u/me` 的 `alternates.canonical` 指向 `/u/<username>`。⛔ 不要再叠 `noindex`：canonical 已经回答了重复内容，两个信号同时挂是互相矛盾的。
- ⚠ 段名 `me` 沿用仓库既有约定（`/api/users/me/*`），⛔ 不造 `/u/self` / `/profile` 第二套说法；静态段优先于同级 `[username]`，所以 `me` 已进 `PROFILE.RESERVED_USERNAMES`（2026-09-20 查库确认线上零占用）。
- ⚠ `/u/(.*)` 在 `proxy.ts` 里是公开路由（别人的主页要能匿名看），未登录这一档中间件不管，由该页自己 `redirect` 到登录页——与 `/settings` 同一个口径。
