## 怎么读这张表

- **通道** = 项目当前实际调用的那条线（`adapterType`）。
- **倍率** = fal 单价 ÷ 原生单价。`1.00×` 表示 fal 不加价；`< 1` 表示 fal 比原生**更便宜**。
- 标「原生」的行本来就没走 fal，不存在倍率。
- ⚠ 价格随时会变。本表是**某一天的快照**，接入前请复核，别把它当合同。

**一句话结论：fal 不是普遍更贵，而是按厂商分化。** 字节系（Seedance / Seedream）是纯转售，加价 1.6~2.2 倍；FLUX / Recraft / Kling 是 fal 的一级发行合作，基本持平；HappyHorse 1080p 和混元 3D 的白模档 fal 反而更便宜。

### 火山 Seedance 计费公式

```
token 用量 = (输入视频时长 + 输出视频时长) × 输出宽 × 输出高 × 帧率 ÷ 1024
费用 = token 用量 × token 单价
```

| 模型                       | 480p/720p 单价（元/百万 token）           | 1080p         | 4k            |
| -------------------------- | ----------------------------------------- | ------------- | ------------- |
| `doubao-seedance-2.5`      | 不含输入视频 **70.00** · 含视频 **42.00** | 未开放        | 未开放        |
| `doubao-seedance-2.0`      | 46.00 / 28.00                             | 51.00 / 31.00 | 26.00 / 16.00 |
| `doubao-seedance-2.0-fast` | 37.00 / 22.00                             | 不支持        | 不支持        |
| `doubao-seedance-2.0-mini` | 23.00 / 14.00                             | 不支持        | 不支持        |

公式我反推验证过官方示例（720p 5s：`5×1280×720×24÷1024 = 108000 token × 70 元/M = 7.56 元` ✓），所以下面的推算可信：

| Seedance 2.5 推算 | 价格                  |
| ----------------- | --------------------- |
| 480p · 30s        | 20.16 元（$2.84）     |
| 720p · 30s        | **45.36 元（$6.39）** |

⚠ 输入含视频时有**最低 token 用量兜底**，短输入不会更便宜。⚠ 4k 档单价看着最低（26 元/M）是因为 token 用量按像素面积算，总价反而最高。

### ⚠ 撤回：那条「默认走 fal 多付 2.1 倍」的成本敞口不成立

初稿据 `src/lib/video-model-resolver.ts:167` 的 `pickDefaultProvider`（持 key 的 provider 优先 → 否则取该品牌第一项 → 兜底 FAL）判断「无火山 key 时默认走 fal，每条多付 2.1 倍」。**读透派发链路后这条是错的，已撤回。**

真实情况是：`generate-video.service.ts` 的 `canSubmitVideoViaExecutionWorker` 原本写死 `adapterType === FAL`，其余全部落到 `501 not migrated`。**火山 Seedance 四变体和 Gemini Omni Flash 根本执行不了** —— 能选、能配 key、一提交 501；火山 adapter 自己的注释也写着「service 走 worker-only，dead，此处为铺未来线」。所以 fal 不是「贵的默认」，是当时唯一能跑的。

**换言之：表里那些 1.6~2.2 倍的省钱，在派发面打通之前一分也拿不到。**

**2026-08-01 已打通。** execution worker 新增 provider 派发缝（`submitProviderQueue` / `pollProviderQueue`），两批迁移落地：

| 线路                      | 状态        | 兑现的省钱                              |
| ------------------------- | ----------- | --------------------------------------- |
| MiniMax H3（国际 + 国内） | ✅ 已迁     | 2.00× → 每 2K 秒 $0.26 降到 $0.13       |
| **火山 Seedance 四变体**  | ✅ **已迁** | **720p 省 54% · 1080p 省 49%**          |
| Gemini Omni Flash         | ⬜ 未迁     | 走 Interactions API，形状与前两者都不同 |

火山那条是全站最大的一笔，且它四个变体正是画布视频汇点的主力。**Seedream（图像）走的是另一条链路**——worker 的图片分支链里 `generateVolcEngineImage` 早就在，所以图像侧的 1.6× 一直是能拿到的。
