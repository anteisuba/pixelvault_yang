分段浮岛

按你的选择做的：B 的结构（推挤式分段面板 + 单一滑动指示器 + 单行账户） 叠 C 的材质（灰底 + 圆角浮卡 + 白色浮片）。四个断点和五个交互态都在下面，可以直接点。

主张 01

整栏只有一个东西在动

切工具时，只有那块白浮片在滑。其余全是 120ms 的墨色渐变，不再有「灰底啪地开关」。

主张 02

激活态不靠面色差承重

白浮片对灰底只有 1.24:1，撑不住。真信号是那条 15.6:1 的墨竖条 + 字重墨色的 2.7 倍跃迁。

主张 03

三个断点，一套组件

桌面推挤、平板覆盖、手机工具优先 —— 同一份 DOM，只换 data-bp。两套导航手工同步的账就此还清。

主张 04

144 / 44，比现在还窄

展开 192→144（−25%），收起 48→44。撑宽轨的其实是一个英文标签，不是布局 —— 改标签比加宽轨便宜。

你在评论里点名要换图标 —— 这正好和我在方向 A 的代价里写过的那条是同一件事： 3D / 画布 / LoRA 在 16px 下不好分。核实过了，下面每一个候选都在项目已装的 lucide-react 里，不加新依赖。
