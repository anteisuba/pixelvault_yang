# 三语术语表

产品里的固定词，三语只用这一种叫法。新文案先查这里；新出现的固定词先补进来，再写文案。规矩见 [frontend.md「i18n」](frontend.md#i18n)。

| 中文          | English                      | 日本語        | 说明                                                                                |
| ------------- | ---------------------------- | ------------- | ----------------------------------------------------------------------------------- |
| 角色          | Character（复数 Characters） | キャラクター  | ⛔ 日文缩写「キャラ」                                                               |
| 造型          | Look（复数 Looks）           | 衣装          | 角色的一套外观；旧叫法「变体」不再用                                                |
| 画廊          | Gallery                      | ギャラリー    |                                                                                     |
| 素材          | Assets                       | アセット      | 素材页 / 素材库；⚠ 现有文案里还有 Media / Materials / 素材 的混用，按模块改到时统一 |
| 提示词        | Prompt（复数 Prompts）       | プロンプト    |                                                                                     |
| 模板          | Template（复数 Templates）   | テンプレート  | 「我的模板」                                                                        |
| 工作台        | Studio                       | スタジオ      | 生成台所在的页面                                                                    |
| 画布          | Canvas                       | キャンバス    |                                                                                     |
| 助手          | Assistant                    | アシスタント  |                                                                                     |
| 标签          | Tag（复数 Tags）             | タグ          |                                                                                     |
| 生成          | Generate                     | 生成          | 生成键                                                                              |
| 收藏          | Favorite（复数 Favorites）   | お気に入り    |                                                                                     |
| 公开 / 不公开 | Public / Private             | 公開 / 非公開 |                                                                                     |
| 底模          | Base model                   | ベースモデル  |                                                                                     |
| 参考图        | Reference image              | 参照画像      | ⚠ 现有文案里还有「参考画像」，按模块改到时统一                                      |

不翻译：ANTEI、LoRA、Civitai、Danbooru、NovelAI 等专有名词与模型名。
