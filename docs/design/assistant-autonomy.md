## 一句话结论

改的东西已经基本做到「直接做 + 能撤销」，真正拖慢的是**出图那道闸**：默认每次都停在确认卡上，开了「交给 AI 出图」又只按张数拦（4 张），不按钱拦——视频一条可能就比 4 张图贵，画布开着自动更是完全没上限。建议把这道闸换成**按钱算的一道门槛**，门槛内默认直接出；再把提示词里零散的「先问」收成三条，统一说法。

看下来的问题：

1. **钱闸按张数不按钱**。4 张 NAI（订阅，不另花钱）和 4 张 GPT Image、1 条 Kling 视频被当成一回事。项目里其实已经有单价表（`constants/models/unit-prices.ts`）和画布估价（`lib/canvas-generation-cost.ts`），只是闸没用它。
2. **画布开自动 = 无上限**。一句「全出」可以出几十张卡。这是现在唯一一处「明显多花钱却不问」的口子。
3. **默认停在确认卡**，违背「拿得准就做完」。你每次都得按一下，等于每步点头。
4. **两边规矩不一致**：画布整段覆盖手写文字要确认，工作台整段覆盖提示词却直接改。两边都能撤销，应该一个说法。
5. **「先问」散在四五处提示词里**，没有一个总原则，模型容易该问的不问、不该问的问。

## 改法

### 1. 总原则：能撤销 = 没改坏

「改坏已有东西」用一个可判定的标准：**这一下能不能一键撤回原样**。能 → 直接做，过程行带撤销；不能 → 先问。

| 动作                                             | 改后                                   |
| ------------------------------------------------ | -------------------------------------- |
| 台上、库里、设置、记忆的改动                     | 照旧直接做（都已能撤销）               |
| 画布整段覆盖你手写的文字                         | **改成直接做**（有撤销），和工作台一致 |
| 画布删卡：卡是这次对话里助手自己加的、还没出过图 | **改成直接做**                         |
| 画布删卡：你做的卡，或已经出过图的卡             | 照旧先问                               |
| 重投剧本（会重排整组镜头）、删产出版本           | 照旧先问                               |
| 删库里的东西、公开                               | 照旧没有工具                           |

### 2. 钱闸：按钱算，门槛内直接出

- 每次 `generate` 先用现有单价表估这一批大约多少钱（工作台、首页草稿、画布同一套）。
- **一句话里累计 ≤ 门槛 → 直接出**；超过 → 停下问一句「这批大约 $X，出吗？」（还是现在那张确认卡，上面写价钱）。
- 不另花钱的（NAI 订阅等单价为 0 的）永远直接出；**估不出价的**按超过门槛算，先问一次。
- 「交给 AI 出图」开关改成这道门槛本身：门槛 = 0 就是「每次都问」，等于今天的关；去掉 4 张上限；画布也走同一道门槛。
- 门槛存在助手设置里，你说一句「以后 2 块以内直接出」，助手用现有的 `assistant_setting` 改掉它，不用找设置页。
- ⚠ 钱闸的扳机仍在客户端（服务端照旧没有工具能直接建生成），不变。

### 3. 「这样可以吗」：先做后问，不是先问后做

拿不准时分两种：

- **便宜、能撤销**（改词、换参考、换模型、门槛内出一批）：按最可能的理解直接做，回复里一句「我按 X 理解的，不对你说」。这就是「这样可以吗」。
- **贵或撤不回**（超门槛、删你的东西、两种读法出来的东西完全不同且都要花钱）：先问，用问题卡，2–4 个选项，推荐的放第一个。

你说「不行 / 不对」：助手**换一个方案**（换杠杆，不是换说法），不再问同一个问题；同一点连着三批不中，直说这个模型可能做不到并给替代（现有规则保留）。

### 4. 停下点逐个改

| 停下点                         | 改后                                                                                                                |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| 出图确认卡（默认）             | 门槛内直接出；超门槛才出现，卡上写价钱                                                                              |
| 出完钉的「按这个方向继续吗？」 | **去掉**；改成助手自己看一轮（现有「自看」默认 1 轮，门槛内默认开），看完一句话说中了哪些、没中哪些，以及下一步打算 |
| 「想想 / 你觉得呢」            | 保留：你要的就是讨论，给方向不动手；只有选项真要你挑时才放问题卡                                                    |
| 参考图借哪部分                 | 改成按最可能的部分直接借，回复里说借了哪几样；只有借脸还是借画风这种差很远的才问                                    |
| 角色页提议卡                   | 空着的格子直接填（带撤销）；要覆盖你写过的格子才出卡让你勾                                                          |

### 5. 提示词怎么写

把 `prompt.ts` 里散的几条收成 HOW YOU WORK 下一段，替掉 ALWAYS ASK FIRST：

> Work like a friend who knows them. When you are fairly sure, just do it and finish. When you are not sure but the step is cheap and undoable, do the most likely reading and end with one short line like "I read it as X — say if not". Ask first (an ask card) only in three cases: it cannot be undone; it costs over their limit (the generate result tells you); or two readings lead to clearly different work and the wrong one would waste money. When they say no, change the approach, not the wording.

改完把 `ASSISTANT_NEXT_PROMPT_VERSION` 拨到动手那天。「两种读法」只能靠模型判断，写在提示词里；另两条（撤销、钱）写成代码守卫，不靠模型自觉。

## 改完什么样

> 你：「把这张换成黄昏光，再出两张」
> 助手：（改词 · 撤销）（出 2 张，约 $0.08）……（自己看一轮）「光到了，脸偏暗，我把补光加了一点又出了两张。」

> 你：「画布上全出了」（12 张卡，约 $3.4，门槛 $1）
> 助手：「这批 12 张大约 $3.4，超过你定的 $1，出吗？」[出 · 只出前 3 张 · 先不出]

> 你：「这个不对」
> 助手：换个杠杆再出（门槛内），不再问一遍「你想怎么改」。

## 分步

1. **钱闸**：估价接进 `generate`（工作台 / 首页 / 画布），门槛设置，替掉 4 张上限和画布无上限，确认卡写价钱。单测：估价、累计、估不出价、0 价。
2. **提示词**：上面那段替掉散条，拨版本号。
3. **停下点**：去掉「按这个方向继续吗？」改自看一句话；画布覆盖手写文字、删助手自己加的空卡改直接做；角色页提议卡改「只覆盖时出卡」。
4. **评测**：在 `assistant-eval/cases.json` 加「该问没问 / 不该问却问」几条，等助手全改完统一跑（评测花你的额度）。

每步单独可上线、可回滚。
