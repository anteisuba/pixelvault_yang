## 0. 一句话

| 阶段                  | 建议北极星                                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **现在（画布+LoRA）** | 画布做成 **「想法 → 可审的节点图 → 素材 → 视频」** 的可中断流水线；LoRA 做成 **「发现/挂载已稳 → 底模丰富 + 辅助创作」** |
| **画布图编做完后**    | **跨模态资产闭环**（同一角色/场景在图·视·音·3D 可复用）+ **模板化工作流**（可保存/分享/再跑）                            |
| **再往后**            | 音频/3D **接到同一流水线**（不是孤立页堆模型）；运维级：一致性、批处理、成本与可重复性                                   |

业界共识：单点生成已同质化；**可重复的多阶段流水线 + 角色/风格一致性** 才是差异化（Comfy 生产叙事、故事板→视频、自动分镜工具同一方向）。

## 1. 画布：完整工作流 — 想法与建议

### 1.1 你描述的链路（正确，且对齐行业）

```text
想法 / 一句话 logline
    → 结构化（剧本 / ScriptDoc / 分镜表）
    → 自动投影节点（角色、背景、镜头、声音…）
    → 按依赖批量/串行生成素材
    → 关键帧 / 参考装配
    → 视频节点（I2V / Seedance Reference 等）
    →（可选）合并、延长、归档到 Assets
```

这与：

- 节点式管线（Comfy 式 **prompt → pipeline → production**）
- 故事→分镜→生成视频工具
- 动画/短剧「角色一致性 + 批量镜头」

是同一产品类别。**你们已有节点、助手、ScriptDoc/投影、视频发送计划**，不是从零讲故事。

### 1.2 建议拆成可交付里程碑（避免一次做「全自动大片」）

| 阶段            | 用户可完成的事                                                           | 关键能力                                   | 风险若跳过           |
| --------------- | ------------------------------------------------------------------------ | ------------------------------------------ | -------------------- |
| **W1 半自动**   | 想法 → 助手出大纲/分镜表 → **一键投影**节点图（可改）→ 手动点生成        | `scriptDocToGraph` 幂等、角色/镜头绑定稳定 | 自动生成失控、难调试 |
| **W2 队列生成** | 按依赖顺序 **批量生成**（角色→背景→镜头图→视频），可暂停/重试/单节点覆盖 | Job 队列 UI、失败大声、模型默认锁定        | 扣费爆炸、风格碎     |
| **W3 视频收口** | 镜头图/参考视频 → Seedance Reference / I2V；多镜 merge                   | 已有视频发送计划 + Reference 路径          | 与素材契约脱节       |
| **W4 可重复**   | 保存为 **工作流模板**（图结构+默认模型+提示骨架），一键再跑换 logline    | 模板 schema、版本                          | 每次从零搭节点       |

**原则（强烈建议）：**

1. **助手只写事实层（ScriptDoc），不直接乱戳节点** — 与现有 canvas 方向一致。
2. **每步可人工改** — 全自动是默认路径，覆盖是一等公民（行业生产管线都强调可改、可批、可复跑）。
3. **全图画布默认同一主模型族** — 一致性 > 单镜炫技（你们 baseline 已有）。
4. **先图后视** — 关键帧质量决定 I2V；视频模型用已调研的 Seedance 线。
5. **成本闸** — 批量前预检节点数 × 单价；可先「只生成角色+3 个镜头」试跑。

### 1.3 产品形态建议（体验）

- **向导模式（新手）**：想法 → 3 问（时长/风格/画幅）→ 预览分镜卡 → 确认投影。
- **图模式（熟手）**：现有节点编辑 +「从剧本刷新未锁定节点」。
- **运行面板**：拓扑排序进度条；失败节点标红；一键重试失败子集。
- **不要**第一期做完全无人值守的长片；先做 **15–60s 短片闭环** 再谈集数。

### 1.4 画布图片编辑（你排在完整工作流之后 — 可微调顺序）

业界：生成后 **局部改、扩图、去背、一致性编辑** 是留存关键（Kontext、Seedream edit、画布 inpaint 等）。

建议：

| 若目标是…                       | 建议顺序                                                              |
| ------------------------------- | --------------------------------------------------------------------- |
| 尽快讲清「PixelVault 能出短片」 | **W1→W3 优先**，图编做「镜头修一刀」最小集（inpaint/outpaint/参考改） |
| 尽快讲清「专业修图台」          | 图编可与 W2 并行，但 **别阻塞** 视频闭环                              |

最小图编包（对接已有 canvas image-edit 能力表）：  
**选区 inpaint / outpaint / 去背或提取 / 指令编辑（Kontext 类）** → 结果回写节点 `mediaUrl` 并保留 lineage。

## 2. LoRA 后续：底模 + UI + 辅助创作

当前：挂载/底模骨架差不多。社区事实见 `LoRA底模与工作流调研-2026-07`。

| 方向         | 建议内容                                                                                                                                                          | 优先级 |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| **底模增加** | 优先 **Pony 体验补齐**（快通道或文案诚实「仅 Runner」）、IL/Noob 新 checkpoint allowlist、Anima DiT 来源还原稳；**观察** Krea2/Z-Image 作 LoRA 底，勿与云图模混淆 | P1     |
| **UI**       | Generate 发送预览/容量诚实、Reference 预检（多挂/超 cap）、响应式 compact 主路径、Library 筛选与兼容提示                                                          | P1     |
| **辅助创作** | 按 **family 方言** 的助手（Pony score vs IL 标签）；触发词/搭配确认；「做同款」预检；**不**自动暗挂推荐 LoRA                                                      | P0–P1  |
| **Train**    | 在 Generate/辅助稳后再做 Train 关键切片；训练 base ⊆ 可执行 family                                                                                                | P2     |

LoRA 与画布的交点：**角色节点可挂 LoRA 出设定图**，再进镜头/视频 — 比孤立训模型更能形成闭环。

## 3. 「这些都做完」之后的开发方向

下面按 **差异化 / 依赖 / 市场** 排序，不是堆功能。

### 3.1 第一优先：资产与一致性中枢（已有 Assets 的进化）

行业痛点：角色每镜换脸、素材找不到、无法再跑。

- **角色/场景卡 = 视觉 + 听觉（+ 可选 3D）身份** 贯穿画布与 Studio
- 生成结果 **强制 lineage**（模型、LoRA、参考、seed）
- 「用此角色开新片」一键带参考与默认模型

这是图编 + 工作流 + LoRA 的 **共同收口**，也是对 Midjourney 式单点工具的反击。

### 3.2 第二优先：工作流模板与批处理

Comfy/工作室 生产在强调 **同一 workflow 反复跑、批处理、可分享**。

- 模板市场（个人 → 团队 → 社区）
- 变量槽：logline、角色名、画幅、时长
- 批量：10 条选题共用一图结构

### 3.3 第三优先：音频接到流水线（你判断可扩展 — 同意）

市场：短视频/解说 **声画一体**；TTS/克隆/SFX 已商品化。

建议接法（避免做成孤立「音频页堆模型」）：

```text
剧本台词 → 声音节点（继承角色音色）
环境：背景节点可选 hum
视频：Seedance generate_audio / 后期混音节点（后）
```

扩展点：多情绪音色、字幕时间轴、BGM/SFX 库、与视频时长对齐的自动裁切。  
**先嵌入节点图，再丰富模型目录。**

### 3.4 第四优先：3D 接到流水线

趋势：图/视频 → 3D 资产 → 再渲染/再参考；电商与角色周边。

建议接法：

```text
角色/道具定装图 → 3D 节点（Rodin/Hunyuan…）
→ 多视角图回灌为参考
→（远期）场景布局参考视频
```

3D 单独做「模型动物园」ROI 低；**服务角色一致性与镜头参考** ROI 高。

### 3.5 第五：增长与平台（产品成熟后）

- 模板与作品的 **Gallery 发现**（已有画廊可加强「工作流来源」）
- 团队/分享链接（只读图 + 一键 fork）
- 成本仪表盘（流水线预估 credit）
- 响应式 compact 主路径（见 responsive 调研）— **全程并行债，勿最后才还**

### 3.6 明确可以后置

| 项               | 原因                     |
| ---------------- | ------------------------ |
| 再堆 20 个云图模 | 同质化；先稳默认与一致性 |
| Midjourney 接入  | 无合规 API（已调研）     |
| 完全自动长剧     | 质量/成本/版权未验证前   |
| 重做全站统一皮肤 | 域级 UI 即可；别挡流水线 |

## 5. 对你三个具体问题的直接回答

### 「想法 → 自动节点 → 视频，有什么想法？」

- **值得做**，且是画布存在的理由。
- **做成可审可改的流水线**，不要黑盒一键出片。
- 技术上贴合你们 ScriptDoc/节点/视频发送计划；产品上对标「故事板→视频」+ Comfy 生产批跑。
- 模型：图用 Seedream/FLUX/LoRA 线；视频用 **Seedance（含 Reference）**。

### 「LoRA 底模+UI+辅助做完后呢？」

- 把 LoRA **焊进画布角色节点**，服务短片一致性。
- 全域：**资产中枢 + 工作流模板**。
- 再音频/3D **进图**，不是并排再开两个孤岛。

### 「音频和 3D 怎么扩展？」

- **音频**：台词与角色音色绑定 → 进视频装配；再 SFX/BGM。
- **3D**：定装图→网格→多视角回灌参考；服务镜头而非展览馆。
