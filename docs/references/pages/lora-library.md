## 1. 页面职责

库负责发现与判断：这个 LoRA 效果像不像要的、和当前底模装不装得上、要不要挂上或收藏。收藏管理我收藏的与我自训的。两边都**不**承担提示词编辑、配方回放与出图——那些属于生成台。

## 2. 外壳（第 9f 步 9f-2b 改：叠在外壳中间）

- ≥768 的库 / 收藏⛔ 再住在 LoRA 台里：它们是外壳库叠层的「LoRA」一类（`/library/lora`，收藏 = `?view=favorites`），叠在中间那一栏、盖住对话、⛔ 盖住台（`app-shell.md` §12）。LoRA 台顶上不再有分段（2026-10-25 起训练入口是「自训」第一格虚线「训练新 LoRA」）；旧链接 `?section=community|mine` 送到叠层对应那一格。
- 挂上去进的是外壳上那一份挂载栈（`LoraStackProvider` 挂在 `(shell)/layout.tsx`）：右边 LoRA 台输入框里当场多一颗药丸，台不卸载、不换场。
- LoRA 台开着时登记当前底模（`useRegisterLoraLibraryPick`）：叠层顶上写「选给 LoRA 台 · 底模 X」，详情页按它判断装不装得上；台没开就只按 LoRA 自己的条件说。
- 助手「打开库 / 圈几把」开这一层（输入框里的「＋ LoRA」2026-10-25 起改弹「挑 LoRA」框，见 ui-spec ㉔）；已经开着就不再压一层历史。原来的「竖条浮出整列」「回到生成」与生成 ↔ 库换场一并删掉（台就在旁边，用不着）。

## 3. 库（Civitai / Hugging Face）（③ ⑥ 已落）

- **一行筛选**：搜索占满 · Civitai / Hugging Face · 类型 · 底模 · 分级 · 排序。后四个是按内容宽的下拉，改过的那一格浅灰底。
- **数量一行**：不到 1 万写精确数「8,402 个 LoRA」；搜索中写「正在搜「…」…」。Civitai 索引把总数数到 1 万为止（owner 2026-10-15），到顶写紧凑数加「+」——zh / ja「1万+」、en「10K+」（`formatLibraryTotal`，手机翻页条与筛选抽屉同一写法），⛔ 把封顶值当精确数。
- **卡片**：3:4 封面 + 名字 + 下载 · 点赞。封面先铺这张图的平均色，真图到了由糊变清。悬停封面右下出「＋ 挂载」；挂上后变黑「✓ 已挂载」+ 右上一个 ✓，挂了**留在原地**（⛔ 不弹 toast、⛔ 不跳到生成台）。点卡开详情页（§4）。
- **视频样例**（owner 2026-10-15 选 B「进视野就动」，原型 `.claude/mockups/lora-video-preview/`）：Civitai 的样例是视频时，卡片封面 = 视频静帧（CDN `anim=false,transcode=true,width=N/{id}.jpeg`）+ 左下「▶ 0:06」时长角标（右上是「已挂载 ✓」；时长开播读到元数据才写上）；卡片 60% 进视野就静音循环播放（`transcode=true,width=N/{id}.mp4`，`preload="none"`），静帧 200 交叉淡成视频；**同屏最多 6 段在播**（按阅读顺序，其余停在静帧），出视野立刻暂停、回来接着放；详情页盖住网格时网格整片停下、让出名额。上限整页共用一份（`hooks/use-in-view-autoplay.ts`），视频层只有一处（`library/LoraSampleVideo.tsx`）。片段直连 `image.civitai.com`（自家图片代理只放行 image/\*），静帧照旧走代理。⛔ 自动播放开关（owner 定不要）；⛔ 声音；系统「减少动态效果」时不自动播，只在大图里点播放。只管 Civitai 的视频：Hugging Face 的动态 WebP、以及 Civitai 标成 image 的动态 WebP 照旧由 `<img>` 自己播，不计入上限（owner 定先不管）。竖条与挂载小封面只用静帧。
- **往下滚**：一段 24 个，离底 1.5 屏提前取下一段；来不及时底部一行「正在接着取下一段 · 已显示 N / 总数」，到底写「已经到底 · 共 N 个」。换筛选时旧结果变淡留着，⛔ 不清成白屏。
- **搜索**：回车或点放大镜才搜；输入框底边一截黑线来回走（边即进度），旧结果变淡到 42% 留着，新的到了交叉淡。最匹配的排最前，⛔ 不分段、不加说明（后端 ①）。
- **过载**：先给快照，一句话写明「Civitai 搜索这会儿过载 · 先给你 N 分钟前搜过的同一组结果，好了会自动换成最新的」+「再试一次」。
- **搜不到**：「没搜到「X」」+ 在哪几个筛选里一个都没有 + 放宽一项的按钮，每颗带放宽以后的真实数量。
- **分级**：「安全」= 至少一张安全样例就列出、只放安全图；记住上次选的那一档（本机浏览器，库和收藏共用）。
- **Hugging Face**：同一副外壳，来源差异如实写，⛔ 为了看起来一样编字段——
  - 这一行没有「分级」（上游不给）；搜不到时的「放宽一项」不带数量（上游不报总数）。
  - 上游不报总数：数量行写「已显示 N 个」，到底了才写「共 N 个」。
  - 一个仓库可能有好几个权重文件：只有一个的「＋ 挂载」原地挂；好几个的键写「挂载…」，点了去详情页选文件，⛔ 替用户挑第一个。
  - 挂载 = 直接进挂载栈（同 Civitai），⛔ 顺手收藏；收藏才导入（带出处快照，时刻 = 那一段结果取回的时刻）。
  - 封面是社交横幅兜底的，进视野再去 README 找第一张真图，找到前只铺底色。

## 4. 详情页（④ 已落）

- 从下面升上来盖住库（竖条留着），整页往下滚；‹ 或 Esc 回到库里原来滚到的位置。
- 头部：名字 + 底模 · 来源 · 下载 · 点赞 · 更新时间；右边「挂载 / ✓ 已挂载」「收藏 / 已收藏」「打开来源 ↗」「⋯」（复制风格码 · 复制下载链接 · 取消收藏）。⛔ 没有底部通栏黑条。
- 左：样例三列瀑布，悬停角标「有配方 / 没有配方」，点一张开样例大图（§5）。视频样例同网格：静帧 + 左下时长角标，进视野就静音循环（同屏上限 6）；视频样例**只当预览**（图片台没法拿视频做同款），所以不出「有配方 / 没有配方」悬停标。
- 右 300 窄栏：**版本**（与模型描述同一次请求取回，每个版本就是一条能挂的条目；切版本 = 样例与右栏交叉淡）+ 装不装得上 · **触发词**（点一下复制；「复制全部」）· 分级与授权 · 作者（主页 ↗）· 说明（「展开全部」）· 文件 / 发布 / 样例数。
  - 装不上时的出路是「**换到 {能装上的那一版} ›**」（同一个模型里有的话）：底模只能在第一把 LoRA 的家族里选，从库里「换 X 底模」做不到，⛔ 给一个点了没用的键。
  - 作者只写名字和主页：「他有几个 LoRA」上游要另打一次请求，⛔ 为一个数字多打 Civitai。
  - 样例要么都带配方、要么都没有（作者示例图没带生成参数时才退到纯预览），右栏写「N 张 · 都带配方」或「N 张」。
- 复制成功：那颗键的字换成「已复制」1.2 秒再回来，⛔ 不弹 toast。
- Hugging Face：「版本」那一格叫「文件」（仓库里每个权重文件一行，打开时先落在装得上当前底模的那个）；样例是 README 里的图（都没有配方）；授权写许可名；作者主页指向 Hugging Face；没有分级、风格码与发布日期就不写。
- 分级与授权**如实写**：分级只有 Civitai 条目带；许可有出处快照用快照，Civitai 列表条目用作者勾的权限位，收藏记录没快照的写「许可未知」（⛔ 从空推成「仅限个人使用」）；自训的不画这一格。

## 5. 样例大图

与生成台同一个查看器（`lora-generate.md` §5）：视频样例自动播放、静音循环，底部一条控件（播放 / 暂停 · 进度可点 · 时长）；缩略轨上视频带 ▶ 小标。从点的那张长出来，左大图 + 左右切换 + 缩略轨，右「这张的配方」+「这张还叠了」（挂载栈里已有的写「已挂载」）。库里只有「复制配方 · 打开来源」，⛔ 没有「做同款」（做同款属于生成台）。没带配方的样例同样能打开，右栏只一句「这张没有公开配方」。

## 6. 收藏（⑤ 已落）

- 同一副外壳；一行：搜索（名称或触发词）· 收藏 N / 自训 N · 底模 · 排序（最新 / 最早 / 按名称）。全在本机筛：收藏与自训一次就取齐了，⛔ 为搜索再打服务端。
- 数量一行「N 个收藏」；搜着写「N 个收藏里有「…」」。
- 卡片下面一行写触发词（不是下载数）；滚到底写「已经到底 · 共 N 个」。挂载同库：留在原地，竖条多一张小封面。
- 空的时候各给一条出路：收藏空 →「浏览 LoRA 库」，自训一栏第一格永远是虚线「训练新 LoRA」（空的时候只剩它）。
- 详情页同 §4，头部是「已收藏」，⋯ 里「取消收藏」。Civitai 的收藏打开后取回那一版的完整条目（版本、样例、热度）；收藏记录与取回的条目**按版本号认作同一把**（两边链接写法不同），切到别的版本挂的是那一版，照样过下载闸。
- 自训的详情页没有版本与来源图，样例是它自带的预览图；⋯ 里多「设为公开 / 私有」与「删除」（删除再确认一次）。

## 7. 动效

曲线一律 `--ease-standard`，颜色与透明度线性；时长只取 120 / 200 / 240 / 320，装配列让位那根弹簧与生成台同一根。每一个「开」都有对应的「关」，关也要真的演完再拿掉。

| 动作            | 怎么动                                                                                           | ⛔ 不做                        |
| --------------- | ------------------------------------------------------------------------------------------------ | ------------------------------ |
| 库 ↔ 收藏       | 外壳不动；分段填色照常走；内容 120 淡出，再 200 淡入另一边的                                     | 不重排外壳、不左右滑           |
| 搜索            | 输入框底边一截黑线来回走；旧结果 200 变淡到 42%；新的到了旧的 120 淡出、新的 200 淡入            | 不清空成白屏、不转圈           |
| 封面            | 先铺平均色，真图解码好后 200 由糊变清                                                            | 不闪灰骨架、不逐张飞入         |
| 视频封面        | 60% 进视野静帧 200 交叉淡成视频、静音循环；同屏最多 6 段；出视野立刻停，回来接着放；时长角标常驻 | 一进页面全部开播、出视野还解码 |
| 往下滚          | 新的一段 200 淡入，已有的不动                                                                    | 不跳位、不整页重排             |
| 悬停卡片        | 「＋ 挂载」120 淡入并上浮 4px（200）；封面投影 120；移开同样退回                                 | —                              |
| 挂载            | 按钮 120 变黑「✓ 已挂载」；右上 ✓ 200 淡入；竖条多一个小封面（0.6 → 1，320），数字跳一下（240）  | 不弹 toast、不飞图标、不跳页   |
| 详情页开 / 关   | 从下面 32px 升上来并淡入 320；关上往下沉 32px 并淡出 200，回到原来滚到的位置                     | 不从中间弹、不回到库顶         |
| 切版本          | 样例与右栏 120 淡出，再 200 淡入这一版的                                                         | 不左右滑                       |
| 样例大图开 / 关 | 从点的那张长出来 320；缩回那一张 240                                                             | 不从屏幕中间弹                 |
| 翻样例          | 大图 200 交叉淡；缩略图描边 120 移过去                                                           | 不做左右滑的轮播               |
| ⋯ 菜单          | 从 ⋯ 长出来 0.72 → 1、由糊变清 200；关上缩回 120                                                 | 关时不直接消失                 |

减少动态效果：位移、缩放、宽高变化一律换成 120 淡入淡出；搜索框底边不走、只呼吸。叠层盖上来的「叠」归 9f-4。

## 8. 手机（<1024，2026-09-03 owner 拍板，本轮不动）

范围仅限 Library **标签页**（网格收敛到 `LoraLibraryCard`）。旧的库弹窗（`LoraLibraryModal` picker）2026-09-28 删掉：当时的装配列「＋ 添加 LoRA」≥768 打开库叠层（9f-2b）、手机切到「库」这一栏（库 B 三方向共同约定 ⑤「不再另开库弹窗」）。2026-10-25 起 ≥768 改弹 ui-spec ㉔ 的「挑 LoRA」框（库那副骨架 + 圈选，不是旧的 picker）。

- **视频样例**：同桌面 B，同屏上限 4 段；网格卡左下是底模胶囊，角标放右上；详情抽屉的封面同样进视野就播。
- **结果区**：2 列封面卡网格（640px 起 3 列），3:4 封面取列表 payload 的 `cardImageUrl`（Civitai）/ showcase 封面（HF），封面叠来源 + 底模 chip，名称 2 行 clamp，紧凑 ↓/♥ 计数。桌面见上文 B。
- **详情**：点卡打开底部抽屉（vaul，~92%），内容序＝样例轮播 → 标题+badges → 数据 → 触发词（+推断 pill，可复制）→ 底模/授权/安全 → description → 作者；sticky 动作栏 使用此 LoRA（主）/ 收藏 / 打开来源。关闭回到原滚动位置。详情数据（mined prompts、description）只在打开时经 `selectItem` 拉取，不预取。收藏详情也在打开时按已保存的 Civitai 模型/版本 ID 加载同一份样图，点击缩略图切换大图；尚未加载或无来源样图时展示收藏记录中的图片。
- **筛选**：顶部收成一行 chip `来源 ▾ · 排序 ▾ · 筛选 ●N`，点开底部 sheet（~60%），分区 来源/排序/类型/底模(可搜)/安全，footer `显示 N 条结果`；状态仍归 library hooks 所有，延续 2026-08-07 排序/筛选分层拍板（sheet 内分区呈现，不混排）。
- **分页**：悬浮胶囊 `‹ 1 / 12 ›`，sticky 于安全区上方；页替换语义不变，本轮不做无限滚动。
- 判断依据：手机场景是"看图挑→确认能用→一键用"，44px 缩略图列表让第一步做不了；参考 Civitai 官方 App 的封面网格（只借方法不借皮肤）。

## 9. 助手当面搜（owner 2026-09-29）

助手找 LoRA 时切到「库」、把词填进搜索框、底模筛选设成当前底模家族，你看着它搜；搜完在网格里圈出最多 3 把装得上的，你点卡上「＋ 挂载」。契约见 [`lora-assistant.md`](lora-assistant.md) §13，画板见方向稿画布「LoRA 库 · 助手当面搜 · 全部状态」。

- 助手面板开着时舞台让位，网格与筛选行按剩下的宽度自己排（同生成台让位）。
- 圈 = 封面外一圈黑边 + 左上黑底「助手推荐」小标；推荐 ⛔ 挪到最前、⛔ 放大。挂上后撤掉换成 ✓。
- 搜索框描黑边，右端小标「助手在搜… / 助手搜的」，说明这个词是助手填的；你一改搜索词或筛选，圈、小标、黑边一起撤（结果已不是它搜的那组）。
- 分级、类型不动你的；底模筛选被设成当前底模家族；排序同你自己搜词时一样换回「Highest Rated」。
- 库页在 Hugging Face 时先切回 Civitai（只搜库里的 Civitai）。
- 动效：切页与搜索同 §7；圈晚 120 出现（黑边 200 描上、小标 200 淡入）；撤圈 120 淡出。
