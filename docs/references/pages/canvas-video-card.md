## 0 · 域定义

视频节点是一个可继续参与连线的**视频产物**；右侧编排器是该节点的**唯一下单面**。

- 视频卡只回答“这段视频是什么、现在是什么状态”。
- 右侧编排器回答“本次要怎么生成、使用哪些素材、用什么模型与参数”。
- 已连接素材仍属于画布真节点，不复制、不搬家；编排器只是读取和指定。
- 卡匣/节点定位不在本轮范围；扩大入口复用现有
  `NodeDetailPanel`，不再在节点旁维护第二套详情页。

## 1 · 视频卡

| 部件   | 规格                                                        |
| ------ | ----------------------------------------------------------- |
| 名字   | 卡外左上，族图标 + 原地可编辑名称；复用 `NodeShell.Header`  |
| 卡内   | **只有视频媒体**，不显示场记条、模型、参数、成分 chip、页脚 |
| 空态   | 媒体窗内显示真实空态                                        |
| 生成中 | 媒体窗内显示真实生成中态，不伪造百分比                      |
| 就绪   | 原生 `<video controls>`，poster 复用 `videoThumbnailUrl`    |
| 端口   | 左右垂直居中，保持 React Flow 真锚点                        |

视频卡不因打开编排器改变尺寸；这样连线锚点与下游布局不跳。

## 2 · 右侧编排器

- 只在单选视频节点时出现；拖拽节点、多选时隐藏。
- 固定在视频卡**右侧**；以顶部锚点定位后，桌面上移 `40px`、窄屏上移
  `20px`，落在节点工具条与视频卡之间的视觉中带。
- 桌面间距 `24px`；窄屏间距 `20px`。
- 紧凑宽度使用 `--canvas-card-w-console: 320px`。
- 右上仅保留“展开编辑器”图标；进入中央 `NodeDetailPanel` 后，节点旁不再
  同时保留一套重复详情表单。
- 取消选择节点后整个编排器隐藏。

### 紧凑态

保持一个宽松的输入面，不堆叠重复标签：

1. 模型/模式摘要与“展开编辑器”入口。
2. 已连接参考素材缩略条；没有素材时显示下一步，不放假缩略图。
3. 一块占主面积的原生 `<textarea>`；已有 `@token` 由素材按钮按光标位置
   插入。紧凑态不再使用会在受控回写后丢失选区的 `contenteditable`。
4. 底部 dock：真实模型选择器、参数入口与生成按钮。参数弹层只显示当前
   模型声明支持的时长、画幅、分辨率和音频能力；紧凑时长使用单一滑杆，
   不再额外联动一个“自定义”开关。

### 详细态

- 从侧栏进入中央 `NodeDetailPanel`；视频节点尺寸、坐标和连线不变。
- 继续消费与紧凑态同一份 `useVideoComposer` 状态和节点数据，不复制
  prompt、模型或参数状态。
- 显示真实素材管理、模型选择、模型能力驱动参数、负面词、seed、
  发送预览和错误/缺失原因。
- 不在节点旁重复渲染详情表单；关闭详情页后回到紧凑侧栏。

## 3 · 真值与能力边界

- 不造假模型、素材、容量、生成进度或请求预览。
- 素材缩略与连接计数来自 `useVideoComposer.referenceTokens`；详细态的
  发送预览与溢出继续来自 `useVideoComposer.sendPreview` 和
  `ReferenceManagerPanel`。
- 无角色标签的直连图片按镜头参考收割；`声音 → 非角色图片 → 视频` 保留
  画布边作为绑定关系，声音以“随图片发送”的路由引用显示，并进入同一份
  实际发送计划。它不是复制素材，也不需要新增数据库归属字段。
- 模型选择复用 Studio 的 `CanvasRoutePicker` / `MainModelPicker`；
  `getVideoModelCapabilities` 管具体选项，`video-model-resolver` 管
  Seedance reference sibling，`getVideoModelSendContract` 管素材槽、
  参数是否可编辑和当前执行链是否可用。
- `buildVideoSendPreview` 是预览与真实提交的唯一发送计划；画布提交不得
  另行重算引用顺序、容量或 prompt token。
- 不支持的能力不渲染；缺素材/缺模型/生成中使用真实 disabled reason。

### 模型专属发送契约

| 模型族             | 当前素材槽                                                  | 参数边界                                                              | 执行状态                                |
| ------------------ | ----------------------------------------------------------- | --------------------------------------------------------------------- | --------------------------------------- |
| Seedance Reference | 图片 ≤ 9、视频 ≤ 3、音频 ≤ 3、总数 ≤ 12；音频不能单独发送   | 时长、画幅、分辨率、原生音频、seed；支持 `@ImageN` 位置 token         | Fal 已接入；VolcEngine 未迁移           |
| Seedance base      | 文本或单张首帧                                              | 时长、画幅、分辨率、原生音频、seed                                    | Fal 已接入；VolcEngine 未迁移           |
| Kling V3 Pro       | 当前只发一张明确首帧；不把平铺素材伪装成 Element            | 时长、画幅、负面词、原生音频；不发 resolution/seed                    | Fal 已接入                              |
| HappyHorse v1.1    | 文本或单张首帧                                              | 时长、画幅、720/1080p、seed；模型有原生音频但公开 schema 没有音频开关 | Fal 已接入                              |
| Gemini Omni        | 图片 content array；官方未公布硬图片上限；不发音频/视频参考 | 16:9 / 9:16；时长与 720p 由模型决定                                   | Interactions execution 未迁移，禁用发送 |

未知/自定义视频模型不能只因使用 Fal adapter 就被判定为可执行；必须先有
明确的 worker serializer 和官方能力契约。

## 4 · 响应式与可访问性

- 侧栏用 React Flow `NodeToolbar` 锚定节点并随节点移动，但保持可读的
  屏幕尺寸，不成为 viewport 固定抽屉。
- 窄屏仍在节点右侧，保持 `20px` 间距；画布平移负责把它带进视野。
- 控件均可键盘到达，输入区阻止 React Flow 快捷键冒泡。
- 关闭、展开、生成、模型/参数控件有可读 label。
- 动效只使用 Canvas `150/250/420ms` 三档，并尊重 reduced motion。

## 5 · 验收

1. 点击视频节点出现右侧编排器；拖拽只移动节点，不误开或保留浮层。
2. 编排器左边缘与视频卡右边缘固定相距 24px；打开中央详情不移动视频卡。
3. 视频卡内不再出现成分栏、紧凑 composer 或页脚。
4. 左上名称可 Enter/blur 提交、Esc 取消。
5. 直连散图与经图片路由的声音出现在素材条和真实发送预览；提示词、
   模型、参数和生成按钮读写现有真实状态。
6. 多选与拖拽时编排器隐藏；取消选择后隐藏，重新选择可恢复。
7. 375px 与桌面路径均无布局跳变、遮挡或水平间距漂移。
8. 侧栏预览的接受/丢弃素材与真实请求 payload 完全一致。
9. 定向 Vitest、全量 typecheck、相关 lint 与真机点击/拖拽回归通过。
10. 编排器内部控制区的双击不冒泡为节点双击；只有显式扩大入口进入中央详情。
11. “从画布选择”只列出可合法连入当前视频的现有节点，选中后直接建边；
    “＋”先选图片、视频或声音，再从对应素材库创建节点并建边。两者都不得
    打开详情。
12. 节点双击、视频预览、片盒排序和 Studio 回跳都不得打开详情；所有节点族
    只能由明确标注的扩大图标写入 `expandedNodeId`。
