## 0. 一句话

| 问题                         | 结论                                                                                                                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 组件怎么分层？               | **ui（无业务）→ layout → business（含 studio-shared）→ 域专属（studio/lora/node/…）**                                                                                                      |
| 模型是不是按图/视频/音频分？ | **是。** 数据：`ModelOption.outputType` = `IMAGE \| VIDEO \| AUDIO \| MODEL_3D`。UI：Studio `outputType` 小写 image/video/audio；画布节点 `mediaKind`；选择器 `MainModelPicker.modality`。 |
| 模型组件核心链？             | **数据 hooks（按模态）→ BaseModelPickerPanel / ModelSelector（展示）→ 域包装（MainModelPicker / WorkflowModelPicker / VideoComposer 品牌切换）**                                           |
| 什么适合做成通用？           | 已有一批；优先再抽 **重复的媒体展示、发送预览、进度/空态、参考槽**；**不要**把 LoRA/画布节点业务硬塞进 `ui/`                                                                               |

## 1. 组件分层（现状）

```text
src/components/
├── ui/                 # shadcn + 项目原子：button/dialog/select/prompt-input…
├── layout/             # 应用壳：AppSidebar、LocaleSwitcher、MobileTabBar
└── business/           # 业务 UI（可有状态/hooks，不直打 API）
    ├── ModelSelector.tsx / MediaCardTile / Asset* / Gallery* …
    ├── studio-shared/  # L1.5：≥2 个 Studio 工具共用、无 tool-specific 分支
    ├── studio/         # Studio 工作台本体 + lora/ + prompt-tags/
    ├── node/           # 画布节点工作台
    ├── image/          # Studio 图像结果对比/变体等
    ├── cards/ prompts/ gallery/ home-v3/ assistant/ …
```

| 层                  | 职责                                                | 可跨域复用？                 |
| ------------------- | --------------------------------------------------- | ---------------------------- |
| `ui/`               | 无业务纯原语 + 完整交互态                           | **是**（全站）               |
| `layout/`           | 导航/locale/壳                                      | 应用级                       |
| `studio-shared/`    | 多 Studio 模态共用 chrome/picker/workflow           | Studio 内跨图/视频/音频/3D   |
| `business/*` 域目录 | 单域完整皮肤与流程                                  | 默认否；只共享**行为**时可抽 |
| 页面级拼装          | `StudioWorkspaceUI`、`StudioNodeWorkbench`、首页 v3 | 否                           |

权威分层说明：`business/studio-shared/README.md`、`business/studio/CLAUDE.md`、Hard Rules（ui 无业务 / business 用 hooks）。

## 2. 模型：数据分类（你记得的图/视频/音频）

### 2.1 目录层（常量）

```text
src/constants/models/
  image.ts   → outputType: 'IMAGE'
  video.ts   → outputType: 'VIDEO'
  audio.ts   → outputType: 'AUDIO'（另有 audioKind: speech | sfx）
  model-3d.ts → outputType: 'MODEL_3D'
  enum.ts / types.ts
```

`ModelOption.outputType: OutputType`（`types/index.ts`：`'IMAGE' | 'VIDEO' | 'AUDIO' | 'MODEL_3D'`）。

查询：

- `getAvailableImageModels()` / Video / Audio / 3D 同源过滤器。

**次级分组（选择器内，不是模态）：**

- `styleTag`：photorealistic / anime / design / artistic / general
- `qualityTier`：budget / standard / premium
- `adapterType` + `getProviderGroup()`：按厂商分组
- 视频品牌（Seedance/Kling…）在画布 `video-model-resolver` / VideoComposer，**不是** catalog 的第四模态

### 2.2 Studio 运行时（上下文）

`studio-context` 的 `state.outputType` 为 **小写** workflow 模态：`image | video | audio`（与 3D 工作区可能分挂）。

- 切 workflow → 同步 `outputType`
- `StudioToolbarPanels`：`if (outputType === 'video'|'audio'|…)` 挂不同工具条
- 模型列表：对应 `useImageModelOptions` / `useVideoModelOptions` / `useAudioModelOptions` / `use3DModelOptions`

### 2.3 画布节点

`NODE_MEDIA_KIND_IDS`：`text | image | video | audio`。

- 图像节点再 `role`：character / background / shot / frame…
- 视频生成节点类型常挂 Seedance；参考视频 `videoReference` 不选模型

## 3. 模型相关组件：怎么做的

### 3.1 架构（推荐心智图）

```text
                    ┌─────────────────────────────┐
  catalog           │ getAvailable*Models()       │  按 outputType 分文件
  + API keys        │ + buildSaved… / merge…      │
                    └─────────────┬───────────────┘
                                  │
         useImageModelOptions / useVideo… / useAudio… / use3D…
                                  │
                    StudioModelOption[]（统一 option 形状）
                                  │
         ┌────────────────────────┼────────────────────────┐
         ▼                        ▼                        ▼
 BaseModelPickerPanel      ModelSelector（旧/富）     域内品牌切换
 （studio-shared/pickers）  business/ModelSelector    VideoComposer
         ▲                        │                   Seedance Fast/Std
         │                        │                   fal/volc
 MainModelPicker(modality=…)      │
 WorkflowModelPicker(kind=…) ─────┘  转成 StudioModelOption 再喂 Panel
```

### 3.2 组件职责

| 组件                     | 路径                         | 职责                                                                                      |
| ------------------------ | ---------------------------- | ----------------------------------------------------------------------------------------- |
| **BaseModelPickerPanel** | `studio-shared/pickers/`     | **通用面板**：搜索、workspace/saved 分组、锁 key → setup、选中回传 `StudioModelOption`    |
| **MainModelPicker**      | 同上                         | **按 modality 挂 hook**：`image\|video\|audio\|model_3d\|llm_assist` → 再渲染 Base 面板   |
| **CanvasRoutePicker**    | 同上                         | 画布/路由向模型或 LLM 能力选择（与 Main 同源面板族）                                      |
| **ModelSelector**        | `business/ModelSelector.tsx` | 较早/较完整 Studio 选择器；style/provider 分组、多选对比；`StudioModelOption` 类型源      |
| **WorkflowModelPicker**  | `business/node/`             | 画布 inspector：父组件传入**已按节点类型过滤**的 options；`kind` 归约为 image/video/audio |
| **VideoComposer** 品牌条 | `node/composer/`             | Seedance **品牌/速度/厂商**，不是完整 model 列表；与 Reference 切换耦合                   |
| **HomeV3ModelRail**      | `home-v3/`                   | 营销展示轨，非生成选择器                                                                  |
| **VoiceSelector**        | `node/`                      | 音色，不是 generation model catalog                                                       |

### 3.3 数据钩子（按模态拆分 — 印证你的记忆）

| Hook                   | 源 catalog                  | 用于                             |
| ---------------------- | --------------------------- | -------------------------------- |
| `useImageModelOptions` | `getAvailableImageModels()` | Studio 图、MainModelPicker image |
| `useVideoModelOptions` | 视频 available              | Studio 视频、Main video          |
| `useAudioModelOptions` | 音频 available              | Studio 音频                      |
| `use3DModelOptions`    | 3D available                | 3D 工作区                        |
| `useLLMRoutePicker`    | LLM 能力 scope              | 助手/文本路由                    |

共性：`StudioModelOption` + 用户 active API key → saved routes + healthMap。

### 3.4 与「接入原生/聚合」的关系

选择器 **不** 按「原生 vs fal」一级分类；按 **模态 → 可选模型列表 → 样式/厂商二级分组**。  
原生/聚合是 adapter 层事实（见 `模型接入原生与中转调研-2026-07.md`），UI 只显示 provider 标签/锁 key。

## 4. 适合做成（或已经是）通用组件

### 4.1 已经通用（保持边界）

| 区域            | 例子                                                                                                                                                  | 说明                   |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `ui/`           | Button, Dialog, Select, Tabs, Spinner, PromptInput, SeedInput, AspectRatioSelector, ReferenceImageSection, AudioPlayer, OptimizedImage, CardTileBase… | 继续扩 token，不塞业务 |
| `studio-shared` | BaseModelPickerPanel, MainModelPicker, chrome 布局, QuickSetupDialog, GenerateBar 类                                                                  | 多模态共用壳           |
| business 跨页   | MediaCardTile, AssetSelectorDialog, ImageDetailModal, VideoPlayer, ApiKey\*                                                                           | 多页消费               |

### 4.2 高价值「再通用」候选（跨 2+ 域、行为重复）

| 候选                  | 现状                                                                                            | 建议形态                                                                          |
| --------------------- | ----------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **媒体结果卡**        | ImageCard / MediaCardTile / Polaroid / 节点 NodeMediaPreview 多套                               | 抽「媒体壳」：封面、状态、hover 动作槽；**皮肤按域 variant**                      |
| **生成中/失败/空态**  | StudioEmptyState、各 GenerationError、节点 status badge                                         | 统一 progress + error surface（studio-shared primitives 已有 GeneratingProgress） |
| **参考图/附件条**     | ReferenceImageChip、ImageAttachmentPreviewStrip、reference-image-section、节点 ReferenceManager | 统一「参考槽列表 + 添加/移除 + 强度」行为 API                                     |
| **发送/请求预览**     | 视频 sendPreview 较完整；图/音频弱                                                              | 可推广「将发送字段只读预览」模式到其它模态                                        |
| **详情大图/lightbox** | StudioLightbox、ImageDetailModal、MediaDetailViewer                                             | 合并交互契约，保留域字段                                                          |
| **项目/文件夹筛选**   | ProjectChipFilter、AssetFolderTree                                                              | 已偏通用，避免再复制                                                              |
| **输出类型 chip**     | OutputTypeChip（prompts）                                                                       | 可与 Studio 模态切换视觉语言对齐（不必合并代码）                                  |

### 4.3 不适合抽成全站通用（保持域内）

| 区域                                                  | 原因                         |
| ----------------------------------------------------- | ---------------------------- |
| `studio/lora/**` 整树                                 | 装配/来源配方/库筛选强域语义 |
| 画布 NodeShell + 各 *Node / *Inspector / \*DetailBody | 图数据与边契约绑定           |
| VideoComposer 品牌/Reference 切换                     | Seedance 产品特例            |
| Prompt 助手 LoRA 结果卡                               | 助手协议专用                 |
| 首页 HomeV3\*                                         | 营销域皮肤，禁止回灌 Studio  |

### 4.4 抽取判据（与 ui-page / studio-shared 一致）

1. **≥2 真实消费者** 且行为一致
2. 共享的是 **行为/a11y/状态机**，不是某一域皮肤
3. 无 `if (mode === 'lora')` 硬编码；模态差异用 **props / slot / variant**
4. 不把 service/API 拉进 `ui/`

## 5. 模型 UI 分类总表（设计/实现对照）

| 维度                  | 取值                             | 用在哪                                        |
| --------------------- | -------------------------------- | --------------------------------------------- |
| **模态（一级）**      | IMAGE / VIDEO / AUDIO / MODEL_3D | catalog 文件、MainModelPicker.modality、hooks |
| **Studio 工作流模态** | image / video / audio            | studio-context.outputType、工具条分支         |
| **画布 mediaKind**    | text / image / video / audio     | 节点生成 kind、WorkflowModelPicker.kind       |
| **风格分组**          | styleTag                         | ModelSelector / 部分列表分组                  |
| **厂商分组**          | provider group                   | 选择器二级                                    |
| **视频品牌**          | Seedance / Kling / …             | 画布 VideoComposer，覆盖 catalog 子集         |
| **路由类型（文档）**  | 原生 / fal·Replicate / Runner    | 非 UI 一级分类；见 provider 调研              |

**你的记忆正确：产品与目录的主分类是图 / 视频 / 音频（+ 3D）。**  
其下再分风格、厂商、以及视频品牌/Reference 模式。

## 6. 给后续改造的建议优先级

1. **文档化**（本文）：选型时先定 modality，再选 Base 面板，避免再写第四套 ModelSelector。
2. **新模型选择入口**：优先 `MainModelPicker` + 对应 hook；画布用 `WorkflowModelPicker` + 父级过滤 options。
3. **抽组件**：先参考槽与媒体卡壳（多域痛点），再动 LoRA/节点。
4. **收敛遗留**：`ModelSelector` 与 `BaseModelPickerPanel` 长期应统一视觉/无障碍；新代码不要两边各写一半。
