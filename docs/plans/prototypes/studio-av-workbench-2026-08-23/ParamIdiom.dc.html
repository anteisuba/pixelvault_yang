形态 1

折叠行

整行是 button · aria-expanded

收起时行内印当前值，截断；空值印 placeholder。这样不点开也知道它现在是什么。

展开后预览必须消失 —— 下面的输入框已经把同一句 placeholder 写了一遍。「同一句话不许一屏两遍」，这条是 08-22 从真机改回来的。

⌄ 图标 size-3.5 · duration-fast(120ms) · ease-standard，展开转 180°。

⚠ 容器必须挡住冒泡（onClick stopPropagation）—— PromptInput 根 div 在容器内任何点击冒泡上来时都会把焦点抢回主提示词框。不挡的结果是「看着聚焦了、打的字全进主框」。

开合状态存组件本地 useState，不进 reducer —— 没有第二个入口需要开它。

用在：内容是列表或多行文本、展开占高的那些（停顿与发音 · 模型参数 · 多角色音色 · 反向提示词）。

形态 2

单一触发器 + 浮层

桌面 popover / 手机抽屉，同一对原语

触发器把每一档的当前值都写出来（16:9 · 自动 · 每模型 1 张）—— 收起状态下也不用点开才知道下一版长什么样。这是它和折叠行最大的区别：折叠行只印一个值，它印一组。

⚠ 摘要里的值必须确实在候选里才印。清晰度那条守卫就是为此：能力表给 1K/2K/4K 而默认是「自动」，不守卫会印出一个弹层里根本点不回去的值。

某一档在当前模型上不存在 → 整组不渲染，不是置灰。视频的时长 / 分辨率天生就这样（档位实算，空数组不画）。

开合状态进 reducer 的 panels —— 命令面板等第二入口要能开它。

组内选项是药丸：选中 bg-primary/10 + text-primary + ring-1，未选中描边。触发器打开时换成 border-primary/30 + bg-muted/45。

用在：2–4 组枚举、每组 2–5 个候选（视频规格 · 音频朗读 · 音频输出 · 音效规格）。

形态 3

名单 + 居中面板

复用 BaseModelPickerPanel layout="columns"

名单用行不用丸 —— 行装得下单价，缺价一眼看得出来。

每一行都能删，包括最后一条。 删空了回到「请先选择」，那本来就是合法状态；留一条删不掉的行反而让「怎么换掉它」没有出口。

⚠ 添加入口恒不显示选中值（value={null}）。传选中值会让触发器和名单第一行写着同一个名字 —— 真机抓到过「名单 FLUX LoRA + 触发器 FLUX LoRA ⌄」。

缺 key 的行不置灰死掉，点它走 QuickSetupDialog 内联配置（Hard Rule 8）。

用在：候选多、要搜索 / 试听 / 比价的（模型 · 音色库）。音色库天然是这一类 —— 它要试听。

怎么选

—— 判据是「内容长什么样」，不是「重不重要」
列表 / 多行文本，展开占高 → 折叠行。收起印一个值。
2–4 组枚举，每组几个候选 → 触发器 + 浮层。收起印一组值。
候选多，要搜 / 试听 / 比价 → 名单 + 居中面板。名单是行。

⛔ 一栏里不要同时出现三种以上折叠行。音频 B 原稿的五个折叠就是这个病 —— 按上面判据重分之后是「2 浮层 + 2 折叠 + 1 面板」，见音频切片板。
