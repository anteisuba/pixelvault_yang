# 提示词页面

2026-09-28 owner 从三方向里选 **A「网格 + 详情一页」**（与 LoRA 库 B 同一个样子）。画板：设计画布「工作台布局与弹层 · 方向稿」页「提示词页 · 三个方向」的 A 列（`PmA` 主画面 · `PmA_Detail` 点开 LoRA 模板 · `PmA_Empty` 搜不到）与动效表 `PmMotion`。09-09 那版（design-suite `#prompts` 的正文卡 + 弹窗详情）作废。

## 职责与范围

查找、保存、编辑、复制模板，把模板送回对应的台。保留「我的模板 / 共享提示词库」两个 tab、权限、发布、clone 与作品血缘。

- **类型只有四格：全部 · 图片 · 视频 · LoRA。** ⛔ 音频那一格去掉（owner 2026-09-28：音频有提示词没什么用）；已有的音频模板不删，留在「全部」里。新建弹窗也不再给音频（类型只剩图片 / 视频，推荐模型不列音频模型），音频结果上的「存配方」一起拿掉。音频台自己的模板面板照旧。
- **LoRA 模板存整套**（owner 2026-09-28）：挂载的几把（名字 · 链接 · 权重 · 触发词 · 来源，与装配台那一份记录同形）· 底模 · Runner 参数 · 提示词 · 负面。从 LoRA 台结果上的「存成模板」来（见下）。判据：模板的 `params.loraSetup` 在，或旧存的 `params.advancedParams.loras` 非空。
- 「共享提示词库」那一页这一轮不动。

## 结构（桌面）

- **一行筛选**：搜索（占满、打字就筛）· 类型 ▾ · 排序 ▾（最近用过 / 最近新建）；改过的那一格浅灰底（同库 B）。下面一行写真实数量「N 个模板」。
- **网格**：4 列，容器变窄时 3 / 2 / 1 列。卡片 = 类型 · 名字 · （LoRA 模板多一行「名字 权重」）· 元信息（模型或底模 · 第 n 版 · 日期）；有作品的放封面、不铺正文，没作品的铺正文前五行。悬停出「复制 · 使用」。⛔ 卡片上不放删除 / 编辑（在详情里）。
- **详情是一页，从下往上升**（同库 B）：头部「‹ 返回 · 名字 · 类型 · 第 n 版 · 日期」，右上「使用 · 复制提示词 · 编辑 · ⋯」（⋯ = 发布 / 取消发布 · 删除）。左边这一套出过的作品（大图 + 一排缩略，没出过写「还没出过作品」）；右边一条窄栏：
  - LoRA 模板：搭配（名字 权重 · 底模）· 参数 · 提示词 · 负面；
  - 图片 / 视频模板：模型 · 提示词 · 负面。
- **编辑**：右栏换成表单（名字 · 提示词 · 负面；图片 / 视频模板另可换模型），保存 = 新一版，取消还原。
- **使用**：图片 / 视频模板跳回对应的台、只换提示词（沿用现有的预填）；LoRA 模板回 LoRA 台，把底模 · 挂载 · 权重 · 参数 · 提示词 · 负面原样装好，⛔ 不直接出图、⛔ 不带种子（种子回到随机）。每次「使用」记一次最近使用时间，「最近用过」按它排（没用过的按新建时间排在后面）。
- **空态**：搜不到 = 写明是哪个条件没有 + 放宽的出路（去掉类型 / 清空搜索 / 去共享提示词库）；一个 LoRA 模板都没有 = 说明它从 LoRA 台「存成模板」来。

## LoRA 台上的「存成模板」

结果图右上角、「问助手」旁边一颗同形的图标键。存的是**这一张出图那一刻**的整套（出图时就地记下，⛔ 读当前装配台 —— 出图之后动过的不算）；服务端核对挂载链接与这张图实际用的一致。存好了键换成「已存成模板」，toast 带「去看看」。结果条刷新即清空，所以素材库 / 画廊里旧的 LoRA 图走原来的「存为模板」只存得到链接与权重，名字按收藏记录补，补不到就写「LoRA」。

## 动效（照 `PmMotion`）

- 开详情：从下 32px 升上来并淡入，320；关：下沉 32px 并淡出，200，回到网格原来滚到的位置。
- 悬停卡片：「复制 · 使用」120 淡入，卡片投影 120；⛔ 不放大卡片。
- 筛选与搜索在本地，结果立刻换；⛔ 不清成白屏、⛔ 不转圈。
- 复制：那颗键的字换「已复制」1.2 秒再回来，⛔ 不弹 toast。
- LoRA 模板「使用」：装配列多出来的几行走到位（同装配列挂载的那一拍）。
- 减少动态效果：位移换成 120 淡入淡出。

## 状态与验收

覆盖：没有模板、搜不到、有 / 无封面、封面失败、LoRA 模板（新存的整套 / 旧存的只有链接）、详情加载 / 失败、编辑 / 取消 / 保存、复制失败、使用（图片 / 视频 / LoRA）。键盘可达、焦点返回卡片、reduced-motion。手机（<1024）这一轮不重做：同一套组件在窄容器下单列、详情页全屏。验证用定向组件测试、lint、typecheck 与浏览器证据；生成、发布、删除不在真实账号上执行来验证布局。
