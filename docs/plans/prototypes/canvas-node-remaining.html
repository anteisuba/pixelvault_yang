画布全域扫描 · 功能 / 页面 / 交互 / 窄屏 / 键盘

画布，里里外外都看过了。

功能够深。路标、层级、窄屏，还没跟上。

全 域 实 测

一句话

不是功能少。是入口太多，彼此挤。

画布、左栏、底栏、助手，四层同时抢注意力。

20个工作面检查
0个阻断 / 数据事故
3个必须先修

全景

一张画布，四套操作。

节点在中间。资源在左。控制在下。AI 在右。

功能完整 项目可恢复 工作面互相遮 没有稳定主次

P1 · 误触

点“当前项目”，却打开素材库。

“添加”菜单盖住导航，还会截走点击。

实测复现：菜单打开时点击“当前项目”，触发了下层的“从素材库选择”。

入口盘点

找得到。看不清边界。

P1 · 键盘

先走 20 条线，才轮到按钮。

Tab 读的是内部 ID。18 个节点又都叫“命名”。

AI 工作面

助手很强。也很占地方。

聊天、生成大纲、节点应用，已经是一套独立工作台。

P1 · 手机

能看到。很难做。

390 像素宽：大画布被缩成微缩图；助手挤满屏。

优先级

先清路，再美容。

P1 · 先修

挡错路

添加菜单不要盖导航。连线退出 Tab 顺序。手机改成“查看 / 审核”，别硬塞桌面画布。

P2 · 收口

一件事，一扇门

搜索连卡片一起过滤。适应画布只留一颗。节点与卡片库分清。项目删除远离改名。

P3 · 打磨

让状态说人话

30% 时给概览标签。按钮带对象名。助手头部在窄屏分两行。统一 44px 触点。

值得保留

这不是模板拼出来的画布。

留节点种类按图片 / 视频 / 声音 / 组织分组
留项目、历史、节点三种索引都在左边
留撤销 / 重做不可用时诚实禁用
留助手可收起；剧本按需展开

检查边界

危险动作，没有乱点。

实测画布、添加、素材库、项目、历史、搜索、外观、底栏、助手、剧本、8 种详情。
窄屏1024、768、390。桌面视口已恢复。
只读核对审核模式、生成流程、分享、改名、删除、新建项目。
没触发会花模型费用、改数据、删除项目的动作。

运行中未发现画布自身报错。开发日志只有一条首屏图片加载提醒；浏览器扩展报错不计入产品问题。

下面：8 种节点

每一种，都新建、点选、拖动、打开。

节点结论保留在后半本。

先共同的病

点 + ，全堆在同一个点上。

默认 200%。生成类空窗把屏幕撑满。下单面经常在画面外头。

现在

8 张卡，一个坐标。

添加菜单从左侧 + 落下的节点，全部生在同一个 topbar 坐标。叠成一摞。空图片、空镜头、空视频、空文本，每一张都是一块巨大的白幕。

改完

错开落。空窗跟名片一样克制。

每加一张，往右下错一格。空生成窗默认约 320 宽，不要一出生就占半屏。下单面必须落在视口里。

01 · 图片

拖入即可上传。点了没反应。

新建「图片」。没有名字。没有工具条。没有右侧生成框。整张卡是 dropzone。

点选：巨大空框 点击：不打开文件 下单面：没出现 拖文件：这是唯一入口

现在

一张邮票大的工作，做成一块墙。

改完

240 宽虚线框。点选后右边出生成面。点击也可上传。

02 · 镜头图

两个生成门。

点选后：上头「生成」，右边再一个「描述你想生成的画面」。

工具条生成 右侧再一扇门 空窗文案短了

现在

同一件事，按两次。

改完

工具条只留展开和删除。生成只住右边。

03 · 视频生成

空窗对了。下单面经常看不见。

新建时卡太宽，右侧编排器被挤出视口。点选等于没打开。

空窗不是说明书 默认尺寸太大 打开面跑出屏幕

现在

点了，像没点。

改完

卡缩到能并排放下右侧面。空着不要写就绪。

04 · 参考视频

和视频生成长得像一对。

「还没有上传视频」。摄像机图标。同样大的白窗。上传入口不明显。

不像「请上传」 和生成空窗几乎同款

现在

两个视频空窗，分不清谁产谁吃。

改完

参考卡更小。正中一颗「上传视频」。不跟生成窗抢脸。

05 · 镜头文本

一段字，撑成电影幕。

点选。没有右侧写作面。要改字得再按展开。空着是 16:9 的「还没有镜头文本」。

卡是视频尺寸 点选不能写 必须打开详情

现在

笺被做成了幕。

改完

窄笺。点选就能写四格：场景 / 动作 / 镜头 / 构图。

06 · 视频合成

还没有成片。合并键找不到。

和镜头文本、参考视频叠在一起。工具条「开始合并」在卡顶上，卡一高就被顶出视口。

说明书撤了 主动作容易看不见

现在

空窗对了，手势没地方放。

改完

选中后右边是片段条 + 合并。不要只把键挂在头顶。

07 · 音色档案

同一件事，三个入口。

卡上「从音频库选择」。上头「声音库 / 从素材选择」。右边「描述你想生成的声音」。参数条还写着下一轮。

空卡是名片尺寸 文案不再说画面 入口重复三次 拖的时候封面和正文会裂

打开：左边又是空湖。没选音色，右边已经有语速 / 音量 / 情绪。

现在

挑音色，三条路。打开，一块灰。

改完

卡上那一颗是唯一入口。拖影整张走。打开就是声音库，不是灰井。

♪
从音频库选择

08 · 收集

菜单里没有场景。只有「收集」。

「收集」建出角色名片。场景要从别处变。点选后工具条是添加素材 / 出演。

名片脸 场景不在添加菜单 拖同样会裂

现在

角色有门。场景没有门。

改完

菜单里角色 / 场景两行。拖影整张名片。

第二轮 · 真的按了「展开」

打开，就是把一张卡变成一张大工作桌。

有东西，桌子可以大。没东西，先把下一步放到眼前。

↗ 按卡片上方这个键

打开 01 · 图片

有图时，能用。

左边看图。右边改图、选模型、加参考。

看图很清楚 生成在右边 空图片不该先铺大画布

空着时

先看到一块大空地。

应该

先问：上传，还是生成？

打开 02 · 镜头图

左边全空。工作都在右边。

要先写提示词、镜头、构图、动作。灰色大舞台此时没有用。

现在

空舞台是主角。

应该

先写画面。有图后再放大舞台。

打开 03 · 视频生成

素材很多，却躲在右边。

左边还是空。真正要检查的是 7 个素材和提示词。

现在

先看空片，再找素材。

应该

先核素材和文字。有片再看大片。

打开 04 · 参考视频

这张基本对了。

视频就是主角。右边只说文件。底下只有清空和替换。

一眼知道它是什么 一眼知道能做什么

打开 05 · 镜头文本

这张也对了。

四个格子：场景、动作、镜头、构图。没有假舞台。

打开后很清楚 但卡片上不能直接写

打开 06 · 视频合成

最空的一张。

0 / 9 段。左边却先留了一整块成片舞台。

现在

没有片段，也先给影院。

应该

先给 9 个片段槽。接够两段再合并。

打开 07 · 音色

内容清楚了。入口还太多。

中间是试听卡。右边有系统音色、我的音色、声音库。

终于像声音档案 卡上还有声音库 / 素材 / 生成三条路 试听显示 0:00

打开 08 · 收集

最像一个档案柜。

左边放参考图。右边绑角色卡、音色、出演镜头。

图放一起 身份关系放一起 打开比卡片更有价值
