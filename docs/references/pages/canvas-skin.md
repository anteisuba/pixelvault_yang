# 画布域皮肤数值规格 v0.2 —— `src/app/canvas.css` 的施工基准

> 目的：把 owner 认可的外壳语言从**散文**变成**可执行数值**。散文（"轻盈""白卡""柔和投影"）钉不住观感，三轮都在漂 —— 这份文件是钉子。
> 作用域：`src/app/canvas.css`；**脊柱（`globals.css` / `@theme` / `ui` 原语）不动**。
> 相邻文档：结构与信息设计见 [`node-canvas.md`](node-canvas.md) 与 [`canvas-node-detail.md`](canvas-node-detail.md)。
>
> **v0.2 状态**：v0/v0.1 的色值是**读图估值**；本版全部替换为 **owner 指定参考站的真机取样值**（见 §0.4）。所有对比度用确定性脚本逐对计算，**并逐条标出我们刻意不跟随的地方**（§11）。
>
> ⚠ **落地时的两处偏离，改 `canvas.css` 前必读**：
>
> 1. **§0 说「全部定义在 `.domain-canvas` 作用域内」，实现里不是。** 第一版照此做，真机暴露系统性缺口：Radix
>    Popover / Dialog / DropdownMenu / Select 的内容传送到 `document.body`，在 `.domain-canvas` 的 DOM 子树之外，
>    CSS 自定义属性不跨这个边界，14 个传送门文件因此全部回退到旧的 `--node-*` 深皮值。第二轮改为在 `:root`
>    直接反转 `--node-*` 默认值（`canvas.css` 顶部那块），并且**值写字面量而不是 `var(--canvas-*)`** ——
>    `--canvas-*` 只在 `.domain-canvas` 内定义，`:root` 这一层引用不到。字面量仍 1:1 抄自本文，不是新造颜色。
> 2. **深色档（`.domain-canvas[data-scheme='dark']`）没有实装。** 下表深色列保留为将来的目标值，当前画布域是纯浅色档，
>    且必须显式声明 `color-scheme: light`（app 在 `layout.tsx` 硬编码 `<html class="dark">`，不声明的话原生滚动条/表单控件
>    会在白卡上渲染成深色竖条）。

## 0 · 命名与落点

前缀 `--canvas-*`（区别于遗留 `--node-*`）。定义在 `.domain-canvas` 作用域内，深色版用 `.domain-canvas[data-scheme='dark']` 覆盖同名 token，**不新增第二套名字**。（⚠ 传送门例外见文首。）

## 0.5 · 克制纪律（设计理念）

参考站「看着舒服」的根源不是圆角或投影，是**它几乎不用颜色**，且**分层差极小**。六条可执行规则：

1. **结构一律不着色。** 边框、分隔线、分组标题、图标全部中性。
2. **全画面最多两类非中性色**：强调（只表"选中 / 活跃"）+ 语义（只在徽章尺寸）。
3. **主动作用墨色实底，不用品牌色。** 参考站实测 `--btn-primary-bg: #0a0a0a` / text `#ffffff` / hover `#262626` —— 印证此条。
4. **分层靠极小的明度差，不靠边框。** 实测卡白 vs 画布底仅 **1.13:1**。轻盈感的代价见 §11。
5. **禁用不消失** —— 保留原位、降到 subtle、**并给原因**（参考站只灰不给原因，不继承）。
6. **可检查硬指标**：一屏内彩色（chroma > 0）像素占比 **< 2%**，媒体内容不计。

### 3.1 可达性的落法（**本规格与参考站的核心分歧**）

参考站的控件边 1.19:1、填充 1.09:1 —— **"这里能点"这件事在静态下几乎不可识别**。但直接把边加粗到 3:1 会毁掉它的干净。折中：

> **可识别性由「内容 + 焦点」承担，不由「边框」承担。**

1. 静态边与填充**对齐参考站**（`.08` 边 + `.04` 填充）—— 观感一致。
2. **图标 / 文字本身必须 ≥3:1**：图标色用 `--canvas-ink-regular #525252`（**7.81:1**）。一个纯图标按钮，图标本身就是它的可识别信息。
3. **焦点环 2px `#737373`（4.74:1）**，键盘可达全程可见。
4. **选中态用 `--canvas-accent` 2px 环（5.56:1）**，不靠填充差。
5. **例外**：既无图标也无文字的纯色块（如空槽位）必须用 `--canvas-stroke-focus` 档的边，不能用 `.08`。

### 3.2 分段控件（比例 / 画质 / 音频开关这类）

实测参考站 tab 组：槽底 `rgba(0,0,0,.04)` · 选中块 `#ffffff` · 选中字 `#0a0a0a` · hover `rgba(0,0,0,.05)`。
本规格采用，并补：选中块加 `0 1px 2px rgba(0,0,0,0.08)`；**禁用项留在原位 + 降到 subtle + 必须带原因**。

### 3.3 画幅选项

图形在上（按真实比例画的小矩形，非文字 pill）、文字在下；选中态是**填充块**不是描边。现状代码已做对（`VideoComposer` 画幅可视化选择块），保留。

| ----------------- | --------- | --------- | ----------- |
| `--canvas-ok`     | `#16794C` | `#4FBF8B` | 5.42 / 7.19 |
| `--canvas-warn`   | `#8A5A00` | `#D9A441` | 5.93 / 7.33 |
| `--canvas-danger` | `#C0342E` | `#F0736C` | 5.57 / 5.79 |

## 6 · 间距节奏与密度 ⚙

基数 `4px`。允许台阶 `4 / 8 / 12 / 16 / 24 / 32`，不许 6、10、14、18。
控件高度：紧凑 `28px` · 常规 `32px` · 主动作 `36px`。触屏最小命中 44px 靠 padding 补。
格位尺（容量区）：格 `20×20px`，间距 `4px`，圆角 `4px` —— 9 格一行实宽 `212px`。⚙ 决定卡最小宽度。
卡宽：`--canvas-card-w: 250px`（实测对齐）· 组装台 `320px`。
浮起容器内：`padding: 8px`，`gap: 8px`（rail，实测）/ `gap: 16px`（底部工具条，实测）。

### 7.1 连线 —— 三个维度编码三件事，颜色只有两档

参考站实测（zoom 0.97）：

| 边类型             | 实测                                                                      | 对底   |
| ------------------ | ------------------------------------------------------------------------- | ------ |
| 已连接（含选中态） | `#A3A3A3` 实线 · 渲染宽 ≈3.8px · `stroke-linecap: round`                  | 2.29:1 |
| 选中叠加           | 渐变「彗星」流光，`stroke-dasharray: 64.5px, 99999px`（一段亮点沿路径跑） | —      |
| 未就绪 / 待生成    | `#D4D4D4` 2px 虚线 `6,5` · **`opacity: 0.55`**                            | ≈1.2:1 |
| 命中区             | 透明 `hitarea`，宽 ≈15.4px                                                | —      |

⚠ **更正**：v0.2 初稿把参考站的虚线称作"装饰"，是看漏了 —— 它本来就在用「实线 = 已建立，虚线 = 未就绪」的语义。本规格**沿用这套语义**，只调达标值。

本规格：

| token / 维度 | 已建立                                  | 未就绪                                                             | 选中                                  |
| ------------ | --------------------------------------- | ------------------------------------------------------------------ | ------------------------------------- |
| 色           | `--canvas-edge` `#8A8A8A`（**3.06:1**） | `--canvas-edge-pending` `#A3A3A3` @ `opacity .6`（弱信息，允许弱） | 不换色                                |
| 粗细         | `3px`                                   | `1.5px`                                                            | 不变                                  |
| 虚实         | 实线，`linecap: round`                  | 虚线 `6,5`                                                         | 不变                                  |
| 叠加         | —                                       | —                                                                  | 彗星流光（明度 + 动效，**不加色相**） |

三个维度（粗细 / 虚实 / 流光）分别编码"建立与否""重要性""当前焦点"，蓝仍被"选中对象"独占（§0.6）。
命中区沿用其慷慨值：透明 `stroke-width: 16px`。
深色档：`--canvas-edge` `#8A8A8A` 不变（对 `#0A0A0A` 达标），pending 用 `#525252`。

左缘族色条宽 `3px`。

## 8 · 浮起容器（玻璃）与浮层

全部实测自参考站，**直接采用**（owner 本来就要「左侧工具栏玻璃质感」）：

| 构件                              | 背景                     | 圆角                         | 边                     | 投影                                                                 | 模糊                       | 内距 / 间隙                        |
| --------------------------------- | ------------------------ | ---------------------------- | ---------------------- | -------------------------------------------------------------------- | -------------------------- | ---------------------------------- |
| **左侧合体面板**（rail + 班底架） | `rgba(255,255,255,0.80)` | `16px`                       | `1px rgba(0,0,0,0.08)` | `0 4px 20px rgba(0,0,0,0.10)`                                        | `blur(35px)`               | 图标轨 `8px`/`8px` · 内容区 `12px` |
| **左侧收起态**（仅图标轨）        | 同上                     | `9999px` 全胶囊              | 同上                   | 同上                                                                 | 同上                       | `8px` / `8px`                      |
| **底部工具条**                    | `rgba(255,255,255,0.85)` | `999px`                      | 同上                   | `0 4px 6px -2px rgba(0,0,0,0.06), 0 10px 15px -3px rgba(0,0,0,0.10)` | `blur(20px) saturate(1.5)` | `0 8px` / `16px`                   |
| **浮层 composer**                 | `#FFFFFF`                | `14px`（实测 `--radius-xs`） | `1px rgba(0,0,0,0.08)` | `0 4px 12px rgba(0,0,0,0.04), 0 8px 24px rgba(0,0,0,0.06)`           | —                          | `16px` / 组间 `20px`               |

尺寸：左侧面板展开 `296px`（`56` 图标轨 + `240` 内容区），收起 `56px`；距左 `20px`，上下留 `20px`。底部工具条实测 `459×52`。
⚠ 展开态圆角用 `16px` 而非全胶囊 —— 一块高而宽的面板做成胶囊会把顶底内容挤出可用区；只有收起成窄条时才回到 `9999px`。图标轨与内容区之间用 `1px rgba(0,0,0,0.08)` 竖分隔，**不做二次投影**。
深色档：玻璃底改 `rgba(23,23,23,0.80)`，边改 `rgba(255,255,255,0.10)`，投影加深而非发光。

浮层遮挡纪律：贴节点右侧、顶对齐、跟随节点；视口不够时翻到左侧；**永远不盖住它自己的入边与上游卡**。

## 9 · 动效

对齐实测：`--canvas-dur-fast: 150ms`（hover / 状态标）· `--canvas-dur-base: 250ms`（浮层出入、选中）· `--canvas-dur-slow: 420ms`（面板展开）。
曲线：`--canvas-ease-out: cubic-bezier(0.22, 1, 0.36, 1)`（进入 / 弹出）· `--canvas-ease-inout: cubic-bezier(0.4, 0, 0.2, 1)`（状态过渡）。
`prefers-reduced-motion` 全部降到 0 并保留终态。

## 10 · 真机校准清单（⚙ 五个旋钮）

1. `--canvas-dot-gap` 48 —— 与现状 44 目视比对
2. 节点卡有边（`.08`）vs 无边 —— §11-① 的取舍需真机看
3. `--canvas-card-radius` 8 / 10 / 12
4. 格位尺 20px —— 18 / 20 / 22，决定卡的胖瘦
5. 连线 `#8A8A8A` 1.5px 实线 —— 一屏 20 条边时会不会太吵

## 12 · 由真机勘察带出的结构问题

### 12.1 卡名在卡外 —— ✅ 已拍板（owner 2026-07-26）

卡名住卡**外**上方：`15px/24px · 600 · --canvas-ink`，前置族图标，与卡顶间距 `4px`，左对齐卡的左缘。卡内 `padding: 0`，是纯媒体。

**这推翻了原「共享节点外壳」的第一件**。新的外壳分解：

| 部件          | 位置                                                   | 说明                                    |
| ------------- | ------------------------------------------------------ | --------------------------------------- |
| 族图标 + 名字 | **卡外上方**                                           | 唯一的文字标识；改名在此处原地编辑      |
| 媒体窗        | 卡内，`padding: 0`                                     | 卡 = 媒体本身，`250px` 宽，媒体比例定高 |
| 状态          | 媒体窗内**左上角浮标**                                 | 形 + 词双编码；空态时占据媒体窗中心     |
| 唯一主动作    | 媒体窗内**居中浮层**（实测参考站「替换」按钮即此形态） | 仅 hover / 选中时出现，不常驻           |
| 端口          | 卡左右缘垂直居中                                       | 族色 + 形状双编码                       |
| 近场工具条    | 卡外，选中时出现                                       | 位置策略随展开形态定                    |

⚠ 连带影响：**组装台的容量条与参数摘要 chip 没有"卡内头部"可挂了**。组装台因此是唯一"卡内有内容"的族 —— 它的媒体窗下方接一段控制区。这个例外要在信息设计文档里写明。

### 12.2 底部工具条 —— ✅ 已拍板（owner 2026-07-26）

**方案 B（按职责分栏）+ 班底架常驻第二主角。** 正式**修订已确认条款 7 的后半句**（「底部腾空」）：

- 顶栏 = 项目 + **视图切换（画布 / 序列）**
- 左侧 = **rail 与班底架合体的单一浮起容器**（`56px` 图标轨 + `240px` 内容区 = `296px`）
- 底部中间 = 视图控制浮起胶囊（选择·手 / 缩放 / 适应 / 撤销重做）
- 右侧 = 助手 dock，可收起，**默认收起**

拆分依据是**控件形状**不是审美：缩放 `− 70% +`、撤销重做、选择·手都是横向控件组，竖排必须降级成弹层；而「添加」「班底」是单图标开大面板，天然竖排。
完整布局与断点策略见 [`canvas-workbench.md`](canvas-workbench.md)。

## 13 · 交给实现时的硬要求

- 全部 token 落在 `.domain-canvas` 作用域，**不改任何 `--node-*` 旧值**，两套并存直到旧皮退役。
- 深色版不是把浅色反相：卡背比底亮、投影靠加深而非发光。
- 不引入 Tailwind arbitrary values（Hard Rule 5），全部走 `@theme` 或本作用域 CSS 变量。
- 玻璃容器必须给 `@supports not (backdrop-filter: blur(0))` 的降级（提高不透明度到 0.95）。
