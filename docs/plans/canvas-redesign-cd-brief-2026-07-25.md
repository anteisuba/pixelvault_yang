## 事实与状态矩阵

- **核心用户**：做长视频/系列镜头的创作者；画布是"第二次以上"的场所（Studio 才是单次入口）。
- **核心对象（本切片）**：**生成聚合体 = 视频生成节点**（代码名 `seedance`）。它是画布上唯一真正"下单"的对象。
- **最高频任务**：一组素材（角色出场图组 + 场景 + 静帧 + 音色 + 参考视频 + 镜头文本）汇入一个视频生成节点 → 写提示词 → 生成。
- **默认入口**：画布上选中该节点 → 卡上紧凑态 composer；`⤢` 展开 → 详情态 composer（今天已有 `density: 'card' | 'detail'` 两档，**保留这个两档，别合成一个**）。
- **输入 → 处理 → 结果**：上游边收割成分 → 装配 payload（去重 + 截断到上限）→ `@token` 翻译 + 图例注入 → provider 生成 → 结果视频落在卡上并可进 Assets / 加入成片。

## 已确认结构契约（逐条来自 §7.1，不得概括）

1. 主结构 = **自由无限画布**（Figma 式平移/缩放/框选保留）；不做强制分带、不做行表主视图。
2. 生成聚合体 = **组装台大卡**：三条槽轨（image ≤9 / audio ≤3 / video ≤3 且合计 ≤15s）+ prompt 面 + 结果监视，**真实上限可见**。
3. 关系 = **常显连线 + 类型色 handle**；治乱靠分区/成组/便签，**不靠"关系线总开关"隐藏**；槽轨只表达"袋型合同装了什么"，不取代连线。
4. **吞噬（拖卡入腹 + 吸入三拍 + 快投 + 磁吸）正式退役**；拖到槽轨 = 建边 + 槽位落定。成分**永不消失**，原卡留在画布上。
5. 一致性单位 = **常驻班底架**（角色/场景/音色注册表 + `@` 引用），从底部横匣升为第二主角。
6. 序列 = **第二视图（序列模式）**；画布内只留"加入成片"入口与暂存。
7. 工具栏 = **左侧竖 rail**（工具 / 添加 / 视图切换），底部腾空；助手 = 右侧可收起 dock（延续现状形态）。
8. 本轮新建能力仅两件：**画布级粘贴**、**批量推进（真实队列）**，批量长成**画布上的对象** + **网格审核区**。
