🐞 顺手修掉的一个真 bug（你在日文版发现的「图标跃出」）
根因：助手 FAB 是 absolute 定位，而它的包含块 .rail 在收起态宽度是 0，于是 width:auto 的 shrink-to-fit 可用宽度也是 0 —— 内容被压到最窄，逐字换行。
中文「助手」两字压成两行，看着像刻意的竖排（台账 G1 一度就是这么记的）；日文「アシスタント」六字才暴露成明显溢出：内容需要 67px 高，而容器固定 40px。
修法：加 whitespace-nowrap。真机实测 62×40（溢出 67）→ 122×40（内容 38，零溢出）。
