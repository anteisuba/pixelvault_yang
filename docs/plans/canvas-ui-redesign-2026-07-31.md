## 2 · 两份基准文档的要点（owner 指定参考）

**[`UI丝滑交互与动效库选型`](research/UI与设计/UI丝滑交互与动效库选型-2026-07.md)**
丝滑 = **跟手 + 惯性 + 物理衰减**，不是多加 fade。工作台必须「丝滑但精确」——**旋钮/滑条禁止松手惯性**。面板/浮层统一 150–250ms。只动 `transform`/`opacity`。**app 内部只用 motion，GSAP 是首页营销域专属。**

**[`响应式设计优秀实践调研`](research/UI与设计/响应式设计优秀实践调研-2026-07.md)** + [`UI首页画布与全局策略`](research/UI与设计/UI首页画布与全局策略-2026-07.md)
布局模式表 compact(<768) / cozy(768–1023) / comfortable(1024–1439) / wide(≥1440)。**768–1023 平板是当前最丑的区间**。壳色向 owner 已拍 **A′ 浅壳浅台**。

## 4 · liblib.tv 画布拆解（owner 指定调研，实站实看 + 截图）

> owner：「我除了颜色以外都想学习」。实看的是 owner 自己的账号，**只读未改**。

### 4.1 组织思想

**不是「节点编辑器 + 聊天侧栏」，是「生产线 + 运行日志」。** 三个动作撑起来：

**① 命名法是产品功能，不是用户习惯。** 50 个元素全长成 `A2-娅娅偶像舞台服锚点v3` —— **族前缀 + 语义名 + 版本后缀**（A=角色/服装、B=场景、C=道具）。这一条同时解决扁平列表分组、搜索可命中、**助手能精确指代**三件事。助手正文写的是「娅娅（#1面参 + #3服装）」「舞台空场景 (i-ce4fusxq54q9)」——**编号槽位、元素名、助手正文用同一套命名空间**。

**② 助手面板是生产日志，产物住在里面。**（详见 §4.2）

**③ 画布只放媒体，控件是浮层，端口即「加下一个」。** 卡就是媒体 + 上方一行极小字标题（带 ▶ 折叠三角）；选中后浮出**带文字 + 下拉**的能力货架（裁剪/高清/解析/智能去字幕▾/音频分离▾/画面编辑▾）；卡左右的 ⊕ 既是连线端点也是「从这里长出下一个节点」，省掉拖端口这个高难手势。

### 4.2 ⭐ owner 唯一采纳的：助手面板 = 生产日志

自上而下五种块交替：

| 块             | 形态                                                                                      | 解决什么                                    |
| -------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------- |
| 结构化正文     | 步骤勾 `☑ 参考视频分析完成` · 带图标小节头 · 实体行（**粗体名 + `mono id` + 描述 + ✅**） | 助手只出 Markdown 散文                      |
| 结果分组头     | `视频已生成 ×3 ›` 可折叠 + 计数                                                           | 一批产物折叠成一行，不刷屏                  |
| 媒体结果卡     | 叠图 + `+2` 角标；音频是波形卡 + `2s` 时长角标                                            | 不离开对话就能看见产出什么                  |
| **生成中骨架** | **与结果同尺寸**的占位                                                                    | **结果落地时布局一个像素都不跳**            |
| 思考中 + 停止  | 转圈 + 标签；输入框右下是**黑色实心 STOP 方块**                                           | 「还没结束」≠「什么都没有」；取消是一等公民 |

已并入 v1 原型（顶栏有「让结果落地」按钮可演示骨架→结果）。

### 4.3 明确**不**学的三条

1. **顶栏商业 chrome**（限时40折 / 会员中心 / 积分）—— 我们没这个业务压力，学了就是白占顶栏。
2. **低缩放不降级标题** —— 他们 50 节点还行；我们要往「一句话铺满画布」走，迟早糊。
3. **至暗背景** —— owner 已排除颜色；且我们画布已反转成浅色。

### 4.4 与我们现有缺口的对应

- 左栏 `画布` / `资产` **双 tab** —— 正是 **G1**（参考图接不到素材库）的解法：素材库不是另一个页面，是画布左栏第二个 tab
- 同尺寸骨架 + STOP —— 正是 **G4 / §5.5**（进度·取消·失败态都看不见）
- 结构化命名 —— 正是画布线四条修订之②「名字升一等公民」；**包 4.5 已做了数据层的收口，但「名字有结构」这一层还没做**
