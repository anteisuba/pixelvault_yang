## 2. 黑 / 白：规则到底有没有锁死黑色？

### 2.1 权力顺序（现行）

```text
1. brand-dna.md          ← 全局：不规定深/浅，不规定炭墨/暖纸
2. forbidden.md UI       ← 不禁止白底；禁的是未确认就整页实现、继承旧皮
3. 已确认 page 文档      ← 只约束该页/该域
4. active plan / research ← 建议，非全局法
5. archive/*             ← 证据，禁止当现行规则
```

### 2.2 各文档实际说了什么

| 文档                 | 底色立场                                  | 是否约束「你做白色」                                    |
| -------------------- | ----------------------------------------- | ------------------------------------------------------- |
| **brand-dna**        | **明确不规定**全站深/浅、炭墨、暖纸       | **不挡白**                                              |
| **forbidden UI**     | 无「必须黑/禁白」                         | **不挡白**                                              |
| **home.md §A**       | **纯白底 + 黑字**（营销首页）             | 首页**要求白**                                          |
| **assistant-shell**  | 画布助手表面 **白** `#FFFFFF`             | 助手壳走浅                                              |
| **canvas-skin-spec** | 浅色中性灰阶为主；可选 `data-scheme=dark` | **鼓励浅卡/浅壳语言**                                   |
| **canvas-workbench** | 舞台 **冷石墨深** `#101114` + 钨丝琥珀    | 约束**未来画布重设计 A**，非全站                        |
| **node-canvas**      | 暖炭桌 + 纸卡                             | **现行实现描述**；文首写明**不得**当地改版依据/外溢全站 |
| **archive/design/**  | 奶油纸/炭墨「工作手记」                   | **已归档废止**（2026-07-19）                            |
| **UI 策略 research** | 反「纯黑 AI 默认」；壳浅或中性深          | 支持你离开纯黑 slop                                     |

### 2.3 冲突地图（你感觉「文档要我黑」时实际发生了什么）

```text
你想：应用壳 / 工作台偏白
        │
        ├─ brand-dna        → ✅ 允许（域自定）
        ├─ home             → ✅ 已是白（营销）
        ├─ skin-spec        → ✅ 浅色语言
        ├─ workbench        → ⚠ 选了深舞台（仅画布未来皮 A）
        ├─ node-canvas      → ⚠ 描述现状暖炭（实现可能仍深）
        └─ archive 暖纸炭墨 → ❌ 已废，读到等于读坟
```

| 若目标         | 正确读法                                                                             | 错误读法                    |
| -------------- | ------------------------------------------------------------------------------------ | --------------------------- |
| **全站壳变白** | 新开「应用壳」域/页设计，按 ui-page 确认；**不违反** brand-dna                       | 拿 node-canvas 炭桌当全站法 |
| **画布也变白** | 与 canvas-workbench「冷石墨」**冲突**——需 owner **改选/修订 workbench** 或新关键切片 | 偷偷改 token 不改文档       |
| **只首页白**   | 已有 home.md，其它域可继续深                                                         | 无冲突                      |

**结论：**

- 「文档约束成黑色」→ **全局规则层面不成立**。
- 局部成立的是：**(a)** 当前画布代码/旧施工图偏深；**(b)** workbench 拍板过深舞台。
- 要白画布 = **产品设计改拍**，不是偷偷违反 forbidden。

## 5. 是否应该清理？怎么清？

### 5.1 原则

| 做                                          | 不做                                                  |
| ------------------------------------------- | ----------------------------------------------------- |
| **标状态**（现行 / 实现事实 / 历史 / 废止） | 无差别 `rm -rf docs/plans`                            |
| **完成的 active plan → archive/plans**      | 删 research 证据                                      |
| **双重答案合并或拆「现行一节」**            | 用文首一句「已废」盖 200 行冲突正文（forbidden 禁止） |
| **代码变了回写 page/status**                | 只改代码不改文档                                      |
| **archive 保留**                            | 把 archive 链进默认施工必读                           |
