E1

视频没有多结果路径 —— generate() 里视频那支直接 generateVideo()，恒 mode:'single'。图片的「对照台」在这里没有对象。

use-unified-generate.ts:1336 / :618

E2

视频的时长 / 分辨率 / 反向提示词全在居中对话框里，当前值不点开看不见；图片同类参数已经常驻左栏。

StudioDockPanelArea → StudioVideoParams

E3

档位按模型实算，不支持就整栏不渲染（契约 R3）。所以视频参数栏的栏位数量会随模型变化 —— 布局必须能承受这件事。

getVideoModelParameterOptions()

E4

「图片用途」决定发哪个端点，却和「参考图」「比例」并排当第三颗丸，视觉权重一样重。

StudioToolbarPanels.tsx:63

E5

首尾帧从未实现 —— 全仓没有 lastFrame / endFrame 字段。三档只有关键帧 / 图像参考 / 多模态参考。⚠ 别画一个能点的尾帧槽。

全仓 grep 零命中

E6

剧本线整条已建成：主题 → AI 写分镜 → 确认 → 编排器逐场景出首帧再出片段，六个状态齐全。入口只有工具条上一颗丸。

useSceneOrchestrator · VideoScriptSceneStatus

E7

「音乐」这一档可选，但零消费者 —— 切过去显示的是语音那排（音色 / 克隆 / 音频转脚本），对音乐全无意义。

grep AUDIO_KIND.MUSIC 在 components/hooks/lib 命中 0

E8

音乐时长后端通了、前端没门：适配器读 durationSeconds（3–600 秒），而只有音效那支传它 —— 音乐永远是 30 秒默认值。

04

域定义 —— 三条要 owner 一句话

选完才画关键切片
D1 · 外壳同构到什么程度

「左参数栏 + 右舞台」照搬，只换栏位内容？还是允许视频 / 音频各长各的？三个方向里各有一个是同构版、两个是不同构版。

D2 · 这一轮接不接剧本线

已建成但只有一颗丸的入口。接 = 视频方向 C；不接 = A / B 里它继续当一个弹层。这条决定视频改动量是一倍还是三倍。

D3 · 音频三档怎么摆

语音 / 音效 / 音乐参数几乎不重叠。一个工作台三套参数（切档换栏），还是把音乐先关掉？E7 / E8 说明它今天是半成品。
