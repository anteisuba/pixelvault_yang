方向 E静默D「钉幕」的减法版 —— 骨架 / 契约 / 已过合规项一条不动，只做减法（探索产物，非可合入代码）

论点：结构契约是给代码看的，不是给用户看的。七个槽还在、Tab 序还在（DOM 序 2→3→4→5→6→7）、 钉·钉·滚·钉还在——但屏幕上不再出现任何一个槽标题。槽由承载物表达：媒体独占一块无装饰矩形（宽由宽高比推导、居中，空余宽度不画表面）、 素材架收成一行两个文字按钮、参数收成一条规格摘要串 1080P · 5 秒 · 16:9 ▾、关系收成一行 chip、证据收成一行「名词 (N 项) ▾」。 全屏唯一实心元素是动作坞的主动作。

这一版减了什么（R1–R12 逐条）· 三条无先例的决定 · D 的四个 bug 修复（点击展开）
R1 删掉全部 7 个可见槽标题（「主体台」「素材架」「编排台」「关系带 · 下游」「证据抽屉 · 对下游的身份包」…全没了）。 R2 空媒体窗删棋盘格 / 四角取景框 /「生成后在此预览」，只剩同尺寸矩形里一枚极淡模态字形（图=山形 / 视频=▷ / 音频=波形）。 R3 角色族素材架整栏不渲染（那句「本族关闭…」解释文案删除）；浮层里 480P 在不支持的模型下留原位变哑。 R4 「暂无引用 · 画布连线后出现」「还没有参考图——添加一张…」等预埋提示全删；只有阻塞主动作的那一条在动作坞发声。 R5 参考图每项常驻控件 2 颗 → 1 颗（断开常显；查看=点缩略图，带 tooltip）。 R6 fish_audio、模式名、「素材已生成」等派生/只读值脱掉控件壳，降为灰标签+亮值纯文本。
R7 一栏内只剩两类排法：短值=标签左值右一行；长文本=整宽无标签无边框白块（prompt 不再有「生成提示词」标签行——D 的排法冲突自动消失）。 R8 参数按钮=规格摘要串：值用 · 串、契约顺序、无字段名、一行、末尾 ▾；空态回落「编辑参数 ▾」；成本贴主按钮左边同行。 R9 四个真实模型契约（Seedance / MiniMax H3 / Kling V3 / Veo 3.1），切模型后参数串与浮层字段真的跟着变：MiniMax 没有分辨率字段（整字段消失），Seedance 的 480P 变哑（项级留位）。 R10 同层同形：文字按钮一层、chip 一层、白块一层；全屏唯一实心=「生成」。 R11 媒体井宽=高×宽高比、居中，右侧空余不画托盘（角色族 890 宽托盘删除）。 R12 层间距 30px : 层内距 10px = 3:1。 结构改动：「AI 生成」按钮删除，提示词/模型/参数/参考图归位编排台；素材库 / Studio 降为两个文字按钮（不能删——唯一落图入口 / 唯一 Studio 往返起点）；新增散图（图片）族。
三条无先例的决定： ① 生成期＝「保留几何 + 呼吸字形 + 章」——井的尺寸一像素不动，极淡字形做 2.4s 呼吸（唯一动效载体之二），右上角「生成中」章带脉冲点；无百分比、无取消、无进度条（D 的不定式条一并移除）。 ② 参考图控件常显但只剩一颗：断开永远可见在方块下行右侧，名字在左，序号不再单占一角。 ③ 浅底分层不取反明度：白纸（S0）浮起靠「更亮一档 + 极淡投影」，井（S2）沉下靠「更暗一档、零边框」——边界由表面级差（≥1.05/级）+ 投影表达，不再新增任何描边框。 修 D 的四个 bug：弹窗示例卡 .art 改块级（图画得出来了）· 运镜插词按句读智能拼接（不再出「。，」）· 弹窗遮罩改浅 rgba(226,230,235,.78) · 不定式条移除（1.32:1 连根消失）。
