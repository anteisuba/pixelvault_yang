## 粘贴稿（自包含，直接复制进 Claude Design）

```text
你在为一个 AI 创作工作台的「画布（导演台）」做一个已定稿组件的视觉呈现与动效设计。

【本轮性质 —— 先读这段】
结构、信息层级、配色数值、字号、间距、动效时长全部已经定好，写在下面。你这一轮不要重新设计结构，不要改配色数值，不要重排信息层级。
你要做的只有两件事：
1. 把这套已定的结构做成真正精美、有品质感的界面；
2. 设计它的动效——这是本轮最重要的交付物。
如果你觉得某处结构有问题，写在最后的备注里，不要直接改。

【产品语境】
个人 AI 创作工作台里的「画布」是长视频导演台：在一张自由无限画布上把「剧本 → 分镜 → 逐镜生成 → 拼接成片」编排出来。面向「第二次以上」的创作——同一个角色跨多个镜头长得一样、声音一样，最后拼成一条完整的片子。

【要做的组件：视频组装台】
画布上唯一真正「下单」的对象。把一组素材汇进来 + 写一条提示词 → 生成一段视频。
它必须让人一眼看清四件事：这次会送出去什么、还差什么、上限还剩多少、下一步点哪。

【已锁定的骨架 —— 照做，不要改】

外壳规则（画布上所有卡共用）：
- 卡名在卡「外」上方，不在卡内：15px/24px/600，前置一个族图标，与卡顶间距 4px，左对齐卡左缘。
- 卡内是纯媒体，padding: 0。卡 = 媒体本身。
- 组装台是唯一例外：媒体窗下面接一段控制区。
- 端口在卡左右缘垂直居中，用形状+低饱和色双编码：图=实心方 / 音=实心圆 / 视=空心方 / 身份=圆环。
- 每个对象最多一个主动作，按状态改写。不要并列多个按钮。

组装台自身，自上而下：
1. 任务模式 tab 一排（当前模型可选的模式，见下）
2. 槽轨区（结构由当前模式决定）
3. 提示词面（支持 @名字 引用素材）
4. 参数摘要 chip（形如「16:9 / 12s / 720p ⌄」，点开是浮层，不是常驻表单）
5. 结果监视区
6. 唯一主动作

两档密度：
- 紧凑态（卡摊在画布上没展开时）：三行 = 模型名 / 容量条 / 参数摘要 chip。容量条形如「6/9 图 · 1/3 音 · 0/3 视」，数字用 tabular-nums。
- 展开态：卡「原地长大」，不是弹出另一个面板。上游连线与上游卡必须始终可见——展开时靠自动平移画布来避让，绝不遮住自己的入边。

【已锁定的信息设计】

任务模式（tab 集合由当前模型决定，不是固定五个）：
- 文生视频 → 无槽轨
- 图生视频 → 1 个图槽（首帧）
- 全能参考 → 三条槽轨：图 ≤9 / 音 ≤3 / 视 ≤3
- 参考生视频 → 图 N 张（无音槽无视槽）
模型与模式的关系：Seedance 支持 文生/图生/全能参考；Kling 与 HappyHorse 支持 文生/图生；Gemini Omni Flash 支持 文生/参考生视频。
切到不支持当前模式的模型时，模式沿「全能参考 → 参考生视频 → 图生视频 → 文生视频」降级一档，并标一次说明。

槽轨与素材：
- 每个已装入的素材缩略图右上角有一个数字角标 = 它的发送序号，也就是提示词里 @Image1 的那个 1。
- 只有提示词里被 @ 提到的素材才会发送。已连线但没被提到的，标灰 + 「未被提及」，不要让它消失。
- 超出上限的，标灰 + 「不会发送」，同样不消失。
- 当前模式不支持的槽（比如图生视频下的音槽），保留在原位打禁用标记，并且必须给一句原因——只打禁用不给原因是不合格的。

主动作四态：缺必填→「补素材」（不是置灰的生成钮）/ 就绪→「生成」/ 生成中→「生成中」（不确定态，没有百分比，也没有取消——后端没有这两个能力，不许画）/ 失败→「重试」。

【已锁定的视觉数值 —— 逐条照用，不要调】

画布底 #F1F1F1，点阵 radial-gradient 圆点 rgba(200,200,200,.447) 半径 1px，间距 48px。
卡背 #FFFFFF，圆角 8px，静态无投影，只有 1px rgba(0,0,0,0.08) 发丝边；hover 才升起 0 4px 24px rgba(0,0,0,0.08)。
文字四档：#0A0A0A 卡名与主数值 / #525252 正文与图标 / #737373 次级说明 / #8F8F8F 单位与辅助。
描边：装饰边 rgba(0,0,0,0.08)；次级按钮边 rgba(0,0,0,0.15)；焦点环 2px #737373。
控件填充 rgba(0,0,0,0.04)，hover rgba(0,0,0,0.06)。
分段控件（tab、画幅选择这类）：槽底 rgba(0,0,0,0.04) + 1px 边 + 圆角 8px + 内边距 3px；选中块纯白 + 圆角 6px + 0 1px 2px rgba(0,0,0,0.08)。
主动作：#0A0A0A 实底 + #FFFFFF 字，hover #262626。这是画面上唯一的实底重色。
唯一强调色 #2B5CE6，**只用于「选中 / 活跃」**（选中环、焦点、当前对象标记），绝不用于主动作按钮。
状态色只在徽章尺寸出现，不做面积填充：成功 #16794C / 警告 #8A5A00 / 危险 #C0342E。
连线：已建立 = #8A8A8A 3px 实线圆头；未就绪 = #A3A3A3 1.5px 虚线 6,5 且 opacity .6；选中时叠一条沿路径跑的亮点，靠明度不靠色相。
浮层（参数浮层）：#FFFFFF，圆角 14px，1px rgba(0,0,0,0.08) 边，投影 0 4px 12px rgba(0,0,0,0.04), 0 8px 24px rgba(0,0,0,0.06)，内距 16px，分组间距 20px。
玻璃容器（左侧面板、底部工具条）：白 80–85% + backdrop-blur(20–35px) + 1px rgba(0,0,0,0.08) + 柔投影。
字号只有三级：14px/1.6 正文 · 15px/1.6/600 卡名 · 12px/1.35 用量与单位。所有数字 tabular-nums。
间距台阶只允许 4 / 8 / 12 / 16 / 24 / 32。控件高度：紧凑 28 / 常规 32 / 主动作 36。
深色档：画布底 #0A0A0A，卡背 #171717，文字 #FAFAFA / #D4D4D4 / #A1A1A1 / #8A8A8A，强调 #6E9BFF，主动作反相成浅底深字。深色不是浅色反相——卡背要比底亮，投影靠加深不靠发光。

【本轮头等交付物：动效】
时长只有三档：150ms（hover、状态标）· 250ms（浮层出入、选中）· 420ms（面板展开）。
曲线：进入与弹出用 cubic-bezier(.22, 1, .36, 1)；状态过渡用 cubic-bezier(.4, 0, .2, 1)。
请为下面每一条给出具体动效方案（哪些属性动、时长、曲线、是否有交错），并说明它在传达什么：
1. 切任务模式 → 槽轨结构变形：槽位增减、失效槽变成禁用态。这是本轮最重要的一段动效，因为它是「模型能力变了」的唯一视觉证据。
2. 卡从紧凑态原地长大成展开态，同时画布自动平移避让，保证入边不被遮住。
3. 一个素材沿连线从上游卡「落位」到槽轨（注意：这不是把上游卡吃掉，上游卡原地不动）。
4. 容量数字变化（6/9 → 7/9），以及有效上限被压低时（9 → 6）的表达。
5. 生成中的不确定态——没有百分比，要让人相信它在动而且不焦虑。
6. 出片：结果视频落进监视区。
7. 失败：错误浮现，且必须传达「你的成分一件都没丢」。
8. 满载时第 10 张被拒绝的那一下——要让人明白是被拒绝，不是丢失。
9. 选中一张卡时，它的连线与上游卡的呼应。
10. prefers-reduced-motion 下每条怎么降级（全部降到 0 并保留终态）。

【本轮真实内容 —— 必须用这份，不许 Lorem 不许 Character A】
项目《霜降的信》，6 镜，风格「冷调胶片，手持轻微晃动」。
班底：角色「林皎」（出场组 3 张：旧邮局门口中景 / 侧脸特写 / 全身雨衣；音色：林皎 · 参考音频 8s）；角色「老周」（出场组 1 张：柜台后半身；音色：老周）；场景「旧邮局 · 黄昏」（1 张）。
要画的是镜 3：林皎把信推过柜台，老周迟疑地没有立刻接。
成分 = 林皎 3 张 + 老周 1 张 + 场景 1 张 + 镜3静帧 1 张 = 6/9 图；音色林皎 = 1/3 音；参考视频 0/3。
提示词原文：@林皎 把信推过柜台，@老周 迟疑地停在半空没有立刻接。参考 @旧邮局 · 黄昏 的光线，手持轻微晃动，冷调胶片。

【必须交付的画面（缺一格算没做完）】
1. 紧凑态（卡摊在画布上）
2. 展开态 · 全能参考模式 · 典型装配（6/9 图、1/3 音）
3. 展开态 · 图生视频模式（槽轨塌成 1 个图槽，音槽视槽禁用+原因）
4. 展开态 · Gemini Omni Flash（参考生视频模式；时长控件整条消失并写明「模型自行决定 3–10 秒」；分辨率变成只读 720p；画幅只剩 16:9 / 9:16）
5. 缺素材
6. 满载 9/9 + 第 10 张被拒
7. 生成中
8. 失败
9. 已出片 + 「加入成片」入口
10. 一张上下文图：这张卡落在完整画布骨架里——顶栏（项目名 + 画布/序列切换）、左侧合体玻璃面板（56px 图标轨 + 240px 班底架）、底部中间玻璃胶囊（选择·手 / 缩放 / 适应 / 撤销重做）、右侧可收起助手 dock、周围有 2–3 张邻居卡（角色卡、场景卡、音色卡）与常显连线。
浅色与深色两版都要。

【禁区】
- 不要重新设计结构或改上面给的任何数值。
```
