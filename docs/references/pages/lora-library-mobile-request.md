# UI 需求卡 · LoRA Library 移动端（2026-09-03 owner 拍板）

> 上游：[`lora-library.md`](lora-library.md) §5 移动端章节记录了本卡对应的拍板结论；本卡是该结论的 `ui-request.md` 落卡版，供实现会话直接开工。默认值按 [`../ui-defaults.md`](../ui-defaults.md)（字体/颜色/动效/移动端配方/8 项完成定义）。

## UI 需求卡

1. 页面 / 域： `/studio/lora`（Library 模式）· LoRA，`<1024`（`useIsMobile`）。桌面 `≥1024` 不变（R1 单列宽幅 + 原位展开）。
2. 用户来这里完成的一件事： 手机上翻看 LoRA 封面图挑一个 → 打开看效果样例/触发词判断能不能用 → 一键挂载去生成。
3. 改什么（范围）： Library 结果区（列表→2 列封面网格）、卡片点击后的详情呈现（原位展开→底部抽屉）、筛选/排序控件（顶部散列→单行 chip + 底部 sheet）、分页（结果流末尾→悬浮胶囊）。收敛落点为 `LoraLibraryCard`，供日后与 `LoraLibraryModal` picker 统一，但本轮不动 picker。
4. 状态矩阵： 空（无结果，含空搜索）· 加载（首屏骨架、翻页骨架）· 有内容 · 错误（列表拉取失败、详情拉取失败）· 选中（抽屉打开态、筛选 sheet 打开态）。禁用态不适用（本域移动端不做训练创建入口）。
5. 375px 结构（完整，非降级）：

   | 区块         | 375px 呈现                                                                                                                                                    |
   | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | 顶部模式导航 | Generate / Library / Train 保留，横向紧凑 tab                                                                                                                 |
   | 筛选行       | 单行 3 个 chip：`来源 ▾` `排序 ▾` `筛选 ●N`；替代桌面散列的公开/我的/来源/排序/安全/刷新                                                                      |
   | 结果区       | 2 列封面卡网格（`gap-2`，640px 起 3 列），封面 3:4，取列表 payload 的 `cardImageUrl`（Civitai）/ showcase 封面（HF）                                          |
   | 卡片内容     | 封面上叠 来源 chip + 底模 chip；封面下方 名称（2 行 clamp）、紧凑 `↓` 下载数 / `♥` 收藏数                                                                     |
   | 卡片点击     | 打开底部抽屉（vaul，~92% 高），不做原位展开                                                                                                                   |
   | 分页         | 悬浮胶囊 `‹ 1 / 12 ›`，sticky 于安全区之上；页替换语义不变，本轮不做无限滚动                                                                                  |
   | 筛选 sheet   | 点任一 chip 打开底部 sheet（~60% 高），分区：来源 / 排序 / 类型 / 底模（可搜）/ 安全，footer `显示 N 条结果`                                                  |
   | 详情抽屉     | 样例轮播 → 标题+badges → 数据 → 触发词（+推断 pill，可复制）→ 底模/授权/安全 → description → 作者；sticky 底部动作栏 `使用此 LoRA`（主）/ `收藏` / `打开来源` |
   | 详情数据获取 | 仅在抽屉打开时经 `selectItem` 拉取（mined prompts、description），不在网格阶段预取                                                                            |
   | 关闭抽屉     | 回到打开前的网格滚动位置，不重置筛选/分页                                                                                                                     |

6. 交互动作表：

   | 触发                            | 即时反馈                                                       | 动效（按 ui-defaults §4）                                  | 结果                                                        |
   | ------------------------------- | -------------------------------------------------------------- | ---------------------------------------------------------- | ----------------------------------------------------------- |
   | 点封面卡                        | 卡片按压态 `active:scale-press`                                | vaul 抽屉上滑入场（内置，不自写 translateY）               | 打开详情抽屉，触发 `selectItem` 拉取详情                    |
   | 关闭抽屉（拖拽/遮罩/×）         | 拖拽跟手；松手回弹或关闭                                       | vaul 内置拖拽关闭                                          | 回到网格原滚动位置，不丢筛选/分页状态                       |
   | 点 `使用此 LoRA`                | 按钮 `loading` 态（Spinner 替换图标，宽度不跳）                | `duration-fast` 颜色/阴影过渡                              | 挂载该 LoRA，跳转 Generate                                  |
   | 点 `收藏`                       | 图标态切换 + 轻量 toast                                        | `transition-colors duration-fast`                          | 收藏状态写入，抽屉与网格卡同步高亮                          |
   | 点 `打开来源`                   | 新标签页打开外链，本页无视觉变化                               | 无                                                         | 跳转 Civitai/HF 来源页                                      |
   | 点筛选 chip（来源/排序/筛选）   | chip 按压态                                                    | 底部 sheet 滑入（`ResponsiveDialog`/`drawer.tsx` 内置）    | 打开对应 sheet，定位到对应分区                              |
   | sheet 内改选项                  | 选中态即时高亮（`selected` 态：强调色边+`aria-pressed`）       | `transition-[background-color,border-color] duration-fast` | 本地暂存，不立即刷新结果                                    |
   | 点 sheet footer `显示 N 条结果` | 按钮按压态                                                     | sheet 关闭动画（内置）                                     | 应用筛选/排序，网格刷新，回到第 1 页，chip 行 `●N` 数字更新 |
   | 点分页胶囊 `‹` / `›`            | 按钮按压态；到达边界时禁用（`opacity-50 pointer-events-none`） | 无（结果区骨架 → 内容走 `animate-in fade-in-0`）           | 替换当前页结果，滚动到结果区顶部                            |

7. 非目标： 不改 `LoraLibraryModal`（picker）；不改桌面 `≥1024` 布局；不做训练创建流程的移动端界面（该入口维持"请在桌面创建训练"提示，不在本卡范围内新建）；不做无限滚动；不碰 service/API 层。
8. 参考（可选）： Civitai 官方 App 的移动端封面网格（仅借"封面网格 + 点开详情"方法，不借视觉皮肤）。

## 备注

- 状态归属：筛选/排序状态仍归 library hooks 所有，sheet 只是移动端呈现层，不新增独立 state 源。
- 与 2026-08-07 排序/筛选分层拍板一致：sheet 内用分区标签（来源/排序/类型/底模/安全）呈现分层，不合并成一行混排。
