05 · 身份卡

一张卡，三个身份。

所以你怎么连它，都对，也都不对。

筛子
用来找
档案
有图、有声音
参考图
会送进模型

文档说：它不进提示词。代码说：连到视频就会被收割成图。左栏叫「卡片」。卡面长得像照片。

说法 3 槽架 / @

说法 4 顶上芯片
