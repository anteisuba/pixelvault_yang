# 3D 工作台

2026-09-09 owner 确认独立 `design-suite.html#three` 并授权实装；以本次确认解除旧域文档中 3D 页面优化的搁置状态。

## 职责与范围

从参考图或模型支持的文字输入创建 3D，预览、继续处理与导出已有结果。只调整 UI，不改变 provider 契约、价格常量、生成/轮询/存储路径。原型参数与形体是示意；正式页面必须保留真实模型选择、多视图、Mesh-first、材质续作及下载能力。

## 已确认结构

- 移除页面大标题与说明。桌面左侧窄设置栏，右侧大预览；设置内部滚动，底部费用与生成按钮始终可达。
- 模型卡整块可点击，打开现有真实模型/线路选择面板；选择后关闭并同步模型参数。输入模式、质量、格式采用全宽下拉框；参考图为紧凑虚线入口，高级设置为分隔线后的展开行。
- 默认展示模型、输入、质量与输出格式；几何、材质和细节参数按需展开，模型不支持的能力不显示。
- 图生 / 文生切换保留输入草稿；参考图替换、移除继续使用已有上传与素材选择器。
- 预览空态保留已确认的形体示意与顶部状态，底部浮动栏提供正面 / 侧面 / 复位。真实模型接入相机 orbit、target 和 field of view；复位恢复默认距离与中心，减少动态效果偏好下直接跳转。
- 预览、真实生成进度、失败原因/重试及已有模型入口都在结果区。费用摘要使用当前配置的既有估算，不重复展示冲突的固定单价。
- 手机/平板窄屏以预览为主，参数进入响应式抽屉；固定生成操作，复用同一份状态与控件。

## 视觉与共享边界

标志组件为实底设置栏、连续预览面、轻量结果工具。复用 ModelViewer、MainModelPicker、AssetSelectorDialog、QuickSetupDialog 与 ResponsiveDialog；不调整其他 Studio 页面。沿用全站字体和语义颜色，玻璃限预览浮动操作，表单保持实底。不将 3D 变成素材管理网格或长表单页面。

## 状态与验收

覆盖无输入、选择图、文生输入、多视图、高级参数、缺密钥内联配置、生成中/失败/成功与已有模型。桌面 1440、平板 820、手机 375，键盘、焦点、reduced-motion。定向测试验证输入切换、抽屉与生成门控，不调用付费生成验证视觉。
