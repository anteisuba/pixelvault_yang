## 0. 一句话任务

在**结构已确认**的 LoRA「装配台」上，出**冷瓷灰白**基调的高保真视觉方案（域级/页面级 token + 质感层 + 关键状态）。**结构不动，只做视觉。**

## 1. 产品与页面背景（自包含，冷启动可读）

- **PixelVault** 是个人 AI 创作工作台：生成图/视频/音频、永久归档、资产复用。
- **LoRA 域** 是双北极星之一，围绕两个动词：**还原**（把一张喜欢的效果图/来源配方重建成可继续调的生成状态）+ **定制**（锁住角色/风格身份，改可变层出新图）。
- **方向 B「装配台」**（owner 从 A/B/C 三方向选定）：**Generate 控制台是唯一常驻主场**——用户长住在出图台里；**Library（Civitai/HF/我的）与底模选择降级为从装配栏唤起的 modal**。主工作流：**当前装配 → 生成输入 → 出图 → 结果**。
- **现状**：页面功能骨架已实现、可真机运行（多 LoRA 混挂、配方面板、双源库、danbooru 引擎、runner 等）；本轮是把这些**重宿主进装配台**并换上冷瓷皮肤，**不是从零造功能**。

## 3. 锁死不可动（结构层，已 owner 确认，CD 只换皮）

**装配台三栏常驻**（进域第一屏 = Generate，不再默认落 Library）：

- **左·装配栏（常驻）**：底模卡（→ 换底模 modal）→ 竖向 LoRA 栈（每项：缩略 + 名 + 权重条 + 兼容点 + 启停 + ×；顶部「＋添加 LoRA」→ 分类库 modal）→ 触发词 chips → 参考图 → 参数 disclosure（收起显摘要 `尺寸·Steps·CFG·采样器`）。
- **中·创作面**：搭配提醒条（单行·点击原位展开）→ Prompt 主编辑面（主角，含 inline 补全）→ Negative（默认折叠）→ **出图键**（石墨中性，在此，只一次）。
- **右·结果监视**：大结果图 → mono 元信息（`尺寸·Steps·Seed·当前装配`）→ 本次会话缩略历史（>1 张才出现）。
- **助手** = 可收起右 dock；展开时结果监视让位挤入（不足则覆盖）。

**其他锁定**：Library/底模 = 唤起 modal（不做全屏 section）；分类横排检索；「我的」= 库 modal 的一个 tab；60/40 中右比例仅助手关闭态；模式导航「生成/库/训练」保留（属应用壳内）。

**状态矩阵**（CD 高保真需覆盖）：未挂载（纯底模也能出图）· 已挂载·助手关闭[主态] · 添加 LoRA modal 开 · 换底模 modal · 还原（配方 modal→做同款填装配栏）· 搭配提醒展开 · 助手停靠 · 不兼容（琥珀点 + 警示行 + 切建议底模）· loading / error / 空结果。

## 4. 三个标志性视觉组件（视觉重点落这三处）

1. **常驻装配栏** — 左一栏读完「这次挂什么」：底模卡 + 竖向 LoRA 栈（权重条 + 兼容点）+ 触发词 + 容量余量。控制台的脊柱；浮起纸面在这里最吃重（多挂载要一眼分得开）。
2. **分类唤起库 modal** — 「＋添加 LoRA」唤起的浮层：顶部 Civitai/HuggingFace/我的三 tab + 搜索 → **分类横排**（全部/人物/服装/表情/姿势/风格/概念/场景）+ 底模横排 → 双源**同卡**网格（封面 + 家族角标 + 源角标 + 使用/已挂）+ 真实分页；即筛即挂回装配栏。**发现折进主场**。低保真结构见本轮 chat 附图。
3. **数据感创作面** — 中央 Prompt 主编辑（mono 补全 + 搭配提醒）+ 右结果监视列（大图 + mono 元信息 + 会话缩略）。数值全 mono 是「工作台数据感」的来源。

### 4.1 换底模 modal（底模选择器）— 借 SeaArt 卡片网格，重解释为兼容·分组·带标

**触发**：点装配栏底模卡 → 唤起。**参考**：SeaArt 底模选择器（封面卡网格 + 版本选择器 + tabs + 搜索）——借形态，不照抄其自由市场。

**PixelVault 重解释（domain 硬事实，与 SeaArt 的关键不同，不可抹平）**：

1. **受挂载 LoRA 家族兼容约束**：只列/标 `getCompatibleBases(loraFamily)` 结果；默认「仅显示兼容当前挂载」开；不兼容底模隐藏或降档说明（SeaArt 是无约束自由网格）。
2. **两层分组**（现有 `SelectGroup` 逻辑升级为 modal 网格，见 `lora-workbench.md §4.4`）：① **云端 API · 自备 key**（`backend ≠ runner`）② **Runner · 平台免费额度**（`backend === runner`），Runner 内再按架构系分 **SDXL 系 / DiT 系**（数据来自 `LoraBaseModel.family`，`anima-dit` 归 DiT）。SeaArt 是扁平网格。
3. **每卡**：封面 + 名 + 家族·架构 + **忠实/快标**（fidelity，中性信息 chip，非状态色）+ 版本选择器（模型多版本）+ 可用性（Coming Soon 降档）+ **当前选中态**（石墨）。
4. **执行通道分层**：只有同一真实底模同时具备兼容的 fal 与 Runner 路径才显通道切换；**Anima DiT 只有 Runner → 显「Runner 唯一通道」静态标，不伪造 fal 下拉**。
5. **自动选**：挂载 LoRA 后自动选其推荐的兼容底模；本 modal 用于**改选**。

**托管已有件**：底模两层分组 Select（`lora-workbench.md §4.4`）→ modal 化；`getCompatibleBases` / `getDefaultBase` / `getRecommendedLoraImageModelId` / `LoraBaseModel.family` / fidelity 信号（`loraBaseModel`）。皮肤走冷瓷 + 石墨中性；忠实/快与版本是中性信息层，不占状态色。低保真结构见本轮 chat 附图。

> 与库 modal、来源配方 modal 一样，换底模 modal 共享 dialog 行为（键盘 / Esc / 遮罩 / 焦点管理 / 响应式），只追加各自真实动作；三者皮肤统一走冷瓷浮层。

### 4.2 已定关键状态结构（本轮 chat 附低保真图）

- **搭配提醒展开态**（中创作面）：单行状态条被「做同款 / 助手建议 / 挂载」触发 → **原位向下展开**成变更审阅卡（**非阻断 modal**）：将变更（Prompt `+新增词` / 参数 diff / 底模保持兼容）· 触发词（自动加入 · 删除有风险）· 保留项 · **应用[石墨] / 撤销**。托管 `LoraCollocationStatusBar`。
- **助手 dock 展开态**（桌面）：右侧展开 **~380px** 上下文边栏，工作三栏让位压窄（扣除后主台 <900px 则改覆盖，不继续挤）；助手读挂载 / 触发词 / 来源配方上下文，出**变更卡**（建议加词 / 调参）供手动应用 → 进搭配提醒，**不直接出图**；底部输入框。纯底模态不伪造 LoRA 上下文。托管 `LoraAssistantDock`。
- **移动端**：三栏收成**单列 + 底部常驻出图条**（底模 · LoRA 数 · 助手 · 出图）；装配栏 / 库 / 换底模 / 助手 全部改**从底部拉起的近全屏 sheet**（保主台状态；软键盘遵全局 `isTouchPrimary` 策略，不自动抢焦点）；主创作屏 = 装配摘要 chip 横排 + Prompt + 结果。桌面 60/40 与三栏不外推移动端。

## 5. CD 要探索的（高保真 / token 层）

1. **表面梯度具体值**：page（冷灰底）/ 面板（浮起白）/ 浮层（modal）/ 凹槽（参数 well）四级的精确值与相互关系 + 投影分量（极轻）。
2. **发丝线与边界**：冷灰 hairline 的精确值；克制容器语言。
3. **文本与数值层级**：石板墨字层级；**数值/参数 mono**（权重·Steps·CFG·Seed·容量）的排版与可读性。
4. **交互态**：hover / focus（焦点环）/ selected / disabled；**出图键（石墨中性）的视觉分量**；loading / error / empty。
5. **库 modal 的 NSFW 浅底处理（owner 2026-07-24 拍板：单一「安全模式」开关，替换两案）**：库 modal 顶部一个「安全模式」开关（沿用项目现有 NSFW gating）。安全模式**关** → 封面直接显示不模糊；安全模式**开** → 网格里 NSFW 封面**降档显示（模糊 + 压暗）+ 角标**，**详情（inspector）内可逐个揭示原图**。默认安全模式**开**（安全档，沿用 2026-07-06 默认 safe）。不做「模糊+确认 / 降档灰化」两个并排候选。
6. **密度与节奏**：控制台该有的紧凑但不拥挤；装配栏（密）与结果监视（疏）的节奏差。
7. **参照方法**：借鉴 Claude.ai / ChatGPT 产品工作台的任务聚焦、排版主导、克制容器、按需控件——**借方法，不复制品牌皮肤**（SeaArt/Liblib 同理只借布局）。

## 6. 红线（硬约束，违反即打回）

- **结构 / 内容 / 交互一个像素不动**——你改皮不改骨。
- **基调是冷瓷灰白浅色 UI，别滑回深炭 / 黑**（那是被 owner 明确否掉的旧线）。
- **石墨中性**：出图与主动作用高对比深石板，**别引花哨主色 / 高饱和强调**；彩色只留功能语义 + 效果图。
- 不 card/pill 无意义堆叠、不玻璃 / 发光 / 渐变装饰 chrome。
- 库 modal NSFW 浅底**必须 gating**，不裸露。
- 域级 token 严格 **`.domain-lora` 作用域**，不提升为全站默认、不改全局 `@theme` / 脊柱。
- 不复制 Claude.ai / SeaArt / Liblib 的品牌皮肤。

## 7. 提取项目脊柱（提 slot 不提皮肤）

- 读 codebase 提取的是**语义脊柱层**：`--background / --foreground / --card / --muted / --muted-foreground / --border / --input / --ring / --primary` 系 + 半径梯度。
- **不要**提取或套用：全站 `ui/` 组件默认皮肤、其它域（Canvas / Studio / Assets）的域级 token。
- 你产出的冷瓷质感是 **LoRA 域专属**，将来落成严格作用域在 `.domain-lora` 根的域/页 token（`src/app/lora.css`），**不外溢全站**。
