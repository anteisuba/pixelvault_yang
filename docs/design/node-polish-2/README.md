## 怎么对照

1. 出参考图：在仓库根目录运行 `node docs/design/node-polish-2/shoot.mjs <输出目录>`。每个状态出两张 1440 × 900 的图：`-after` 是设计真值，`-now` 是现状，一共 13 个状态、26 张。
2. 每片做完，在 owner 已开的 dev（3000）里用同一视口把同一状态截下来，和 `-after` 并排比。⛔ 另起 dev server。
3. 逐项列偏差：尺寸 / 间距（±1px）、圆角、颜色（只能是下表的 token）、字号字重、文案、动效时长与曲线。偏差清零才算这一片完成。清不了的写原因；⛔ 自行改设计，⛔ 新造 token 或写 Tailwind 任意值。
4. 参考图之间会有弹簧停稳带来的 1–2px 抖动：按量出来的尺寸比，⛔ 逐像素比。
5. 动效用原型控制条的「慢放 ×4」逐条对照下面的动效表。原型里的「现状」只用来对比，⛔ 照着做。

## 逐项

以下尺寸都是屏幕 px；卡名、虚线、选中环、端口这几样按屏幕算，要除以画布缩放。

**1 · 卡名**：字号 12、行高 16、底距 6、左右 3，`muted-foreground`，选中变 `foreground`；不换行，超出卡在屏上的宽度就截成省略号。放大也保持 12。

**2 · 卡面**

- **空卡**：透明底、没有影子，一圈 1.5 的 `foreground/24` 虚线，`rounded-node`。内容竖排、间距 10：先一句话（13，`muted-foreground`），再两颗字键。
  - 字键：高 28、左右 11、全圆角、`surface-fill-hover` 底（悬停 `surface-fill-track`）、字 12、图标 14、图标与字间距 5、两键间距 6。
  - 图片 / 视频：「上传 · 素材库」。视频那句话写「上传一段 · 或写这个镜头怎么拍」。
  - 音频：横排，间距 8，依次是「上传」「声音库」和「或写台词生成」（12，淡）。
  - 文本：两行，「双击开始写」（13）和「或让助手写一段」（12，淡）。
  - 拖文件进来时，虚线变实线、底色深一档。
- **视频首帧还没出来**：卡底 `surface-fill-hover`，中间一个 34 的圆（白 70%），里面是 ▶（`foreground/45`）；右下时长沿用现有样式。首帧到了 200 交叉淡入。
- **音频波形**：左右内距 16，间距 12；播放钮 34、时长 38 宽（12，等宽）。波形占满两者之间：柱宽 3、间距 2，柱数 = ⌊(可用宽 + 2) ÷ 5⌋；柱高 = 0.25–1 × 30，颜色 `muted-foreground/55`。
- **起名**：机器名在这一版生成完成时换成提示词前 12 个字；改过的、被 @ 着的不动。

**3 · 选中**

- **选中空卡**：没有工具条。没挂参考就没有参考轨。占位写这类卡的下一步：图片「描述这张图……」、视频「写下这个镜头怎么拍……」、音频「写台词，或上传一段声音……」。
- **提示词栏**：`card` 底、1px `border` 外圈加 `shadow-node-chrome`、`rounded-node`，内距上 12、右 8、下 8、左 14。宽度：图 / 视频 640、音频 420、文本 380，跟画布缩放 0.6–1（现有）。
  - 版本点：在栏上方，6 的点、间距 6，当前 `foreground`、其余 `surface-fill-track`。
  - 参考缩略：48、`rounded-node-thumb`、间距 8、下距 10；角标高 16、最小宽 16、`foreground` 底白字 10、偏移 −4 / −4。⛔ 缩略下写来源名，⛔ 轨末的「+」方块。
  - 正文：14 / 20，最少 40 高。
  - 键那一行：上距 8、间距 6。
    - 「+」：30 圆，`surface-fill`；悬停 `surface-fill-hover`，打开 `surface-fill-track`。
    - chip：高 28、左右 10、全圆角、`surface-fill`、字 12，值那一段 `muted-foreground`，箭头 12；悬停深一档，打开再深一档，箭头翻上。
    - 发送：30 圆，`primary`，图标 ↑ 16。
  - chip 顺序：参数 chip 在前、模型 chip 在后，紧挨发送。
- **安全区**（画布坐标）：左 = 图标列右缘 72（开着侧栏时 70 + 264 + 12 = 346），上 64，右 = 宽 − 16，下 = 高 − 76。右下绕开小地图（194 × 128，外加 12 的间隙）。工具条和提示词栏先按贴卡居中算好位置（现有偏移），再整体平移进安全区。卡整张出了安全区，两样一起收起。

**4 · 「+」菜单**

- 外形：宽 288、内距 6、`rounded-node-bar`、`popover` 底、1px `border` 外圈加 `shadow-node-menu`。
- 选项行：高 38、左右 10、圆角 10、字 13、图标 16、间距 10，快捷键写在右侧（10，等宽，淡）。
- 分节头：「画布上的」（11，`muted-foreground`，上 10、左右 10、下 6），右侧写「点一下就挂上」。
- 缩略网格：5 列 × 48、间距 6、左右 10、下 8。每格圆角 10、内圈 1px `border`；悬停外圈 2px `foreground`；已挂的右上角有 16 的 ✓ 角标。
- 位置：在「+」下方 8；放不下就翻到上方，再夹进安全区。从「+」的中心长出来。

**5 · chip 弹层（画面）**：宽 280、内距 12、`rounded-node-bar`。标签 11 `muted-foreground`。分段控件高 28，外框 `surface-fill` 底、内距 3、圆角 10；选中那格白底、影子 `0 1px 2px` 8%。选中一项后 160 收起，chip 上的字 120 淡入新值。

**6 · 模型弹层**

- 外形：宽 300、最高 392、`rounded-node-bar`、1px `border` 外圈加 `shadow-node-menu`。
- 搜索框：高 34、外距上 8 / 左右 8 / 下 4、圆角 10、`surface-fill`、字 13。
- 分组名：11，`muted-foreground`，内距 10 / 10 / 4。先是「最近」（最多 3 个，写全名），然后按系列分组，组里的行只写型号。
- 每行：最少 44 高、内距 5 / 10、圆角 10、悬停 `surface-fill`。型号 13 / 18；渠道与单价 11 / 15，`muted-foreground`。
  - 当前选中的行右侧打 ✓。
  - 多渠道的行右侧写「N 渠道 ›」（11）。
  - 缺 key 的行型号变淡，第二行写「缺 key · 点了去配置」，照样能点。
- 底栏：高 40，上方一道 `border`，「配置渠道与 key…」（12，带齿轮图标）。
- 位置：候选依次为 chip 下方、提示词栏右侧、左侧、卡下沿的右 / 左侧，最后才往上。每个候选先夹进安全区，再看会不会压到正在编辑的卡或提示词栏，压到就换下一个。chip 永远不空。

**7 · 定位与落点**

- 节点一览点一行：画布平移 320（`EASE_STANDARD`）。卡中心落到安全区中心，往下偏 30（纵向中心 = 顶 + (可用高 − 170) ÷ 2 + 30）。缩放不变；卡在屏上宽不到 160 就到 100%；放不下就缩到刚好（最高 100%）。停稳那一刻选中它。
- 打开项目：全部卡装进安全区（四周各留 100），最高 100%；空项目 100% 居中。

**8 · 打开态（一张纸）**

- 共同：压暗 `foreground/24`（进 200、出 240）；外壳（底栏、小地图、左上胶囊与图标列、右上剪辑台与助手头像）200 淡出。
- 纸：`card` 底、`border`、`rounded-node`、`shadow-node-card-expanded`，四周至少 48，居中。
- 纸顶：高 52、左 20 / 右 12。名字 15 / 600、字距 −0.01em；读数 12，等宽，`muted-foreground`；图标键 32 圆。
- 标题栏和底栏晚 120 进场、先退场。开合从卡的位置和大小长出来、缩回去，沿用现有 `useGrowFromOrigin`。
- **视频 / 图片画中框**：宽 = min(720, 视口宽 − 96)。正文区左右 20、间距 14，依次是：
  - 媒体区：视频 = 16:9 播放器，`rounded-node-bar`，transport 沿用现有；图片 = `surface-workbench` 底、`rounded-node-bar` 的区域，里面是原比例的图（`rounded-node-thumb`），图底压着版本点（白 55% / 白）。
  - 参考行：标签「参考」11 宽 34；缩略 44、`rounded-lg`、间距 8；末尾一颗虚线「+」，旁边写「拖进来或 ⌘V」（12，淡）。
  - 正文：上方一道 `border`，上距 14，14 / 22。
- **画中框页脚**：内距上 12 / 右 16 / 下 14 / 左 20，上方一道 `border`。左边「让助手写」（高 28、字 12）和读数（12，等宽，淡）；右边参数 chip、模型 chip、主键。主键高 30、全圆角、`primary`、字 12 / 500，带 ⌘↵ 提示。
- **文档**：纸宽 min(880, 视口宽 − 96)、高 = 视口 − 96、顶 48。纸顶下方一道 `border`；格式条居中，上距 12。正文列 680（正文与标题的字号沿用现有全屏文档）；写作栏在纸底、和正文同宽，下距 16。

**9 · 助手（布局 A，与图片 / 视频工作台同一套）**

- 头像：右上 16 / 16，36 圆，打开后留在原位。
- 面板：`card`、1px `border`、`rounded-node`，没有影子也没有毛玻璃。顶 66、底 18、右 18。宽 = 视口宽 × 0.3（最小 320，拖宽上限 0.45）。
- 画布：右边让出「面板宽 + 20 + 18」，右侧两个角变成 18 圆角并加 1px `border`；让出来的地方是 `surface-workbench`，⛔ 露出舞台底色。视口 x 补回一半。剪辑台胶囊跟着画布右上角走。
- 开合：画布与面板同一根弹簧（开 `LIQUID_SPRING.unfold`，收 `retract`）、同一刻起步，面板整块从右边滑进来，内容不分批。

| 时刻                   | 怎么动                                                                                          | 不要                         |
| ---------------------- | ----------------------------------------------------------------------------------------------- | ---------------------------- |
| 选中                   | 工具条、提示词栏从卡边中点长出来：0.72 → 1、模糊 4 → 0、淡入，`SPRING.slot`（现有）             | 从屏幕边滑进来               |

| 「+」/ chip / 模型弹层 | 从键上长出来：0.72 → 1、模糊 4 → 0、`SPRING.slot`；关 200 `EASE_IN`；键同时加深、箭头 200 翻上  | 普通下拉的 zoom-95           |

| 定位                   | 平移 320 `EASE_STANDARD`（改缩放也用同一条曲线），停稳才选中                                    | 先缩放再平移；飞到一半就选中 |

- 剪辑台。
- 角色卡原地展开：没核过。
- LoRA 页的助手：没核过。
