① ATTACH磁性主线 + 挂件

镜头排成一条主线，台词和字幕挂在镜头的某一帧上；配乐不挂，自己铺底。

你做的事挂件怎么走不要
拖的手感（沿用线上）播放头拖顶上的时间读数或在标尺上按住拖；镜头拖过 4px 才算拖，两端 10px 是裁剪区（没选中也能拖），上方出「入 / 出点 旧 → 新 · 长」；贴近段头段尾、播放头、台词、节拍 8px 就吸住并出一条竖线；拖的途中 Esc 放弃播放头只能点不能拖
拖镜头换位置挂着的台词、字幕一起走，和镜头同一根弹簧、同一刻落位挂件晚一拍才跟上
裁镜头开头挂件钉在镜头的那一帧上，跟着那一帧往前移；那一帧被裁掉了，挂件半透明留在原处，导出时不出声不出字自动删掉挂件
删镜头挂件一起删（owner 10-07 定）；顶栏回执写明带走了几条，⌘Z 一次全部回来悄悄留下对不上画面的台词
拖台词到别的镜头上就是换挂点：松手那一刻连接线跳到新镜头并亮一下另开「挂到…」菜单
重拍换版（时长变了）挂件按「离镜头开头多少秒」保持不动；新版更短时，挂件可以伸出到下一个镜头上，仍挂在原镜头按比例缩放挂件位置
台词「出字幕」开着每条台词自带一条同文字的字幕挂件，改台词字就改字幕；单独改过的字幕不再跟走语音识别
配乐不挂任何镜头，按时间线秒放；主线变短时，超出片尾的部分变暗，导出时淡出挂在第一个镜头上

② RETAKE就地重拍与版本

重拍走的就是来源节点那条生成链路，新版本写回节点；剪辑台只是多了一个入口。

状态台面上规则
点「重拍」这个镜头原来的提示词栏从它在时间线上的位置升起，停在预览下方模型、参考、参数都是节点那一份；缺 key 时按全站规则走内联配置
生成中段面压暗去色，钨丝色光带扫过；预览左上角写「第 2 版生成中」可以继续剪；同时可以有好几段在生成
落版自动换上，段闪一下，角标变成 2/2，后面的镜头磁性让位一次撤销退回旧版
失败段留在旧版，描一圈风险红，角上一个「!」；提示词栏里一行原因 + 重试原因用人话写：内容审核、超时、余额、key 失效
画布上出了新版角标旁亮一个点，不自动换（owner 10-07 定）点开版本弹层，新版那张也带同一个点
Claude 建议重拍段左下一枚「Claude 建议重拍」；选中后提示词栏里新加的字有底线，上面一行写理由Claude 经 MCP 只能改提示词、标记；按下重拍的永远是你
版本弹层点角标：各版缩略并排（借自 B），写时长和来源（画布 / 剪辑台），在用的那张描白框点哪张换哪张；失败的那次也列着，可以重试
续拍以最后一帧往下生成，新的一段插在它后面，画布上同时落一张卡并连线和画布卡上的「续拍」同一个动作

③ SEAM接缝与 AI 接镜

两段之间的 ◆ 是唯一的转场入口；弹层里三样，从便宜到贵排。

  • 预设转场：叠化、黑场、擦除、推移、缩放、圆形；悬停就在小格里预演，点了立刻生效，时长 0.3 / 0.5 / 1.0s。接缝上的 ◆ 实心 = 有转场，时间线上横跨接缝画一块淡光表示重叠的长度。不花钱。
  • AI 接镜：用前一段最后一帧和后一段第一帧生成一段过渡镜头插进去。模型只列能做首尾帧的（Seedance 2.0 火山 / BytePlus 渠道、Seedance 2.5）；默认沿用前一段的模型，不能做就落到 Seedance 2.5。按钮写明积分，钨丝色。
  • 生成中接镜段已经占好位（1.5s），后面磁性让位；段面左半是前段末帧、右半是后段首帧，光带扫过。
  • 落版：画布上落一张视频卡，放在前后两张镜头卡之间，连线指回它们（owner 10-07 定）；顶栏回执「接镜已落到画布」。失败：接镜段收回、主线合拢，回执写原因 + 重试。
  • 让 Claude 挑：Claude 看前后两帧，给出一个转场和一句理由；你点「用这个」才生效。它只在预设里挑，不会替你点 AI 接镜。

④ FOLLOW跟着看 Claude 剪

Claude 的改动一批批到达，台面把它们一步步放出来，像有人在旁边剪给你看。

  • 回放节奏：同一批改动按顺序一步一步放，每步约 0.6s：播放头滑到改动处（380ms），预览同一刻换到那一帧，被改的段闪一下；面板里同时多一行步骤，点「定位」可以再跳过去。
  • 你在操作时让路：你在拖、在打字、在播放、开着弹层时，播放头不跳、不自动播；改动照样生效，只有被改的段闪一下，面板那一行写「你在看片，没跳过去」。
  • 剪完从头放一遍：站内助手这一轮说完、或外部 Claude 4 秒没有新改动时，从头放；片子超过 60 秒就从第一处改动前 2 秒开始放。你按任何键就停。
  • 撤销：一批一个撤销（面板里「撤销这一批」或顶栏回执）；面板收着时用回执，开着时回执不重复出现。
  • 钱闸不变：Claude 能排、能裁、能换转场、能标记重拍，不能按生成。

⑤ OTHER全片条 · 空态 · 导出中 · 手机

四个小状态，在台面上点「⑤ 其他」那一排看。

  • 全片条（借自 B）：时间线默认铺满整宽，没有它；放大到装不下时，标尺上方淡入一条全片缩略，白框是你正在看的那一段，拖框或点哪里就去哪里。缩回铺满时淡出。
  • 空态：预览写「还没有镜头」，主线是一块虚线放置区「把画布上的视频卡拖进来」；Claude 面板第一句是「要我先按画布上的镜头排一版吗」，排版不花钱。
  • 导出中：顶栏时长那一格换成进度条 + 取消；台面照常能剪，改动不影响这一次导出。
  • 手机只看不剪，同样暗场：预览、镜头带（带版本角标）、Claude 的回执和段闪、导出进度与下载。
  • 回执浮在预览上方，「撤销」能点：撤销是把别人的改动退回去，不算剪辑。
  • 点镜头带上的一段 = 预览跳到那里，不弹任何编辑入口。

DATA数据与渲染要改什么

给施工看；台面上看不见，但每一条都决定上面的行为能不能做出来。

  • 台词、字幕改成挂件：现在两者存时间线上的绝对秒（startSec）。改成挂在主线镜头上：记住挂在哪段、离那段素材开头多少秒；配乐保留时间线秒。存量迁移：按原来的绝对秒找到当时盖住它的镜头挂上去，找不到就挂到最后一段。
  • 版本不新增数据：版本列表就是来源节点的产出版本；段上已有的 sourceVersionId 是「在用」的那一版。画布新版的小点 = 节点当前版本比段上的新，就是今天「上游已更新」的判据，只是不再自动去换。
  • 转场：词表从 无 / 叠化 / 黑场 扩到六种，加时长字段；渲染层 xfade 原生就有对应效果（fade、fadeblack、wipeleft、slideleft、zoomin、circleopen）。
  • 统一色调：每段存一个 3×4 色彩矩阵。预览用 SVG 颜色矩阵滤镜，导出用 ffmpeg 的 colorchannelmixer，两边是同一组数，所见即所得。
  • 配乐让位：渲染计划里按台词挂件的时间算出音量包络交给渲染层；踩点是一次性动作（一个撤销），节拍在浏览器里分析配乐得到，拖手柄时节拍也是吸附点。
  • AI 接镜：建一张视频卡，首尾帧槽连回前后两张镜头卡，按普通生成发出去；剪辑台只是在两段之间放一个指向它的段。
  • MCP 与站内助手：apply_ops 的剪辑类 op 跟着挂件形状改；新增「设转场」「标记重拍并改提示词」两条；生成类 op 照旧不开放。
