# Topaz Labs 能否接入画布图片/视频编辑（2026-07）

> 状态：**调研结论，非实现授权**。  
> 问题：Topaz 这套工具能不能用到 PixelVault **画布图片编辑**与**视频编辑/后处理**？  
> 判据：官方可集成路径 · 与本仓编辑能力重叠/补缺 · 成本与合规 · 与 Adobe 收购风险 · 实施切片。

---

## 0. 一句话结论

| 问                   | 答                                                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **能不能用到画布？** | **能，且产品契合度高**——Topaz 强项是「生成后最后一公里」：放大、去噪、锐化、脸部恢复、视频升 4K/插帧，不是文生图/文生视频本身。 |
| **怎么接？**         | **只走云 API（或 fal/Replicate 上的 Topaz 代理）**；不要嵌桌面 App / 本机 GPU 渲染进 SaaS。                                     |
| **现在立刻全量上？** | **不建议作为 P0。** 本仓图编辑已有 Aura-SR 等 upscale；视频后处理几乎空白——**视频侧价值更高，但贵、慢、异步长**。               |
| **推荐姿态**         | **T1 图片增强档（可选模型）→ T2 视频 clip 后处理（过审后可选）→ 不把 Topaz 当生成引擎。**                                       |
| **最大外部风险**     | Adobe 2026-06 宣布收购 Topaz（预计 2026 H2 交割）——API 条款/定价/可用性可能变；接入前要做合同与备用模型。                       |

## 1. Topaz 是什么（产品地图）

Topaz Labs（达拉斯）做 **AI 媒体增强（enhancement / restoration）**，不主打从零生成内容。2025–2026 产品线大致：

| 形态           | 代表                                                                                                             | 用途                             |
| -------------- | ---------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| **桌面**       | Topaz Photo / Video / Gigapixel；后收敛为 **Topaz Studio** 订阅                                                  | 本机 GPU 无限渲（视订阅）        |
| **Web 工具**   | Image Web、Astra、Bloom、在线 Video Upscale 等                                                                   | 浏览器云渲                       |
| **开发者 API** | [developer.topazlabs.com](https://developer.topazlabs.com/) · [topazlabs.com/api](https://www.topazlabs.com/api) | REST 异步任务，适合 SaaS 嵌入    |
| **第三方托管** | fal.ai `fal-ai/topaz/*`、Replicate `topazlabs/*`、Segmind 等                                                     | 用现有 fal 账本间接调 Topaz 权重 |

### 1.1 图像能力（API 文档族）

官方 Image Models 分类（[Introduction](https://developer.topazlabs.com/)）：

| 族                       | 能力                     | 画布语义                                   |
| ------------------------ | ------------------------ | ------------------------------------------ |
| **Gigapixel**            | 精度放大（高保真）       | 定妆/静帧导出 2×–16× 级放大                |
| **Wonder**               | 生成式放大（补细节）     | AI 图「看起来更清楚」                      |
| **Bloom**                | 创意放大（可改质感）     | 艺术向，可能改身份——慎用于角色定妆         |
| **Sharpen / Denoise**    | 锐化 / 去噪              | 生成噪点、压缩伤                           |
| **Removal & Cleanup**    | 修复、清理、部分 inpaint | 与本仓 inpaint/object-replace **部分重叠** |
| **Color & Lighting**     | 调色/光照                | 轻后期                                     |
| （应用叙事）Face recover | 脸部恢复                 | 角色近景极有用                             |

### 1.2 视频能力（API 文档族）

| 族                                | 能力                 | 画布语义                                           |
| --------------------------------- | -------------------- | -------------------------------------------------- |
| **Proteus**                       | 精度视频放大         | 成片导出前升 1080p/4K                              |
| **Starlight**                     | 生成式视频放大       | GenAI 视频（Seedance/Kling）拉到 4K 的主打叙事之一 |
| **Astra**                         | 创意视频放大         | 更「补细节」；参数可偏创造性                       |
| **Denoise / Frame Interpolation** | 去噪 / 插帧          | 慢动作、帧率拉高                                   |
| **Video Utilities**               | 压缩恢复、细节增强等 | 社媒再导出                                         |

**不是：** 分镜、口型导演、多镜叙事、角色身份编译——那些仍是 PV 自己的片场。

### 1.3 集成事实（一手 API）

来自 [Image API Quickstart](https://developer.topazlabs.com/getting-started/quickstart.md)：

- 鉴权：`X-API-KEY`（账户门户创建，**创建时只显示一次**）
- 图：`POST https://api.topazlabs.com/image/v1/enhance/async`（multipart：`model` + `image`）
- 轮询：`GET .../status/{process_id}` → `Completed` 后 `GET .../download/{process_id}` 取 URL
- 限制要点：HTTPS only；请求体 **≤500MB**；有负载相关 **429**，需退避
- 另有 Video API Quickstart / Credit Calculator / Playground

公开 API 定价页（[topazlabs.com/api](https://www.topazlabs.com/api)，抓取 2026-07）：

| 档         | 标价（页上）                               | 备注           |
| ---------- | ------------------------------------------ | -------------- |
| Starter    | $0/mo · **COMING SOON**                    | 按 credit 试水 |
| Developer  | **$50/mo · 500 credits** · ~$0.10/credit   | 结转 credits   |
| Scale      | **$240/mo · 3000 credits** · ~$0.08/credit | 优先支持       |
| Enterprise | 议价                                       | 可 on-prem     |

**视频**按分辨率/时长吃 credit，单价明显高于单张图；公开第三方（如 Replicate video-upscale）量级可到「数秒视频约 $0.5+」级，**必须用自家 credit calculator 实测算**再定 PV 标价。

同类 SaaS（Weavy、Krea 公开证言）已把 Topaz 当 **「AI 生成 → 可交付质量」桥**——与画布「生成后过审再导出」同构。

## 2. 本仓现状（对照）

### 2.1 画布图片编辑

`src/constants/canvas-image-edit-capabilities.ts` 已有 ready 能力：

| 能力                                                 | 当前模型               | 与 Topaz                                    |
| ---------------------------------------------------- | ---------------------- | ------------------------------------------- |
| **upscale**                                          | `fal-ai/aura-sr`       | **Topaz Gigapixel/Wonder/Bloom 可作高级档** |
| remove-background                                    | birefnet               | Topaz 有 bg remove 叙事，非差异化必换       |
| inpaint / outpaint / object-replace / style-transfer | FLUX / Gemini / GPT 等 | **生成式编辑**，Topaz 不替换主路径          |
| decompose / extract-element                          | 分割/提取              | Topaz 不覆盖                                |

另有独立 `/studio/edit` 任务网格与 image-edit 服务——同一能力契约可挂多模型。

### 2.2 画布视频

- 主路径：Seedance / Kling / … **生成** + 参考装配
- **几乎没有**「生成后 → 升 4K / 插帧 / 去压缩」一等能力
- Runway 等竞品把 **upscale 后处理**当 Agent 下一步（见 shotcraft 调研里的 Agent 文档）

→ **视频侧 Topaz 缺口最大、叙事最顺。**

### 2.3 工程契合点

| 本仓模式                  | Topaz 是否匹配                                            |
| ------------------------- | --------------------------------------------------------- |
| Adapter + Worker 异步 job | 匹配（async + poll + download URL）                       |
| R2 存终态 URL             | 匹配（下载后转存，勿依赖对方临时链）                      |
| BYOK / 平台 key           | 可做：平台 key 或用户 Enterprise key                      |
| fal 已是视频/图主 adapter | **捷径：若 fal 已托管 topaz 端点，先挂 fal 少开一家直连** |
| Credit 服务端扣减         | 必须映射 Topaz credit → PV requestCount                   |

## 3. 能不能用到画布？场景级结论

### 3.1 图片编辑 — **适合作为「增强档」，不替代编辑矩阵**

| 场景                   | 建议       | 理由                                                |
| ---------------------- | ---------- | --------------------------------------------------- |
| 定妆/角色图 2×–4× 导出 | **高价值** | 脸部保真是 Topaz 品牌强项；优于纯超分有时更「干净」 |
| 分镜静帧放大再喂视频   | **中高**   | 提高 i2v 输入质量；注意 Bloom 创意模式可能改脸      |
| 去噪/锐化/脸恢复       | **中**     | 填 Aura-SR 以外的工具条                             |
| inpaint / 换物 / 风格  | **低**     | 继续 FLUX/Gemini；Topaz 不是主创意图编辑器          |
| 背景抠图               | **可选**   | 已有 birefnet                                       |

**UX 落点（草案）：**

- 图卡工具条 / 审阅网格：「增强」→ 子菜单 **快速（Aura-SR）** / **专业（Topaz Wonder/Gigapixel）**
- 默认不自动跑 Topaz（贵 + 慢）；用户点或「导出前可选」

### 3.2 视频编辑 — **最值得接，定位「clip 后处理」不是「剪辑」**

| 场景                     | 建议           | 理由                       |
| ------------------------ | -------------- | -------------------------- |
| 单镜过审后 → 升 1080p/4K | **高**         | GenAI 原生分辨率常不够交付 |
| 插帧 / 慢动作            | **中**         | Frame interpolation        |
| 去压缩块、去噪           | **中**         | 二次压缩或低码率源         |
| 多镜时间线 trim/拼       | **不靠 Topaz** | 本仓 assembly / 汇点自己做 |
| 改剧情/改角色动作        | **不靠 Topaz** | 回生成模型重跑             |

**UX 落点（草案）：**

```text
视频节点（approved）
  → 操作：「增强导出」
  → 选 Proteus（保真）/ Starlight|Astra（GenAI 友好）
  → 异步 job → 新媒体 URL 挂节点 lineage（非破坏：保留原 clip）
```

与 **人工审核门** 对齐：建议 **仅 approved clip 可进 Topaz**，避免废 credit 增强未定稿。

### 3.3 明确不适合

| 误用                              | 原因                        |
| --------------------------------- | --------------------------- |
| 用 Topaz 代替 Seedance/Kling 生成 | 能力域不同                  |
| 浏览器里嵌 Topaz 桌面 App         | 无意义；SaaS 无法发用户 GPU |
| 全自动每镜必过 Topaz              | 成本与时延不可接受          |
| 把 Bloom 创意放大默认打在角色定妆 | 可能改身份，破坏一致性      |

## 4. 接入路径对比

| 路径                          | 做法                                                                           | 优点                              | 缺点                         | 推荐                |
| ----------------------------- | ------------------------------------------------------------------------------ | --------------------------------- | ---------------------------- | ------------------- |
| **A. 官方 REST 直连**         | 新 adapter：`topaz.adapter.ts`；env `TOPAZ_API_KEY`；async+poll+拉回 R2        | 模型全、官方支持                  | 新供应商运维；Adobe 交割风险 | 中长期 / 要全模型时 |
| **B. 经 fal（或 Replicate）** | 在 `canvas-image-edit` / 新 video-enhance 能力里加 `fal-ai/topaz/...` model id | 复用现有 fal 账本、重试、计费习惯 | 模型子集、加价、滞后         | **MVP 优先探**      |
| **C. 仅文档外链**             | 「下载后用 Topaz Studio」                                                      | 零工程                            | 不成产品能力                 | 过渡话术            |
| **D. 用户本机 Topaz + 回传**  | 本地处理再上传                                                                 | 无限本机渲                        | 破坏闭环、不适合多端         | 否                  |

**MVP 建议：**  
1）查 fal 当前是否暴露所需 image/video Topaz 端点与价；  
2）图：`upscale` 能力增加 Topaz 模型选项；  
3）视频：新 capability `video-enhance` / `video-upscale`（独立于生成）；  
4）平台 key 先内测，再谈 BYOK。

## 5. 成本、合规、Adobe 风险

### 5.1 成本

- 图：相对视频便宜，可当「高级 upscale」加价 1 档。
- 视频：按秒×分辨率吃 credit；必须 **提交前预估 + 确认门**（对齐 Ask before generate）。
- PV 侧：禁止把 Topaz 成本藏进「一次生成」；增强是 **独立计费动作**。

### 5.2 合规

- API 条款：再分发增强结果、SaaS 再售、是否要求署名——**签约前读 Terms**（官方 docs 销售条款）。
- 消费级订阅页常见 **「年收入 <$1M 有限商用」** 类限制；**API/Enterprise 档**才适合平台级再售——**不要用个人 Studio 订阅密钥顶生产多租户**。
- 用户上传与生成物隐私：媒体过 Topaz 云 = 第三方法处理；隐私政策与 DPA 要覆盖。

### 5.3 Adobe 收购（2026-06-25 官宣）

- [Adobe Newsroom](https://news.adobe.com/news/2026/06/adobe-to-acquire-topaz-labs)：协议收购，预计 **2026 下半年**交割，监管批准等条件。
- 公开表态：Topaz 产品暂继续独立售卖；技术会进入 Firefly / Creative Cloud 叙事。
- **对 PV：**
  - 短期 API 仍可用（文档与定价页 2026-07 仍在）；
  - 中期可能涨价、限 API、或优先 Adobe 生态；
  - **架构上增强层必须可插拔**（Aura-SR / 其他 fal 超分作 fallback）。

## 6. 与剧本节点 / 审核门的关系

（承接 `video-shotcraft与助手合并评估` §12–§13）

```text
G3–G7 生成 → 用户审核 approved
                 │
                 ▼ 可选
            Topaz 增强（图/视频）
                 │
                 ▼
            再审一次？或仅「导出档」自动挂 lineage
                 │
                 ▼
            汇点 / 下载 / 进 Gallery
```

- **不要**在 G2 分镜未锁时批量 Topaz。
- 定妆：优先 **Gigapixel/Wonder 保真**；慎用 Bloom。
- 视频：默认 **Proteus/Starlight 精度向** 服务 GenAI clip。

## 7. 方案建议（可拍板）

| 方案                        | 内容                                                   | 何时                          |
| --------------------------- | ------------------------------------------------------ | ----------------------------- |
| **T0 不做站内**             | 导出说明 + 外链                                        | 若近期不碰后处理              |
| **T1 图增强档（推荐先做）** | upscale 多模型：Aura-SR 默认 + Topaz（fal 或直连）可选 | 1–2 周级（有 fal 端点时更短） |
| **T2 视频增强导出**         | approved 视频节点「升清/插帧」异步 job                 | 在 T1 稳定 + 算清 credit 后   |
| **T3 全工具条**             | denoise/sharpen/face/lighting 全铺                     | 仅当用户明确要「修片台」      |

**默认推荐：T1 → T2；T3 按需。T0 仅当 Adobe 风险不可接受且无备用。**

## 8. 若立项：最小切片（非授权，仅路线）

1. **Spike（1–2 天）**
   - 用官方 Playground / 试 key 跑 1 张 AI 图 + 1 段 5s Seedance 样片；记时延、credit、脸漂移。
   - 对照 fal-ai/topaz 是否同模型、价差。
2. **常量**
   - `canvas-image-edit-capabilities` upscale.models 追加 Topaz id；或新 `video-enhance-capabilities.ts`。
3. **服务**
   - enhance service：输入 R2 URL → 调 adapter → 回写 R2 + lineage。
4. **UI**
   - 图：编辑菜单高级 upscale；视频：composer/节点「增强导出」。
5. **计费**
   - 独立 cost 表；失败不吞用户 credit（与现生成策略一致）。
6. **降级**
   - Topaz 429/下线 → 自动/提示回退 Aura-SR 或仅原片。

**禁做：** 改生成主模型列表冒充 Topaz；桌面 App 自动化；无预估的批量增强。
