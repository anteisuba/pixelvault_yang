# 界面细节打磨

用于已定方向的界面细节修复。围绕指定目标完成调整和验证；范围遵循 `docs/WORKFLOW.md`，仅在需要设计判断时补读已确认的域/page 规范。

从实际界面找出影响当前任务的细节：对齐与间距、文字层级、图标与图片布局、三语文案、键盘焦点、窄屏溢出，以及该控件实际需要的交互状态。复用现有 token、组件和动效配方，不为打磨重设全站风格。

状态与动效按用途选择：异步操作需要反馈，表单错误需要可恢复路径；不要求每个元素都有 loading/error/success，也不要求每次状态变化都动画。保留减少动效偏好、焦点可见性和必要的可访问名称。

若发现功能缺陷，已在修复范围内则一并解决；超出范围时指出其影响，继续独立的细节修复。不以功能尚未全部完成为由停止可交付的局部工作。

用受影响的真实交互与视口验证，按 WORKFLOW 选择静态检查和必要行为测试。没有相应设备或浏览器时说明未验证范围，不声称全平台通过。完成本次修复及验证后交付，不额外要求他人评审，也不自动发布。
