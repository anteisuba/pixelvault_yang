存储（Q2 A：新表）
AssistantMemory
一条 = 一行字：text（进系统提示的就是它）· kind（偏好 / 事实 / 规则）· scope（image · video · canvas · lora · global）
溯源三件：conversationId · messageId · createdAt —— 总览页点「来源」跳回那一轮对话
lastUsedAt（被注入过就更新）决定注入优先级与淘汰顺序；pinned 置顶不淘汰
索引 (userId, scope, updatedAt desc) 与 (userId, kind)；删除即真删，⛔ 不做软删
与上下文卡的分界
卡 = 你亲手经营的素材（正文 · 图 · 负面 · 常挂范围 · @ 点名）；记忆 = 助手观察到的一行事实或偏好
唯一的桥：一条记忆可「存为上下文卡」→ 建 ContextCard 并把这条记忆标记为已升格；⛔ 反向不自动降级
写入（即时写）
每轮结账时一次性写，与「本轮记住 N 件事」同一时刻；⛔ 不在每条消息后写
同 scope 同 kind 规范化字面去重，命中更新旧条；语义去重本轮不做向量（owner 09-19）
每域上限 200 条，超了按 lastUsedAt 最旧静默淘汰；⛔ 不画容量表、不变灰、不做置顶（09-20 最简版撤掉）
注入（怎么被用）
每轮只注入当前域 + global 的前 N 条（按 lastUsedAt），与上下文卡共用一份预算、卡优先
总览页（09-20 最简版，对标 GPT「管理记忆」）
/settings 助手分区里人设下面一块：一张平铺列表按时间倒序，每条一行字 + 时间；顶部一排筛选 chip（全部 · 图片 · 视频 · 画布 · LoRA），默认全部。⛔ 不分组、不按天分段
每行一个动作：删（真删）。点文字就地改。⛔ 不做「存为卡」、不做来源跳转（记忆表仍存溯源字段，只是不画）
右上「全部清空」二次确认；空态一句话 + 隐身入口
回执与隐私（09-20 最简版）
