# 画布镜头表框架（设计稿）

施工单 `p-canvas-shotlist`（原 `p-canvas-breakdown` 拉片并入）。2026-11-01 出稿，基线 main 00a8112。方向见 `references/product.md` 北极星。

## 一句话结论

画布做视频的骨架是一张**镜头表**：一行一镜，列是 镜号 · 画面 · 景别 · 运镜 · 说明 · 风格。表的每一行**就是**画布上那张镜头卡（`video.shot`），不是另存的一份——所以改表就是改片。表有三个来源（自己写 / 助手填 / 从参考视频拆），填好后一镜一镜出图、出视频，最后进剪辑台。

## 发现的问题

1. **镜头信息存了两套形状**：旧 ScriptDoc 有结构化字段，现行剧本卡是一段 Markdown 现拆。入口删了但旧数据模型、投影、`/api/script-breakdown` 还在。这次应该**定一份**，另一份删掉（AGENTS.md：删除过时实现）。
2. **镜头卡上没有「景别 / 运镜 / 风格」**：现在这些只能写进提示词正文，表没法按列读写，助手也只能整段改提示词。
3. **剧情看不到全貌**：镜头带是横排卡片，24 镜要缩得很小才能看全；没有一处能「从上往下读一遍这部片」。
4. **统一性没人管**：角色图、场景图有没有对上，现在全靠人眼对卡。
5. **拉片没有切镜**：视频分析只给整体描述，拆不出「第几秒到第几秒是一镜」。

## 设计

### 1. 数据：一行 = 一张镜头卡

镜头卡 `video.shot` 加一组**镜头字段** `shotSpec`（全部可选，存量项目不受影响）：

| 列              | 字段                                   | 说明                                                                                  |
| --------------- | -------------------------------------- | ------------------------------------------------------------------------------------- |
| 镜号            | 现有 `shotNo`                          | 拖行换序 = 现有 `reorder_shot`                                                        |
| 画面            | 不存，现读                             | 有片放片的封面，没片放关键帧（首帧图），都没有放空格                                  |
| 景别            | `shotSpec.size`（固定词表）            | 大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写；表里点开是一行一项的弹层 |
| 运镜            | `shotSpec.move`（词表 + 可写自由文字） | 固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 手持 / 环绕…，可叠「缓慢」等修饰               |
| 说明            | `shotSpec.note`                        | 这一镜讲什么：剧情 + 动作 + 台词（截图里的「分析」列）                                |
| 风格            | `shotSpec.look`                        | 光线 / 色调 / 质感。空着就继承全片风格（见下）                                        |
| （时长）        | 现有参数 `duration`                    | 建议加一列，剧情节奏离不开它                                                          |
| （角色 · 场景） | 现有 `@角色` + 新 `shotSpec.sceneId`   | 建议加一列，统一检查就看这一列                                                        |

- **发送时**镜头字段拼进提示词（景别 / 运镜翻成模型认的说法），⛔ 不写进提示词正文——正文仍是用户和助手写的那段话。
- **全片风格**存在剧本卡上一份，每行 `look` 空着就用它；改全片风格 = 所有没单独写的行一起变。
- 剧本卡留着当「剧情大纲」那一层；分镜列表改成读镜头卡（不再从正文拆），旧 ScriptDoc 与 `/api/script-breakdown` 删掉，有用的字段（台词、情绪）并进 `shotSpec`。

### 2. 看法：画布的「表格视图」

和剪辑台一样是画布的一个全屏模式（`?mode=table`），三个视图共用一份项目：**画布**（自由摆）· **表**（从上往下读剧情）· **剪辑台**（排成片）。

- 一行一镜，列按上表；行高跟着「画面」缩略图走。顶上一条：全片风格 · 总时长 · N 镜 · 有片 M 镜。
- 单元格点即改，改完就是改那张卡（同一个 op、同一份撤销栈）；拖行换序。
- 行尾一颗按钮，状态即进度：`出画面` → `出视频` → `已有片`（花钱仍要点）。
- 选中几行 →「逐镜生成」：先全出画面给你挑，挑定再出视频。
- 助手面板和画布、剪辑台是同一块，开着时改到的格子闪一下。
- 手机：一行变成一张竖卡（现有 `MobileShotCard` 那种），左右滑换镜。

### 3. 三个来源

- **自己写**：表里直接加行、填格子。
- **助手填**：说一句「做一个 30 秒的雨夜告白短片」，助手先出大纲写进剧本卡，再一次写满一张表（一批 op，一个撤销）。按自主度规矩：整张新表直接做；要覆盖已有行先问一句。
- **从参考视频拆（拉片）**：把参考视频拖进表格视图 →
  1. **切镜**：服务端用 ffmpeg 场景检测切出每一镜的起止秒和关键帧（复用剪辑台那台 Cloudflare 容器，不花 AI 钱）；
  2. **读镜**：每镜的关键帧 + 那一小段交给视频分析（现有 `analyze-video`，Gemini 直看），填景别 / 运镜 / 说明 / 风格；
  3. 落成一张表，每行「画面」是原片截帧（`image.reference`），标「参考」；
  4. 你改成自己的故事（换角色、换场景），或者让助手「照这个节奏改成我的角色」，再逐镜生成。
  - ⚠ 拉片表默认只拿结构（节奏、景别、运镜），⛔ 不默认照抄画面内容；原片截帧只当参考，不进成片。

### 4. 统一检查

表的「角色 · 场景」列每行挂着这一镜用到的角色卡、场景卡的小头像。助手的「检查一遍」：用 `canvas_look_at` 看每行的画面，对照角色卡和场景卡，挑出对不上的行（发色变了、场景换了样子），在格子上标一个点，说清哪里不对。不花生成钱，只花看图的 LLM 钱。

## 分几步做（每步能单独上线）

1. **地基**：`shotSpec` 字段 + 发送时拼提示词 + 助手能读写这些字段；删旧 ScriptDoc / script-breakdown。

4. **逐镜生成**：选几行先出画面、挑定再出视频，进剪辑台。
5. **拉片**：切镜 → 读镜 → 落表。
6. **统一检查**。
7. **手机**（按 roadmap，用的人多些再排）。
