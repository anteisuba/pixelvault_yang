## 0. 一句话

PixelVault 的交互目标是：**跟手、有物理感、久用不累**。  
浏览面可以「滑到停不下来」；工作台必须 **丝滑且精确**。  
动效只服务 **状态、连续性、反馈**，不服务装饰炫耀。

## 2. 硬原则（P0）

1. **跟手优先**  
   拖拽、滚动、画布平移：输入到画面变化应在交互帧内可感知；禁止在 `pointermove`/`scroll` 上触发大面积 React 重渲染。

2. **只动画合成友好属性**  
   默认只动 `transform`、`opacity`（及确有必要的 `clip-path`）。禁止用 top/left/width 做高频动画。

3. **统一时长与曲线**  
   新代码优先使用全局 token（`globals.css`）：
   - `--duration-fast` ~120ms（hover、微反馈）
   - `--duration-base` ~200ms（面板、popover）
   - `--duration-slow` ~320ms（大块布局）
   - `--ease-standard`  
     域可增加更短档（如 canvas 的 150/250/420），但 **同域内不得再散落 magic ms**。

4. **`prefers-reduced-motion: reduce`**  
   必须降级为瞬间或淡入淡出切换；关闭惯性增强与 spring 过冲。

5. **动效服务三类信号**
   - 状态：loading / selected / error / success
   - 连续性：展开、路由内布局、列表重排
   - 反馈：点击、完成、失败  
     禁止：无限装饰循环、无信息 hover 粒子、阻断主任务的长动画。

6. **可访问性不被动画破坏**  
   焦点环可见；Dialog/Sheet focus trap 与 return；触屏不误触弹键盘（既有 ResponsiveOverlay 纪律）。

7. **性能**  
   长列表虚拟化；媒体懒加载；目标主路径 **60fps**（中端设备可降到可交互流畅，但不卡顿）。

## 3. 滚动与惯性

| 做法                                      | 允许         | 禁止               |
| ----------------------------------------- | ------------ | ------------------ |
| 原生 `overflow: auto/scroll` + 浏览器惯性 | ✅ 默认      | —                  |
| 虚拟列表 + 原生滚动                       | ✅           | 假滚动容器无障碍   |
| 全站 Lenis / 自定义 hijack 滚轮           | 仅营销页评估 | **工程页默认禁止** |
| 滑条/参数带惯性吸附乱跳                   | —            | ✅ 禁止            |

## 4. 动画库（本仓硬边界）

| 区域                                                 | 库                                  | 备注                              |
| ---------------------------------------------------- | ----------------------------------- | --------------------------------- |
| 画布、Studio、LoRA、Assets、Prompts、`components/ui` | **`motion` / `framer-motion` 唯一** | 状态与布局动画                    |
| 首页营销（`HomeV3*` / `home-v3.css`）                | **GSAP** 允许                       | **必须**动态 import，不进主 chunk |
| 工程页引入 GSAP                                      | **禁止**                            | 见调研 §3；复议条件见该文         |

理由摘要：工程页以 React 状态机为主；双库成本高；画布与 React Flow 不宜 GSAP 直操 transform。

---

## 5. 分域要点

### 5.1 画布

- Pan/zoom：React Flow / 引擎负责；不叠 GSAP/Lenis。
- 节点选中、工具条、助手 dock、详情：Motion/CSS token。
- 生成中/失败：清晰状态动画，可打断/可取消优先于花活。

### 5.2 LoRA / Studio / 提示词

- 装配台、选择器、配方列表：短过渡 + 列表惯性。
- 参数面板：精密档；避免布局大弹跳导致误点。

### 5.3 素材（Assets）

- 网格滚动、批量选择：浏览档惯性。
- 详情 Sheet：标准 overlay 动效 + focus return。

### 5.4 Gallery / 首页

- Gallery：浏览档。
- 首页：可继续用 GSAP 做叙事滚动；与 app 壳交互品质一致（跟手、不卡）。
