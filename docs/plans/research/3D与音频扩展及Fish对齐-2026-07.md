## 1. 3D：现状 vs「一张图出 GLB」

### 1.1 你看到的能力 vs 本仓

外部 agent（Codex / 某站 demo）「一张图出 GLB」= **Image-to-3D** 通用能力。  
本仓 **不是缺这条链路**，而是：

| 层      | 状态                                                                                 |
| ------- | ------------------------------------------------------------------------------------ |
| 目录    | `MODEL_3D_OPTIONS`：**5 个 available** + 1 个 disabled                               |
| API     | `/api/generate-3d` + status / continue / retry-mesh / cancel                         |
| Service | `generate-3d.service.ts`（队列、mesh 阶段、R2 入库、质量检查 `image-3d-prep`）       |
| UI      | `/studio/3d` → `Studio3DWorkspace` + `use-generate-3d`（预览 / 临时 fal URL / 续跑） |
| 输出    | **GLB**（常量写明默认 glb，对接 ModelViewer）                                        |
| 首页    | 已有 3D 产品位与示例 GLB                                                             |

### 1.2 已接入模型（均可图→3D，要参考图）

| 模型                   | 通道         | 特点（目录注释）                            | 适合      |
| ---------------------- | ------------ | ------------------------------------------- | --------- |
| **TripoSR**            | fal          | 快、预览向、cost 低、`freeTier`             | 试形状    |
| **Trellis 2**          | fal          | 几何/纹理控制                               | 中档      |
| **Hunyuan3D v3**       | fal          | 多视角 + PBR                                | 成品质感  |
| **Hunyuan3D v3.1 Pro** | fal          | 更高保真多视图                              | 精品      |
| **Rodin Gen-2.5**      | Hyper3D 官方 | 最多 5 参考图；**需 Hyper3D Business BYOK** | 高端/多图 |
| Hunyuan 2.1            | fal          | **available: false**                        | 历史      |

**多视角：** UI/常量有 multiview 生成路径（单图可先扩多视角再重建）——比「纯 1 图盲推」更完整。

### 1.3 产品定位矛盾（真问题）

`product.md`（2026-07-10）：

- 3D **搁置**；
- 远期：**导演台视频控制**（机位/场景），不是「3D 资产商店」。

`studio.md`：`/studio/3d` 标 **搁置**，但 **代码与路由仍在**。

→ 「能不能加」→ **技术上已加**。  
「该不该推」→ **产品决策：取消搁置 / 仅专业入口 / 或接到画布角色定妆**。

### 1.4 扩展方向（按价值，非必须全做）

| 优先级         | 方向                                                               | 说明                           | 工作量感             |
| -------------- | ------------------------------------------------------------------ | ------------------------------ | -------------------- |
| **P0 产品**    | 取消「搁置」叙事，导航/首页可进 3D                                 | 能力已有，可见性是问题         | 文档+入口            |
| **P1 联动**    | Gallery/Assets 图 →「生成 3D」；生成结果回 Assets                  | 闭环                           | 中                   |
| **P1 角色**    | 角色卡多视角 → Hunyuan/Rodin 多图 → GLB 回写卡/资产                | 对齐你「角色容器」             | 中高                 |
| **P2 画布**    | 3D 节点仅作 **机位/参考**（远期 product 句），**不做**完整 Blender | 符合北极星                     | 高，依赖视频控制产品 |
| **P2 模型**    | 目录增量（新 fal I2-3D）                                           | 走 add-model 清单              | 中                   |
| **P3**         | Text-to-3D（若 provider 有）                                       | 与「图为准」创作台次要         | 看 catalog           |
| **不做（近）** | 把 Codex skill 当运行时                                            | SaaS 不能依赖本机 agent 渲 GLB | —                    |

### 1.5 和 Codex「一图 GLB」的正确关系

| Codex / agent 演示    | PixelVault                              |
| --------------------- | --------------------------------------- |
| 临时脚本 + 某 API key | 正式 BYOK + credit + Worker + R2 + 权限 |
| 单次文件              | `Generation` 资产、可归档               |
| 无角色/多镜故事       | 可挂角色卡 / 画布（未做满）             |

**建议话术：** 不是「接入 Codex 出 3D」，而是 **「Image→GLB 已是一等公民；接下来做入口与角色/素材联动」**。

## 2. 音频：现状与可加功能

### 2.1 现状矩阵

| 能力                             | 状态                           | 实现要点                                                           |
| -------------------------------- | ------------------------------ | ------------------------------------------------------------------ |
| **语音 TTS（Fish S2 Pro）**      | ✅ 主路径                      | `FISH_AUDIO_S2_PRO` · `fish-audio.adapter` · `/api/generate-audio` |
| **音色库 list / 详情**           | ✅                             | `fish-audio-voice` + `/api/voices`                                 |
| **持久克隆 createVoice**         | ✅                             | FormData → Fish `/model` · train_mode fast                         |
| **即时参考克隆**                 | ✅                             | `references: [{audio, text}]` 无 reference_id                      |
| **多 speaker reference_id 数组** | ✅ adapter 字段                | UI 是否充分暴露待产品验收                                          |
| **ASR 转写**                     | ✅                             | `transcribeAudio` · `/api/voices/transcribe`                       |
| **表现力 → temperature**         | ✅                             | `EXPRESSIVENESS_TO_FISH_TEMPERATURE`                               |
| **prosody speed/volume**         | ✅ adapter                     |                                                                    |
| **时间戳流式拼音频**             | ✅ adapter 内 timestamp stream |                                                                    |
| **VoiceCard**                    | ✅                             | 绑角色卡产品句已有                                                 |
| **画布 voice → video**           | ✅ 方向                        | 音频进 Seedance 槽                                                 |
| **音效 SFX**                     | ✅                             | `ELEVENLABS_SFX_V2` · audioKind sfx                                |
| **ElevenLabs 语音 v3**           | ❌ 下线                        | 2026-07-26 retired（价高）                                         |
| **音乐 Music API**               | ❌ 未进目录                    | design Phase C 未落地                                              |
| **播客 / 长音频拼接**            | ❌                             | design Phase E                                                     |
| **行内情绪 token 编辑器**        | ❌/弱                          | design Phase D；Fish 支持自由 `[tag]` 透传                         |
| **文字造音色 Voice Design**      | ❌                             | Fish 有 API；design Phase F「designed」                            |
| **实时 voice agent WebSocket**   | ❌                             | **产品明确不做**（A1）                                             |
| **DAW 式剪辑**                   | ❌                             | 明确不做                                                           |

施工基准：`docs/plans/audio-domain-design-2026-07.md`（Phase A–F）。

### 2.2 建议扩展优先级（音频）

| 序       | 功能                                       | 为何                                        | 依赖                                 |
| -------- | ------------------------------------------ | ------------------------------------------- | ------------------------------------ |
| **1**    | **Fish 升到 s2.1-pro**（或并行双模型）     | 官方推荐生产模型，质量/延迟/吞吐优于 s2-pro | enum + externalModelId + 测价 + i18n |
| **2**    | **行内情绪 token + 词表 chips**（Phase D） | Fish 最大差异化已在 API 侧，UI 未用满       | prompt 编辑器                        |
| **3**    | **A/B 变体出纸**                           | 情绪可感知                                  | 生成编排                             |
| **4**    | **ElevenLabs Music（≤60s）**（Phase C）    | kind 矩阵缺 music；设计已拍板供应商         | adapter + credit                     |
| **5**    | **播客/双人分段 TTS + 拼接**（Phase E）    | 成品化；绑多 VoiceCard                      | ffmpeg/拼接 spike                    |
| **6**    | **Voice Design（Fish 文生音色）**          | 降低克隆门槛；落 VoiceCard                  | 新 endpoint 封装                     |
| **7**    | 情绪导演 LLM 插 tag                        | Phase F/L3                                  | 助手路由                             |
| **后置** | video-to-sound、MiniMax/ACE-Step           | design 已标后置/远期                        | —                                    |
| **不做** | 实时通话 agent、Fish 变声当主路径          | 与创作台北极星不符                          | —                                    |

### 2.3 与画布/角色卡

已规划链路：`Character → Voice → Script → Shot/Video`。  
扩展时优先：

- VoiceCard 从 Fish 克隆/市场一键落卡；
- 脚本分段 speaker = VoiceCardId；
- Seedance `audio_urls` 继续吃生成结果（不是新 Fish 协议）。

### 3.1 对齐结论

```text
Fish 作为「语音身份 + TTS」供应商：
  已对齐主干 ≈ 70–80%（够用、可生产）
  未对齐「官方最新最好」：s2.1-pro
  未对齐「扩展产品」：Voice Design、Realtime、平台音乐/变声

不是「一个功能都没接」，也不是「全部对齐」。
```

### 3.2 建议 Fish 专线任务包（若开干）

1. **Catalog：`FISH_AUDIO_S2_1_PRO`** + 默认推荐切换策略（保留 s2-pro 或弃用）。
2. **对照 OpenAPI** 扫一遍 update-model / 新 body 字段。
3. **Voice Design** → 候选试听 → 落 VoiceCard。
4. **UI：行内情绪** 专吃 Fish 自由词表。
5. Realtime：**明确写死非目标**（除非以后做 live 预览）。

一手资料入口：

- https://docs.fish.audio/overview/capabilities
- https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech
- https://docs.fish.audio/features/voice-design
- https://docs.fish.audio/llms.txt

改模型/参数前按 WORKFLOW **再拉一次官方**（本调研会过期）。

## 8. GLB 生成后：更多拓展方向（产品脑暴，非授权）

> 前提：现仓 **没有**「视频/图模型直接吃 GLB」；任何挂钩都要有 **编译步**（渲图 / 机位 / 导出文件）。

### 8.1 按「给主线什么输入」分类

| 方向                   | GLB 之后变成什么                         | 接哪                                   | 贴北极星程度  |
| ---------------------- | ---------------------------------------- | -------------------------------------- | ------------- |
| **B 立体定妆**         | 固定机位多视角 PNG                       | 角色卡 / Assets / Seedance `@Image`    | ⭐⭐⭐ 最高   |
| **道具/场景卡**        | 同左，绑 Background 或「道具」           | 画布场景节点                           | ⭐⭐⭐        |
| **Turnaround 工厂**    | 360° 转台截帧条                          | 一致性评分、定妆包                     | ⭐⭐⭐        |
| **再光照 / 再构图**    | 同 mesh 不同 HDR 截图                    | 图工作台变体，不重训                   | ⭐⭐          |
| **深度/法线/遮罩导出** | 控制图                                   | 图编辑 / ControlNet 类（若 Runner 有） | ⭐⭐          |
| **C 导演台机位**       | 相机路径 + 布局关键帧                    | 画布长视频                             | ⭐⭐⭐ 远期大 |
| **A 纯资产**           | 下载 GLB/FBX                             | 游戏/打印/外部 DCC                     | ⭐ 离主线     |
| **AR 分享**            | model-viewer / 链接                      | Gallery 展示                           | ⭐ 社交弱     |
| **LoRA 训练集辅助**    | 多视角图（非 GLB 本身）                  | LoRA 训练样本                          | ⭐⭐          |
| **3D 打印**            | STL 导出（Meshy 强项）                   | 实体周边                               | ⭐ 离主线     |
| **世界/场景生成**      | Gaussian splat / 可漫游场景（Marble 类） | 环境参考、虚拟片场                     | ⭐⭐ 新模态   |
| **动画/绑定**          | rig + 短动作（Meshy/Tripo 生态）         | 参考视频运动                           | ⭐ 复杂       |
| **Part split**         | 部件 mesh                                | 换装/分件（Hunyuan part 类）           | ⭐⭐ 角色     |

### 8.2 和「孤岛感」的关系

- **只做 A（下载）** → 永远像独立工具。
- **做 B/Turnaround** → 立刻接上 **图 → 卡 → 视频** 总线，不必等导演台。
- **做 C** → 产品级新域，排在画布助手管道之后。
- **世界模型 / Splat** → 不是换一个 I2-3D，是 **另一类资产**（场景可漫游），别和 GLB 角色混为一谈。

### 8.3 推荐组合（若只养一条 3D 故事）

```text
定妆图 → I2-3D(现有) → GLB（可下载）
                ↓ 自动/半自动
         正/侧/3-4 截帧 → 角色卡参考 + Assets
                ↓
         画布 / Seedance 只吃图（既有）
```

## 9. 2026 流行 / 主流生成式 3D 模型调查

> 来源：行业对比文、fal 目录、社区讨论（2026 上半年–7 月口径）。**无单一官方排行榜**；下表是交叉共识，接入前仍要查一手 API。

### 9.1 名字频次最高的一梯队

| 名字                                | 类型                          | 社区/评测常说的强项                                  | 本仓                                                      |
| ----------------------------------- | ----------------------------- | ---------------------------------------------------- | --------------------------------------------------------- |
| **Hunyuan3D 3.x / 3.1 Pro**（腾讯） | I2-3D / T2-3D / 多视角        | 生产向、拓扑与 PBR、开放权重叙事强；多文「高端写实」 | ✅ v3 / v3.1 Pro（fal）；2.1 已下                         |
| **TRELLIS.2**（微软）               | I2-3D + PBR                   | 视觉/开源向常被点名；fal 易接                        | ✅ Trellis 2                                              |
| **Tripo**（平台 + 多代 API）        | 快 I2-3D、多图、工作流深      | **速度**、迭代、游戏向；多篇「先试 Tripo」           | ⚠ 仅 **TripoSR**（老/快预览），**非** 完整 Tripo 3.x 套件 |
| **Meshy**（Meshy-5/6 等）           | T2-3D + I2-3D + 打印/动画插件 | **创作者 SaaS 主流**、打印、绑定生态                 | ❌ 未接                                                   |
| **Hyper3D Rodin**（Gen-2/2.5）      | 高保真角色/几何               | **高端观感**、企业向                                 | ✅ Rodin Gen-2.5（BYOK 门槛高）                           |
| **TripoSR**                         | 极速几何预览                  | 便宜快、质量非顶                                     | ✅                                                        |

### 9.2 第二梯队 / 新叙事（别和「角色 GLB」混）

### 9.3 粗分「最流行」怎么理解
