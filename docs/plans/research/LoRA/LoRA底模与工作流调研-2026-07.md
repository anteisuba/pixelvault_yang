## 1. 架构族（先分清，再谈「热门底模」）

LoRA **不能跨架构混用**（硬不兼容）：

| 架构族                                   | 代表                                       | LoRA 互通                                 | 社区角色（2026）                                    |
| ---------------------------------------- | ------------------------------------------ | ----------------------------------------- | --------------------------------------------------- |
| **SD 1.5**                               | Anything 等                                | 仅 1.5                                    | 存量最大历史库；新训练少；低 VRAM 遗老              |
| **SDXL 基座**                            | SDXL 1.0                                   | 纯 SDXL LoRA                              | 写实/通用；细调常被 Pony/IL 分流                    |
| **Pony（SDXL 衍生）**                    | Pony Diffusion V6/V7 系                    | **Pony 系 LoRA 海量**；与 IL 互用会掉质量 | **角色/NSFW/插画 LoRA 库存之王**                    |
| **Illustrious / NoobAI（SDXL 衍生）**    | Illustrious XL、NoobAI-XL、WAI-Illustrious | IL↔NoobAI 较近；与 Pony **勿默认互通**    | **默认出图质量 + 新角色 LoRA 训练主流**             |
| **FLUX.1 / FLUX.2 系**                   | FLUX.1-dev、Klein 等                       | 仅 FLUX 系 LoRA                           | 写实/提示服从；生态小于 Pony/IL 但在长              |
| **Anima DiT**（非 SDXL）                 | Anima Base（Cosmos/Qwen-Image 线）         | 仅 Anima baseModel                        | 社区称动画向「新热」；与 Pencil XL **不是同一族**   |
| **Anima Pencil XL**                      | SDXL 上的 Pencil 系                        | SDXL/部分交叉                             | 与 DiT Anima 易混名，产品必须拆开                   |
| 新兴本地（Krea2 / Z-Image / Qwen-Image） | 2026 本地向                                | 自有 LoRA 生态在长                        | **Civitai 角色 LoRA 主库仍以 Pony/IL 为主**；观察项 |

**粗粒度兼容桶（本仓）：** `flux` / `sdxl`（含 IL/Pony/Pencil 在路由上的归并规则以代码为准）/ `anima` / `anima-dit` / `other` —— 细粒度选择器见 `LORA_BASE_FAMILIES`。

## 3. 主流工作流（社区习惯）

### 3.1 生成（Inference）— 固定骨架

几乎所有 Comfy/WebUI 二次元 LoRA 流同构：

```text
CheckpointLoader (底模)
  → LoraLoader × N（权重 0.6–1.0 常见）
  → CLIP Text Encode (+/−)
  → Empty Latent / 参考图 VAE Encode
  → KSampler（步数/CFG/采样器跟底模卡说明）
  → VAE Decode → Save / Upscale
```

| 步骤    | 社区惯例                                                                                   |
| ------- | ------------------------------------------------------------------------------------------ |
| 多 LoRA | 角色 + 画风 + 质量/细节增强；总强度勿叠爆                                                  |
| 分辨率  | SDXL/IL/Pony：1024 档或 896×1152 等；勿乱用以太高原生再硬拉                                |
| 采样    | 以 **该 checkpoint 模型页推荐** 为准（Euler a / DPM++ 等）；Turbo/LCM 要配专用调度         |
| 加速    | DMD2 / Lightning / Turbo LoRA（步数降到 4–8）在 SDXL 族常见；FLUX/Anima 另有 turbo 辅 LoRA |
| 高清    | 先出图再 4x 超分（AnimeSharp 等）— 与本仓 runner 可选 upscaler 同思路                      |

### 3.2 提示词方言（按族）

| 族                       | 提示习惯                                                                          | 负面                                |
| ------------------------ | --------------------------------------------------------------------------------- | ----------------------------------- |
| **Pony**                 | 常强制质量前缀：`score_9, score_8_up, score_7_up` + Danbooru 标签                 | 模型页推荐 neg；缺 score 前缀质量塌 |
| **Illustrious / NoobAI** | Danbooru 标签 + `masterpiece, best quality` 等；角色名/画师名有时不靠 LoRA 也能出 | 标准质量 neg                        |
| **FLUX**                 | 偏自然语言长句；LoRA 触发词仍要保留                                               | 较短 neg 或按模型页                 |
| **Anima DiT**            | 跟 Anima/Qwen-Image 工作流与触发词；**不要**套 Pony score 前缀                    | 按 runner/模型页                    |

产品含义：助手 / 搭配提醒 / 做同款 **必须按 family 换模板**，禁止一套 prompt 方言打天下。

### 3.3 发现 → 挂载 → 出图（Civitai 用户路径）

```text
Civitai 搜 LoRA（筛 baseModel）
  → 看样例图 + 触发词 + 推荐权重
  → 下载 / 在线生成
  → 选「匹配 base 的 checkpoint」
  → 堆 LoRA + 出图
  →（可选）用源图 meta 做配方还原
```

与本仓 **Library → 使用此 LoRA → Generate** 同构；Library 必须暴露 **类型 + 底模(family)** 筛选（已拍板）。

### 3.4 训练（Train）— 社区惯例摘要

| 项      | 常见做法                                                                    |
| ------- | --------------------------------------------------------------------------- |
| 选 base | **先定发布目标生态**：角色向 IL 或 Pony；写实向 FLUX                        |
| 数据    | 10–50 张精修集（角色）；重复脸/多角度；打标 Danbooru 或自然语言（跟 base）  |
| 工具    | kohya / OneTrainer / 云训练；分辨率 1024 档（SDXL 族）                      |
| 产出    | 标明 `baseModel`（Illustrious / Pony / Flux 等）— 错误标签是兼容灾难源      |
| 本仓    | Train 空间产出回流「我的」→ 挂载 Generate；训练 base 选项应 ⊆ 可执行 family |

### 3.5 配方还原（本仓差异化）

```text
源图 meta（checkpoint + LoRAs + prompt + 采样）
  → 兼容过滤
  → Runner 忠实跑 或 hosted 近似
  → 超容量 / 不兼容 → 预检（产品基线，非本次调研展开）
```

社区对等物：Civitai「用此图参数」/ 本地 PNG info。本仓 **做同款 / 来源配方 modal** 应对齐此心理模型。

## 4. 工作流模式（产品语言）

| 模式                      | 输入               | 底模策略                      | 社区对应          |
| ------------------------- | ------------------ | ----------------------------- | ----------------- |
| **单卡使用**              | 1 LoRA             | 自动推荐该 family 默认底      | 最常见            |
| **角色 + 画风**           | 2–3 LoRA           | 同族；权重角色 > 画风         | 多 LoRA 叠        |
| **质量/细节辅 LoRA**      | +detail/add-detail | 同族低权重                    | Detail Tweaker 类 |
| **配方复刻**              | 源图全 meta        | **精确 checkpoint**（runner） | PNG info 还原     |
| **纯底模探索**            | 0 LoRA             | Anima Base / IL 等            | 测底模气质        |
| **写实 FLUX + 角色 LoRA** | FLUX LoRA          | 仅 flux-hosted 等             | 与二次元线分流    |

容量：社区常挂 2–4 张；本仓 **全局 cap 与 provider max 交集** 见产品基线（基础 3 / 高级跟执行通道）。

## 5. 对 PixelVault 的建议（调研级，非拍板）

### 5.1 已对齐社区的部分

- Illustrious/NoobAI + WAI runner、Pony V6、FLUX LoRA、Anima DiT 来源自动 checkpoint — **覆盖 2026 主流量**。
- hosted 快 / runner 忠实 双后端 — 符合「试一下 vs 还原」分流。
- Library 底模筛选、Generate 装配行底模身份 — 符合 Civitai 用户心智。

### 5.2 产品/文档可加强

1. **Family 文案**：Pony = 海量角色 LoRA；IL/NoobAI = 新默认质量；FLUX = 写实；Anima DiT ≠ Pencil。
2. **Prompt 方言**：Pony score 前缀 vs IL masterpiece — 助手与空态提示按 family 切换。
3. **跨族挂载**：默认禁止或强警告（IL↔Pony）。
4. **Pony 快通道**：若 hosted 无真 Pony 端点，UI 应写清「仅 Runner 忠实」避免用户以为和 FLUX 一样快。
5. **观察清单（未接）**：Krea2 / Z-Image 等作 **LoRA base** 需独立调研 allowlist + 兼容桶；**不要**与云 Seedream 混淆。
6. **SD 1.5**：维持 external/不主推，与社区一致。

### 5.3 不建议

- 用云 API 图模（Seedream/GPT Image）冒充 Civitai LoRA 底模。
- 无 meta 时把任意 checkpoint 名显示为「已完美还原」。
- 为追热点把未验证的 DiT/新底硬塞进同一 SDXL workflow。
