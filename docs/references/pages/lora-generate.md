## 1. 页面职责

Generate 把已选的 LoRA、底模、来源证据、参考图、提示词和真实生成参数组织成一次可检查、可迭代的出图。唯一主工作流：

**装配 → 写一句 → 出图 → 看结果、再改**

来源配方与助手是按需辅助：只能改写或解释装配与输入里的真实内容，不另起第二套生成骨架。发现与收藏归「库 / 收藏」，训练归「训练」，长期资产归素材库。

## 2. 桌面结构

板里不再套卡（ui-spec §1）：**顶上一行 → 台面 → 输入框**，自上而下，直接落在白板上（`.lora-bench` 不铺工作台灰）。⛔ 台名标题、⛔ 「生成 / 训练」切换。

1. **顶上一行**：挂了 LoRA 时一颗浅灰药丸「{LoRA} 出过的图 **N** ›」（左边三张叠着的小圆图）；没挂就空着。行高 36 / 行距 12 不变，助手面板按它对齐台面顶边（`STUDIO_OPERATOR_WORKBENCH_COLUMN_ANCHOR`）。
2. **台面**：只放这次出的图（§2.3）。
3. **输入框**：LoRA 药丸 → 搭配状态条 → 参考图 → 提示词 → 没写进去的触发词 → 负面词 → 工具行（§2.4）。圆角 16、一圈细边，写字时边加深。

**训练**不在台上：入口是 LoRA 库「自训」那一栏第一格虚线「训练新 LoRA」（owner 2026-10-25；挑 LoRA 框里不给），进来是 `?section=train`，顶上一颗「‹ 训练新 LoRA」回到生成。

### 2.1 LoRA 药丸（`LoraMountPills`）

- 挂上的每把一颗浅灰药丸：小圆图 + 名字 + 权重（等宽灰字）；停用的变淡、⛔ 藏；装不上的多一颗琥珀小点。最后一颗「+ LoRA」是这一行唯一的描边药丸，弹「挑 LoRA」框 `LoraPickerDialog`（ui-spec ㉔，锁「和当前底模装得上」）。「从角色选」并进框里左栏的「角色」（owner 10-25），台上没有单独那一颗。助手「打开库」仍去库整页 `/library/lora`。
- 在挑 LoRA 框里刚挂上的那一颗弹进来（`mountEvent`，刷新读回的不演）。
- **点一颗 = 从上方弹出小卡**（宽 300，从药丸长出来）：头 = 小图 + 名字 + 「来源 · 家族」+ 启停开关；权重黑色胖条 + 值（底模不给值域时只写值）；触发词浅底（`highlight-soft`）；装不上时一句「{家族} · 和底模装不上，出图时不生效」；右下文字键「卸下」（⛔ 红色）。
  - 停用 = 药丸变淡，它的触发词同一拍从正文里拿掉（§2.4）。
  - 第一颗是主 LoRA —— 还原、来源图默认分组都取它。⛔ 拖动排序（装配列那套随列一起退了）。
- **版本一排**（ui-spec ㊲ 画了）还没接：挂载栈里的 LoRA 不带别的版本，要换版本得先接 Civitai 版本数据，另做。
- **常与它同挂**不画（10-24 定）；手机照旧。

### 2.2 顶上一行「出过的图」（`LoraSourceBand`）

- 点那颗药丸 = 从这一行长出浮层（分组 + 「N 张」+「点一张看完整配方 · 做同款」+ 缩略图），盖在台面上，⛔ 推图。浮层外 / Esc 收回；点一张缩略图开样例大图时浮层留着，大图开着时点外面 / Esc 只关大图。长出 = 下落 8px + 0.96 放大 + 由糊变清；收回反过来。
- 分组：每把一颗浅色 chip，封面在前、名字截断；选中那颗浅底。Hugging Face 挂载换成样例图 + 提示词；只有示例图没有配方时摆纯预览，作者描述收成一行；都没有写「{名} 没有公开样例」。

### 2.3 台面（`LoraResultStage`）

- 这次出的图**一行 4 张**（图格 `MediaTile`，3:4）：干净无框；悬停变暗、左下浮出「交给助手」白药丸 + 「存成模板」小圆键；点一格看大图。新的在前，本会话，刷新即清（长期归档在素材库 / 画廊）。
- 「交给助手」= 把这一张挂进助手输入区，不自动发送。「存成模板」（契约见 [`prompts.md`](prompts.md)「LoRA 台上的「存成模板」」）存这一张**出图那一刻**的整套，⛔ 读当前输入框；存好换成 ✓。
- 从提示词页「使用」一个 LoRA 模板回到这里（`?template=<id>`）：挂载栈整个换成模板那几把、底模 · 参数 · 提示词 · 负面照存的装好，种子回到随机，⛔ 不出图；装一次就拿掉那个参数。模板打不开（已删）说一句，台上不动。标签台存的与提示词页新建的标签模板「用在 LoRA 台」只换提示词和负面：挂载 · 底模 · 参数不动，正文里原有的触发词留着；加过权重的标签按当前底模的写法落（`(tag:1.2)`，不认括号的底模去掉权重）。
- 生成照「加载态 A」：最前面多一格素底框，框边就是进度线 + 百分比 + 阶段词 + 参数行，右上 × 取消。出图：合拢 → 停一拍 → 线淡出；收尾那一拍就在新图自己那一格上（新图压在白纱下糊着，线松手时变清）。
- **失败就地说**：最前面那一格「没出图 · 原因」+「重试」，线停住变灰。⛔ 不弹 toast、⛔ 不写进输入框。
- 没出过图：台面中间一句话（挂了 LoRA：「写一句提示词，出图后结果在这里」；没挂：「可以直接用底模出图，也可以去「库」挂 LoRA」）。
- Runner 线路生成中图下给一句耗时预估；本会话第一次换成「先加载底模」那句。

### 2.4 输入框

- **搭配状态条**（做同款 / 助手改过、或有装不上的 LoRA 时才有）：「● 搭配 已应用来源配方」；有装不上的多一段「· 1 个 LoRA 和底模装不上，这次不生效 · 换底模」；末尾「查看 / 收起」。点「查看」在状态条下**原位展开**：做同款带来的改动、助手改的，各一行，能撤销的带「撤销」；做同款待审阅时多一颗「应用」。⛔ 触发词不在这条上报（它就在正文里）。
- **参考图**（只在底模吃参考图时）：挂了才在提示词上方出一排缩略（点开看大图、悬停出 ×）。三条来路落到同一份：工具行「参考图」、粘贴进提示词、拖进输入框。
- **平时收薄**（owner 2026-09-29）：没在写字时提示词只露 2 行、负面收成一行预览「负面 · …」、没写进去的触发词那一行收起、「搭配」状态条收成工具行最左一颗「● 搭配」。点提示词 / 负面预览 / 工具行「负面」/ 「搭配」，输入框长回全文、边加深；点输入框以外（弹层与标签补全除外）、Tab 出去或按生成就缩回。
- **提示词**：15/24 的正文，写字时封顶 4 行后内部滚动；标签补全照旧。**触发词就写在正文里**，在正文里浅底高亮（@ 引用那种 `highlight-soft`）；⛔ 出图时不再往正文前面另拼一遍。
  - 挂上作者认过触发词的 LoRA（自训 / 精选 / Civitai `trainedWords`）→ 触发词写到正文开头；停用 / 卸下 → 从正文里拿掉；停用再启用照原样写回。别的时候正文完全归你：删掉的触发词不会被写回来。
  - 做同款 / 还原 / 助手整段改写正文时，原来在正文里的触发词留着（缺了补回开头）；同一个词的不同写法认作同一个，⛔ 不写第二遍。
- **没写进去的触发词**：生效中、但正文里没有的，在提示词下面一小行「触发词 ＋词」，点一下写到正文开头。
- **Runner 出不了图**（总闸关 / 次数用完）：药丸下面一行琥珀字说清楚；平时的「剩 N/M 次」只在底模列表最底下一行。
- **工具行**：左 参考图「＋」· 负面 · 还原（圆钮，只放图标，悬停说名字）；右 底模 · 比例 · 参数 · 黑色「生成」。都是浅灰药丸（ui-spec ㉕），弹层都**从药丸长出来、关上缩回**。
  - **还原**：用这个 LoRA 推荐的提示词、负面词和权重；没挂 LoRA 时变淡、点不动，悬停说为什么。
  - **负面**：点它在提示词下原位展开一行负面词；写了内容就一直在。底模 CFG 恰好是 1（Anima Turbo 一类；或参数里把 CFG 调成 1）时负面词不起作用：药丸变淡、点不动，悬停说「这个底模 CFG 1，负面词不起作用；写的内容留着，换回来还在」；那一行收起、内容留着，出图不带它。判据只有一个：`isRunnerNegativePromptInert`（`constants/runner-checkpoints.ts`）。
  - **底模**（`LoraBasePill`，ui-spec ㊲）：药丸写底模名 + ▾；点开和模型选择器同一种列表：分 SDXL 系 / DiT 系，每行字母小方块 + 名字，快出的（步数蒸馏档）标「快出」，选中那一行浅灰底 + 勾。没挂 LoRA：列纯底模能出图的那些（⛔ 不列「来源图底模（自动）」），默认 **Anima Turbo v1.1**，没有开关；挂了 LoRA：顶上「只看兼容的」默认开，关掉看全部、装不上的变淡写「装不上」。最底下一行 Runner 剩余次数。手机仍是旧的换底模抽屉（`LoraBaseModelModal`）。
  - **比例**：写当前比例；弹层里选比例，Runner 底模再多一格精确宽高。本域一次出一张，⛔ 不画张数。
  - **参数**（只 Runner 底模有，`LoraParamsChip`，宽 340）：药丸写「采样器 · N 步」（CFG 改过再跟一段），都没改过时写底模自带的默认（如「euler · 10 步」），没有就写「默认参数」。弹层里 采样器 / 调度器 = 灰底下拉（没动过写「默认」浅字）；步数（1–100）/ CFG（0–30）= 黑色胖条，值写在右边（也能直接敲，没动过浅字写底模默认，没给时 30 / 7）；Seed「随机 | 固定」、放大「不放大 | 4x-AnimeSharp」= 小号切换条。参数不合法时弹层里就地说、生成键点不动。手机输入栏同一颗。
  - **生成**：黑色文字键（32 高）；生成中写「出图中 Ns」、点不动，取消在台面那一格右上。缺 key 仍可点，点了走 `QuickSetupDialog`。

### 2.5 助手

- 打开 = **工作台让位**：地台右内边距与面板同一根弹簧；台面与输入框变窄，格子跟着变小（还是一行 4 张）。收起反过来。⛔ 不盖住输入框。
- 头像留在顶上一行右端当开关（点开、再点或 Esc 收回）；点舞台与输入框不收。
- 助手搭好一套（新挂 / 卸下 / 权重 / 参数）或给权重、参数建议时出一张**搭配卡**「应用这套搭配」（owner 09-28「一张卡全包」，契约见 `lora-assistant.md` §12）：点了药丸上的权重与参数走到新值，这一轮过程行上的「撤销」一次撤回；⛔ 不直接出图。⚠ 画板里「搭配条同一拍记一条可撤销」不做 —— 撤回只留过程行上那一个入口（owner 09-24）。

## 4. 动效

曲线一律 `--ease-standard`；颜色、数字、滑块线性或跟手；时长只取 120 / 200 / 240 / 320，让位那根弹簧与图片台同一根。每一个「开」都有对应的「关」，关也要真的演。

| 动作                     | 怎么动                                                                                                                                                                                                                            | ⛔ 不做                          |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| 挂上 / 卸下一个 LoRA     | 新挂的药丸从 0.75 弹进来、淡入；卸下那一颗直接收走                                                                                                                                                                                | 不跳位、不留空行                 |
| 停用 / 启用              | 开关 120 线性；药丸变淡与正文里的触发词拿掉 / 写回同一拍。停用时正文里那个词先糊一下、暗下去（320）再拿掉；启用时写回的词从暗、糊变回清楚（`TRIGGER_WORD_PULSE`，那一拍字由背板画、textarea 字透明）                              | 不藏药丸、打字不演               |
| 搭配展开 / 收起          | 原位展开 200 淡入、输入框跟着长高；收起 120 淡出、200 收回                                                                                                                                                                        | 不弹对话框、收起不直接跳         |
| 「触发词 ＋词」一行      | 与负面词同一套原位展开 / 收起；收起那一拍留着上一排字                                                                                                                                                                             | 不直接跳                         |
| 样例大图开 / 关          | 从那张缩略图放大（320）；关上缩回那张（240），焦点回到它                                                                                                                                                                          | 不从屏幕中间弹                   |
| 比例 / 参数弹层          | 以 chip 为原点 0.72 → 1、由糊变清；关上缩回 chip。比例走与图片台同一颗 `SpecChip`（手机那颗 `LoraAspectRatioChip` 也是它）：带小形状的分段条，chip 上比例框弹簧变形                                                               | 不从屏幕中间弹、⛔ 蓝色旧弹层    |
| 出图 / 换一张            | 新图在白纱下糊着（`RESULT_REVEAL` 10px · 1.04），线松手那一下白纱撤、图变清；点这一轮另一张也由糊变清；比例变了框 `SPRING.slot` 拉成新形状                                                                                        | ⛔ 新图直接换上                  |
| 做同款 / 挂载 / 补挂结果 | 做同款点完查看器就关：补挂上的额外 LoRA 走底部黑条（✓「已自动补挂 N 个」+「撤销」只卸这几把；没挂上 = 红点）。手机库 / 我的库「挂载」跳去生成台，黑条带「撤销」。行内「补挂」结果写在那颗键上（✓ / 去 Civitai 找 / 与底模不兼容） | ⛔ 一条黑条两个动作、⛔ 补挂弹条 |
| 助手开 / 收              | 工作台让位与面板同一根弹簧；结果图等比缩放                                                                                                                                                                                        | 不直接跳回                       |
| 应用这套搭配             | 药丸上的权重与参数直接到新值（拖滑杆时跟手）                                                                                                                                                                                      | 不直接出图                       |
| 换底模：点一行           | 勾 120 线性淡入，列表随即缩回药丸                                                                                                                                                                                                 | 不先关列表再换                   |
| 「只看兼容的」开 / 关    | 列表直接换成兼容的 / 全部（手机抽屉照旧淡出 + 位移）                                                                                                                                                                              | 不整块闪一下                     |
| 负面 chip 让开 / 恢复    | 药丸变淡 ↔ 恢复，120 线性；那一行走负面词同一套原位收起 / 展开                                                                                                                                                                    | 不抖、不闪、不直接消失           |

减少动态效果：高度走位、放大、模糊一律换成 120 淡入淡出；滑块与数字照旧跟手；应用权重直接跳到新值。

## 5. 样例大图（生成台）

owner 09-28「这边是不是也一起优化」：生成台点来源图不再开居中弹窗，改成**在舞台右侧就地展开**（库 B 画板「样例大图」同一形）：

- 从那张缩略图放大出来，盖住台面；输入框不动。
- 左：大图等比放到最大（框 = 图的比例）+ 左右切换 + 底下一排缩略轨。右：340 宽的「这张的配方」—— 提示词 / 负面 / 底模 / 采样 / 尺寸，每格可复制；「这张还叠了」列出配方里别的 LoRA（已挂载 / 一起挂 / 不挂）；底部「做同款」+「用原图 seed」，再下一行「复制配方 · 打开来源」。
- 「做同款」只把真实可用的内容写回装配与输入并关掉大图，⛔ 不自动出图；已有输入时进搭配条的待审阅，⛔ 不静默覆盖。
- 来源提示词进输入框前翻成 Runner（ComfyUI）认的写法：`[tag]`、括号外的 `tag:0.65`、`{tag}`、`BREAK`、`(tag:0.8, )` 原样送进去权重会丢，所以写成 `(tag:0.91)` / `(tag:0.65)` / `(tag:1.05)` / 逗号 / `(tag:0.8)`；右侧「这张的配方」里仍是原文。
- Esc / 关闭键退出、← → 换张；关上缩回那张缩略图，焦点回到它。
