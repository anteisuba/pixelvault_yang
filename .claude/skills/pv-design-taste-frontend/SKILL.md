# 前端视觉判断

用于营销页、作品集和已立项改版的视觉方向探索。PixelVault 的设计确认流程见 `docs/scenes/ui-page.md` / `ui-marketing.md`；本技能不指定全站皮肤，也不替代已确认页面方向。

- 从受众、核心任务、内容类型和使用情境推导视觉层级。比较结构与信息优先级，不能把换色或圆角当作不同方向。
- 用字体、空间、比例、素材和动效形成一致表达；具体字体、配色、密度、卡片与材质由业务域决定，不使用跨项目轮换配色或禁止常见字体的规则。
- 以真实内容验证长标题、三语文本、控制密度与手机布局。支持窄屏重排，避免裁切、横向溢出和遮挡主操作。
- 素材必须服务内容；缺素材时说明需求，不自动填假数据、调用付费生成或安装新图标/动画库。
- 动效服务状态、反馈或连续性，支持 reduced-motion。沿用已有动画库，避免逐帧 React state、装饰循环和阻塞主任务。
- 实现前检查已有组件与依赖；复用行为和可访问性，不重新初始化技术栈或未经设计确认改共享样式。
- 最终检查真实交互、焦点、对比度、移动端和资源开销。以可观察问题为依据，不凭“看起来像 AI”判错。

改版提供三个结构明显不同的方向与一个关键切片；局部修复只验证改动处。
