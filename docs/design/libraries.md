## 还没做的

### 1. 规矩：引用存 id

别处用到库里的东西，存 id + 当时的用法（权重、开关），不存拷贝。作品配方列是例外：既存 id 也存快照。删一项时先问「还有谁在用」，答案从这些 id 里数。

### 2. 详情的「谁在用」

库详情五块框架（图 · 怎么用 · 出处 · 谁在用 · 主动作）里「谁在用」还没有：

| 库   | 谁在用                     |
| ---- | -------------------------- |
| LoRA | 挂了它的角色、用它出的作品 |
| 角色 | 她出现的作品、挂的 LoRA    |
| 标签 | 用它的作品、收它的标签堆   |

作品部分依赖保存提示词的配方列（[prompt-save.md](prompt-save.md)）。

### 3. 「我最近用的」排序

LoRA / 角色 / 标签都要有，从作品记录里数，不靠计数字段。同样依赖配方列。

### 4. 统一 @

写提示词时打 `@`，一个搜索框同时搜角色、LoRA、标签，结果分组显示；助手、生成台、画布共用一个。10-21 时助手的 `@` 不认标签，画布节点有自己的一套，是两份。
