# 工作台 · 图片编辑

> 2026-10-01 owner 确认：图片上的「编辑」与主输入框「自然语言 / 标签 / 编辑」进入同一编辑会话；主输入框随编辑任务切换控制项，沿用当前 UI 风格。本文是本轮实现基准，画布复用同一编辑能力。

## 作用域与入口

`/studio/image` 的舞台和主输入框共同承载「编辑当前图片」。图片卡片、结果预览、参考图与顶部「编辑」入口共用同一会话。编辑是一种任务状态，不是第三种提示词方言；自然语言与标签的路由、生成提示词和模型选择保持原有语义。

点击具体图片上的「编辑」即选定该图并切换输入框。直接进入「编辑」而没有明确目标时，显示选图提示，由用户上传或选择图片；不擅自采用第一张参考图或最近生成结果。进入编辑时收起模板等覆盖舞台的面板。界面持续显示当前源图，切换源图清除旧蒙版和定位信息。

## 页面结构

- 顶部沿用当前「自然语言 / 标签」的分段控件，补充「编辑」。点击自然语言或标签返回相应生成模式。
- 舞台展示编辑中的图片、绘制工具和选区。源图、编辑历史与回退沿用既有能力。
- 主输入框展示编辑任务、常显模型入口、对应参数与提交动作。模型入口复用 `ModelChip` / `ModelPickerPopover`，不复用带生成表单副作用的主生成选择器。
- 整图编辑、局部重绘、物体替换显示各自指令输入；移除背景、超分辨率显示任务参数。模型仅列出能执行当前任务的候选。
- 编辑期间只有编辑提交器和快捷键生效；助手普通生成确认保持待确认，禁用生成按钮，切回生成台后才可处理。生成提示词与模型草稿保持独立，切回后恢复。隐藏 UI 不等于卸载生成事件监听。

沿用现有颜色、字体、圆角、间距、按钮和响应式组件，不引入第二套视觉样式。桌面与手机使用相同会话和执行控制器，布局差异仅影响控制区位置。画布保留其宿主布局，复用编辑器与执行行为。

## 任务与模型契约

| 任务                | 输入与语义                                                                  |
| ------------------- | --------------------------------------------------------------------------- |
| 整图编辑            | 单张图片与整体修改指令；有独立可执行能力，不借用尚未实现的 `style-transfer` |
| 局部重绘            | 单张图片、源图尺寸蒙版与指令；只列出接收蒙版的模型                          |
| 物体替换            | 单张图片、编号框及各框指令；编号和文字不烧录进像素，定位提示不承诺硬边界    |
| 提取元素            | 单张图片与已有提取指令                                                      |
| 移除背景 / 超分辨率 | 复用既有模型及参数                                                          |

Ideogram 4.5 使用官方直连和用户自有 Key，图片生成与编辑共享 provider 配置；精确编辑走官方 Precise Edit。旧 `ideogram-3` 记录保留其真实身份，不改名冒充新模型。没有 Key 时进入现有设置流程，不自动切到收费代理。

应用蒙版保持「白色编辑、黑色保留」，仅在 Ideogram 边界转换为官方要求的「黑色编辑、白色保留」。Gemini 当前执行路径不接收位图蒙版，不能作为局部重绘候选。OpenAI 接收蒙版但模型可能不严格遵循边缘，不将其描述为像素级保证。

每个任务独立保留本会话的模型与草稿；切换同任务模型不丢源图、指令和选区。切换任务时只传递合法参数，禁止静默丢弃必需蒙版后继续提交。未实现的任务保持隐藏。

## 执行状态

| 状态     | 行为                                                               |
| -------- | ------------------------------------------------------------------ |
| 无源图   | 显示选图提示，禁用提交                                             |
| 可编辑   | 明确源图与当前任务；局部重绘尚无选区时给出绘制提示                 |
| 缺少 Key | 提供对应 provider 的现有设置入口                                   |
| 执行中   | 冻结任务、源图及重复提交；显示已有进度与错误状态，不虚构可取消能力 |
| 成功     | 使用归档后的结果继续编辑，沿用历史回退                             |
| 失败     | 保留源图、指令与选区供重试；多条注释中已成功项不回滚               |

提交时固定目标快照，异步返回不能写入后来选中的图片。长任务交给已有执行 Worker 与任务轮询，不在 Next 请求中等待完整生成。

## 结果与共享边界

参考图编辑成功后，读取回填时最新的参考列表，仅在原槽位仍指向本会话源图时就地更新；槽位已被替换、移除或其他图片前移到该槽时解除关联，保留派生结果。结果图编辑继续产生派生结果，不额外注入参考图。派生结果使用 R2 持久 URL，沿用 generation 与父图关联。源图提示词与编辑指令分开，机器指令不得覆盖用户生成草稿。

画笔复用 `StudioInpaintEditor`，导出真实源图像素尺寸蒙版；能力复用 `canvas-image-edit-capabilities` 和 `canvas-capability-runtime`。源图尺寸优先使用实测位图尺寸。Studio 与 Canvas 共享 `ImageEditSurface`，不复制提交、轮询或归档逻辑；画布派生节点本身承担历史。

本轮不增加多图编辑、SAM 吸附、箭头指令、跨刷新编辑历史或数据库 schema。所有新用户文案同步 en / ja / zh。

## 验收

1. 图片入口与顶部编辑入口进入同一会话；无目标时可选图。
2. 生成与编辑来回切换，提示词和模型互不覆盖，编辑快捷键不触发生成。
3. 当前任务模型常显且按真实执行能力过滤；没有 Key 不发起付费调用。
4. 无源图、缺选区、执行中和失败状态均有正确反馈；切源图清除旧选区。
5. 参考图槽位更新、结果图派生、历史回退和多条注释重试保持正确。
6. 官方生成、精确编辑、失败轮询、蒙版转换与归档用契约测试验证；实际付费调用单独记录验证证据。
7. 桌面与手机检查布局及完整交互；执行受影响定向测试、全量应用 Vitest、类型检查和 ESLint，Worker 独立验证。
