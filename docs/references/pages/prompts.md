# 提示词页面

2026-09-09 owner 确认独立 `design-suite.html#prompts` 并授权实装；本次确认覆盖提示词页，不覆盖其他 mock 页面。稿件位于本次设计会话的独立预览目录。

## 职责与范围

查找、保存、编辑、复制模板，并将提示词送往对应 Studio。保留当前我的模板 / 共享灵感、类型筛选、权限、发布、clone 与作品血缘。旧域文档中的公共发现迁移不是本次施工内容。不接入新生成能力，不调整数据模型。

## 已确认结构

- 无独立页面大标题或说明横幅；保留紧凑标签导航、新建按钮与搜索。
- 正文优先卡片：无封面直接展示标题与正文，不预留方形图片空位；有封面采用短封面。桌面多列，手机单列。
- 复制、编辑与使用入口可直接触达；无匹配结果可清空搜索。
- 详情有作品时保留作品与正文两栏，无作品时正文单栏。编辑保留全部原有字段，取消还原已保存值，保存失败不丢草稿。
- 使用前说明只替换提示词；复制失败提供可选中的正文，不以失败 toast 作为唯一出口。

## 视觉与共享边界

标志组件为正文卡、紧凑搜索栏、按有无作品收放的详情。用已有字体、语义颜色、Button、ResponsiveDialog 与确认弹窗；不改应用壳或其他域的样式。内容为实底，仅媒体上的小工具可用半透明背景。区别于素材库的图像墙、Studio 的参数与预览分栏。

## 状态与验收

覆盖无模板、搜索无结果、有/无封面、封面失败、详情加载/失败、编辑/取消/保存、复制失败、使用确认。375px 单列与响应式弹层，820px / 1440px 多列；键盘可达、焦点返回、reduced-motion。验证使用定向组件测试、lint、typecheck 与浏览器证据；生成、发布及删除无需在真实账号执行来验证布局。
