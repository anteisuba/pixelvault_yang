# 设计上下文记录

用户要求建立或更新长期设计上下文时使用，日常实现不触发。

读已有 `docs/brand-dna.md`、目标域/page 文档和真实页面，找出已确认事实与尚缺的用户、任务、品牌或可访问性需求。只询问实质缺口，已有答案不重问。

把确认后的全局不变量更新到 brand-dna，域职责更新到 domains，页面方向按 UI scene 确认后更新到 pages。不要把某页风格写成根 AGENTS/CLAUDE 的全站指令；不创建重复设计体系。报告记录位置与适用范围。
