# Model brand assets

These marks replace provider/API-page screenshots in the homepage model rails.
The model name and execution provider remain separate UI fields.

- Source package: `@lobehub/icons-static-svg@1.91.0`
- Upstream: https://github.com/lobehub/lobe-icons
- License: MIT
- Cached slugs: `openai`, `gemini-color`, `flux-text`, `bytedance-text`,
  `recraft-text`, `alibabacloud-color`, `kling-color`, `hunyuan-color`,
  `microsoft-color`, `tripo-color`, `stability`
- ElevenMusic logotype: ElevenLabs official brand resources,
  https://elevenlabs.io/brand (black SVG cached as `eleven-music.svg`)

Model ownership and capability links remain the catalog `officialUrl` values in
`src/constants/models/`; fal.ai is an execution provider, not the visual owner
of the FLUX, Seedream, Seedance, Recraft, HappyHorse, Kling, Hunyuan, TRELLIS,
or Tripo model marks shown here.
