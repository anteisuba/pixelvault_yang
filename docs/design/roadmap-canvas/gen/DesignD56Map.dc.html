存储（Q2 A：新表）
AssistantMemory
一条 = 一行字：text（进系统提示的就是它）· kind（偏好 / 事实 / 规则）· scope（image · video · canvas · lora · global）
溯源三件：conversationId · messageId · createdAt —— 总览页点「来源」跳回那一轮对话
lastUsedAt（被注入过就更新）决定注入优先级与淘汰顺序；pinned 置顶不淘汰
索引 (userId, scope, updatedAt desc) 与 (userId, kind)；删除即真删，⛔ 不做软删
与上下文卡的分界
卡 = 你亲手经营的素材（正文 · 图 · 负面 · 常挂范围 · @ 点名）；记忆 = 助手观察到的一行事实或偏好
唯一的桥：一条记忆可「存为上下文卡」→ 建 ContextCard 并把这条记忆标记为已升格；⛔ 反向不自动降级
写入（即时写）
时机
每轮结账时一次性写，与现有「本轮记住 N 件事」同一时刻；⛔ 不在每条消息后写（半句话的偏好不算数）
回执
「本轮记住 6 件事」保持现状；展开逐条可「改 / 删 / 不要记这类」
「不要记这类」= 落一条 kind=rule 的负规则（下次同类不再记），⛔ 不只是删掉眼前这条
去重
同 scope 同 kind 先做规范化字面去重（空白 · 标点 · 大小写）；命中则更新旧条的 updatedAt 而不是新增
语义去重（近义不同字）本轮不做向量（owner 09-19 定），留到有量之后再看
注入（怎么被用）
每轮只注入当前域 + global 的前 N 条（按 pinned → lastUsedAt 排），⛔ 不是全量倒进系统提示
与上下文卡共用一份上下文预算，卡优先 —— 卡是你亲手挂的，记忆是攒的
每域上限 200 条，超了按 lastUsedAt 最旧淘汰，接近时在总览页提示并给一次置顶机会（owner 09-19 定）
总览页（Q3 A：按域 + 时间线）
位置

隐私（Q4 A：自动跳过 + 手动隐身）
自动跳过
不记的类目：身份证件 · 账号密码 / API key · 健康与医疗 · 私密关系 · 财务账户 · 未成年人信息
服务端判断，命中即不写，且不出现在「本轮记住 N 件事」里 —— ⛔ 不写一条「有一条被跳过了」的提示（那本身就是泄露）

互不依赖
