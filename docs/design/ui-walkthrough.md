# 全站真用一遍 · 优化清单（`r-ui-walkthrough`）

2026-11-13 第一轮。Claude 在生产站（owner 账号、电脑 1470 宽）按「第一次来的朋友」的路径真用了一遍。标准：吸引人，核心路径简单方便。

**这一轮覆盖**：首页、新对话、聊天出一组图、看大图、图片台、标签台、LoRA 台、配音间、3D 台、画布（只打开）、素材、角色列表、画廊、提示词库、LoRA 库、设置首屏。
**还没覆盖**：角色详情与陪聊、画布里新建并出一镜、视频、LoRA 训练弹窗、剪辑台、出门、手机宽度（浏览器窗口缩不到手机宽，要换办法）、英 / 日文、未登录与新账号（没有 key 时的样子）。

## 实测：说一句到出图

首页写的是「说一句，她替你做完」。实际：点「新对话」→ 输入「画一只在窗边打盹的橘猫」→ 等 18 秒 → 她回「现在只是聊天模式，我改不了图，你切到上面那个工作」→ 手动点开关 → 再说一遍 → 等约 40 秒出确认卡 → 点确认 → 约 50 秒出四张。**共三次操作、约两分半**。图的质量和她看图后的点评都好。

## 一、挡住新人（先改）

| #   | 问题                                                                                                                             | 建议                                                                                                     |
| --- | -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| A1  | 新对话默认落在「聊天」模式的角色身上，第一句「画…」被拒，要用户自己找开关                                                        | 去掉手动开关：她自己判断这句是聊天还是干活；或至少说了「画」就自动切过去接着做，不让用户重说             |
| A2  | 各台同时有两个输入框（左助手、右台），两个发送键、两个模型名，不知道该往哪打字                                                   | 一屏只留一个主输入框。助手开着时台的输入框收成参数条，或反过来；需要出方向稿                             |
| A3  | 公开首页首屏和画廊第一行有近裸图                                                                                                 | 首页图带和画廊默认只放全年龄（施工单早有此条，线上没生效），成人内容要登录后自己打开                     |
| A4  | 新对话空白页只有一句「想做点什么？」，没有任何可点的例子                                                                         | 放三四个可点的开场（画一张图 / 和她聊聊 / 做个短片 / 看看我的图），点了就填进输入框                      |
| A5  | 对话里点开大图只有图，没有下载、收藏、改这张、上一张下一张                                                                       | 大图底部加一排动作：下载、收藏、拿它接着改、左右切换                                                     |
| A6  | 确认卡给中文用户看一整段英文标签，还有一行「有 2 个按 Danbooru 换了写法…」；橘猫这种题她选了 NovelAI（首页自己写着它只画二次元） | 确认卡默认只显示一句中文说明 + 张数 + 花费，英文提示词收进「看提示词」；模型挑选规则按首页那张表核对一遍 |
| A7  | 设置首屏是十几家服务商的 API key 列表，全是「已配置 · 未校验」                                                                   | 点数上线后首屏改成「余额与用量」，key 列表收进「自己接服务商」                                           |

## 二、拖慢、让人犹豫

| #   | 问题                                                                                                 | 建议                                                                             |
| --- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| B1  | 左边竖条 14 个图标没有字，# 是标签、两个图片图标分别是图片台和画廊，要挨个悬停才认得                 | 默认展开带字；或按「做 / 库 / 我」分三组并各配组名                               |
| B2  | 花费的说法每个台不一样：约 $0.03、Opus 订阅免费、0.5 积分、免费                                      | 统一成点数，一个写法                                                             |
| B3  | 第一句回复前等 18 秒只有「正在想」；出图过程是四个灰块                                               | 先回一句短的再干活；灰块上显示进度或预计秒数                                     |
| B4  | 四张结果在 1400 宽的页面里排成两列小图，中间空一大块，要滚动才看全                                   | 四张一行排满，一眼看全                                                           |
| B5  | 换到任何台、甚至画布，左边都跟着同一段对话（在别的项目画布里显示橘猫那段）                           | 画布按项目各有各的对话；台之间跟随可以留，但要有一眼能看出的「这段对话在聊什么」 |
| B6  | 画布打开是 10% 缩放，卡片小到看不清；底部工具条 11 个无字图标                                        | 打开时自动缩放到看得清最近改动的那一块；工具条常用的几个带字                     |
| B7  | 出图后输入框上方自己多出一张缩略图和「将看 1 张」，没有解释                                          | 改成一句人话，例如「接下来会参考这张」并能一键去掉                               |
| B8  | 对话里出现内部用语：自己看图再改 · 第 1/1 轮、专属、思考 Medium、DeepSeek V4.1 Flash                 | 对朋友默认隐藏模型与思考档位（收进「更多」），内部用语换成人话                   |
| B9  | LoRA 库第一屏是 Civitai 的热门（大量真人写真封面），不是「我的」；整个 LoRA 区没有看到「训练」的入口 | 默认先看我的 / 收藏；训练做成 LoRA 区第一眼能看到的入口（配合训练专做）          |
| B10 | 首页要滚十几屏，全程只有右上角一个「进入工作台」；滚动中有整屏空白的时刻                             | 首页首屏放一个真能打字的输入框，打完进工作台接着做；空白时刻补上                 |

## 三、打磨

- 图的名字是「图\_2129·very aes」这种截断的英文，换成她起的中文短名。
- 提示词库的卡片是成段英文标签，看不出是哪一张图的，改成以图为主、文字为辅。
- 浏览器标题还是「ANTEI | 个人 AI 画廊」，和现在的定位对不上。
- 新对话默认是谁（这次是 Aemeath 而不是 ANTEI）没有说明，新人不知道为什么换了人。
- 3D 台空着时中间是一个白模占位，没有说这个台能做什么。

## 做得好的（留着）

- 新对话页本身很干净；素材页、角色页的排版清楚好看。
- 出完图自动入库，素材页马上能看到。
