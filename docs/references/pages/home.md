## v6 · 她 + 一个窗口（2026-11-11 定稿）

### 一句话

首页只讲一件事：**她是谁，她能替你做什么。** 舞台上只有两样东西——左下角的她，右边一个窗口；作品、对话、结果全在窗口里演。窗口和产品里的白板同一个长相，所以首页就是一次产品预演。舞台演完是一份「模型她来挑」的名单，最后是页脚。

- 舞台是一块 `position: sticky` 的整屏，钉在一条长轨道上（合计 1530vh）；舞台里的一切变化只由滚动位置算出来（每段一个 0–1 的进度），**⛔ 定时器推进**。例外只有这些：作品墙图片第一次载入时由糊变清、点语音卡播放、她的待机小动作、⑤ 里小鲸的话一个字一个字出、④ 的成片到位后自己播。
- 段与段之间只有一种换场：**整条对话往上推一个窗口高**，上一段出去、下一段从下面进来是同一个动作，⛔ 中间清空成空镜。第一屏到 ① 也是这个动作。
- 顶栏是现成的那条（见「顶栏」），钉在视口最上面，从头到尾都在。
- 不要的东西（都是讨论里否过的）：⛔ 输入框、⛔ 先放大再缩小的「你那一句」、⛔「她帮你画」这类段标题、⛔「图片台 · …」过程行和图下的模型名、⛔「画画中 · 2/4」这类进度字、⛔ 挑图打勾那一步、⛔ 结尾再来一面作品墙、⛔ 整屏翻页、⛔ 3D 炫技、⛔ 左栏「她能做的」能力列表（第 42 轮）、⛔ 剪辑台（第 50 轮）、⛔ 成片跟着滚动逐帧走（第 51 轮）、⛔ 在窗口里摆两张角色卡让人选（第 42 轮）。

### 第一屏：作品墙

- 内容：画廊里最新的公开作品，只用图（服务端读，沿用 `homepage-showcase.service.ts` 的取法）。画廊全年龄（owner 11-11），公开闸已拦住成人内容（`lib/content-safety.ts`）；存量盘点脚本 `scripts/audit-public-content.ts`。
- 排法：电脑四列、手机两列的瀑布，内边距 12、间距 10、圆角 12；每张放进当前最矮的一列；太长的图高宽比封顶 1.5。整组排两遍，保证四列往上走时底下不露白。作品墙自己裁成一个窗口高，⛔ 压到下面第一段。
- 载入：每张图由糊变清（14px → 0，0.5s），按顺序错开 70ms，左上往右下。实现用现成的 `components/ui/load-reveal.tsx`，⛔ 另写一份。
- 往下滚（第一屏那 130vh）：0–100% 四列各自往上走，速度分别是窗口高的 0.12 / 0.34 / 0.20 / 0.44 倍；25–70% 那一句淡出并上移 30px；35–100% 整条对话往上推一个窗口高，① 从下面进来；窗口底部一层 120px 的白色渐隐和「往下滚」三个字，0–12% 淡掉。

### ① 出图（240vh）

- 你那句：「一只戴圆框眼镜的橘猫馆长，坐在美术馆前台，胸牌写着「馆长」，身后挂满画框，暖光，浅景深」（四张图出图时的原话）。
- 四张图连成长带：电脑上同时看得见两张，宽度正好撑满内容区（高度不够时上下裁一点）；手机上一张。每张在 18% + 15%×i 开始、用 14% 由糊变清并上浮 18px；从第三张起，每来一张带子往左走一格，走出左边的那张淡掉。
- 素材：`public/homepage/production/quad/quad-*.webp` 四张（同一句提示词）。

### ② LoRA（300vh）

- 你那句：「抱着黑皮书的女孩，米白大衣。换几种画风看看」。
- 左半：一张全身图（宽 = 内容区一半减间距），四种画风叠在同一张卡里；一道白线从左刷到右，刷过的地方露出下一种，连刷三次。每种画风左上角一个小标签：扁平线稿 / 偏线稿 / 偏手办 / 手办质感。
- 右半：四种画风的 2×2；没刷到的格子是浅灰占位，刷完一种填上一格，当前那格描一圈黑。手机放不下右半，只留那一张。
- 素材：`public/homepage/production/lora/lora-body-1..4.webp`。

### ③ 配音（240vh）

- 你那句：「给今晚的画展配三句：温柔的女声，少年，再来一段旁白」。
- 三张语音卡排满内容区：卡高 `min(150, (内容区高 − 2×间距) / 3)`（手机封顶 92）；头像、台词、波形、播放钮都按卡高等比放大。卡依次出现，波形条随后一格格长出来。
- 波形高低从真实音频里量；点播放钮才播，播着时她哼歌，播过的波形变黑；同一时刻只播一条。卡没完全出现时点不了。
- 素材：`public/homepage/production/voice/voice-{qing,lei,ke}-{zh,ja,en}.mp3` 与头像（按页面语言取）。

### ④ 画布（320vh）

- 你那句：「做一支 30 秒的短片：下雨天，两个人撑一把伞回家」。故事用站内自产的《借伞》（`public/homepage/production/umbrella/`：五张关键帧 + 30 秒成片）。
- 画布是一张世界（节点 + 连线，世界坐标 1140×610）放在内容区里，点阵底随镜头一起缩放。节点照产品画布的卡片样子（圆角 18、两层淡投影）：
  - 左列：角色卡（小满）、分镜（五行，一行一行出现）、三句台词（头像 + 波形）。
  - 中间两列：五个镜头图 → 五个片段。
  - 右边：「成片 · 借伞」，里面是那支片子（带字幕和时间码）。
  - 连线是贝塞尔曲线，跟着节点出现从头画到尾。
- 镜头：先贴近左上看清角色卡和分镜，节点摆完拉远看全图，最后推到「成片」节点上，片子撑满内容区宽度的九成。
- 片子：镜头推到位以后自己播（静音、循环），字幕跟着片子的时间走；这一段滚走了就停。**⛔ 跟着滚动逐帧拖**（第 51 轮）。
- 手机：一条横着走的镜头带（分镜卡、五个镜头图、成片），不画连线。

### ⑤ 换角色（300vh）

- 你那句：「今天换个人陪我吧」。她答应「好呀，我去叫小鲸～」，然后退场（往左下滑出）。
- 整页底色从左往右被一道白线刷成浅海蓝 `#e6eff5`（`clip-path` 刷），刷完以后页面底色一直是蓝的，到页脚都是。
- 小鲸从她原来的位置滑进来，话是一个字一个字出来的：「……嗯，我是小鲸。说话慢，画画不慢。」
- 窗口里：一行系统字「ANTEI 去休息了，小鲸来了」→ 你问「这张你觉得怎么样？」→ 左边一张图（① 里的第二张），右边两张小卡：「ANTEI · 上次说」原话 /「小鲸 · 现在说」逐字出现「……嗯。它坐得好稳，像一块礁石。我喜欢。」。换了角色就换了语气，靠这两句对比看出来。
- 小鲸：`gpt-image-2` 出的图\_2075，抠掉白底的透明图（小样里是 512px 预览 `her/whale-2075.webp`，施工时换原图）。只做静态图 + 轻微上下浮动，不进 WebGL 动作。

### 模型她来挑

- 舞台松开以后的一段，正常滚动。标题「模型她来挑」横跨整页，下面一句「你只管说。用哪个，她定。」。
- 左栏（230–330px）是小鲸，钉在视口左下角（`position: sticky`），头顶是她的话，一个字一个字出；大的舞台滚走以后她才出现，⛔ 同屏两个。
- 右边一份名单，分图片 / 视频 / 声音三组，表头「找它的时候」「不找它的时候」。每行：图标、名字（**只写家族名，⛔ 写型号**：更新太频繁）、两句话。图片组：GPT Image、Gemini、Seedream、NovelAI、LoRA（注「不是模型，是挂在模型上的」）；视频组：Seedance、Wan、MiniMax；声音组：Fish Audio。
- 停在一行上（手机是点）：这一行变成白卡、其余变淡，往下展开一条素材，小鲸说一句偏心话；离开收起。每行展开的素材条一样高（电脑 `min(240, (宽 − 72) / 4.35)`，手机 190），从上一行挪到下一行版面不跳。
  - 图片：每家三张按各自长处出的图 + 一张同题橘猫；NovelAI 是五张二次元（三人同框 + 四种画风）；LoRA 是同一个人的四种画风。
  - 视频：各一段片子，展开就播（静音、循环）。
  - 声音：三个声线 × 三种语言，点了才播。
- 优缺点文案是查过 2026 年评测后写的（第 53 轮，来源在讨论记录里），⛔ 写会过期的数字（秒数、分辨率、语言数）。
- 图标：OpenAI / Gemini / ByteDance 用 v4 首页当年的官方标路径（现在在 `HomeV6Mark.tsx`）；NovelAI、MiniMax、Fish Audio 用 lobe-icons（MIT，同 `public/homepage/production/models/brand/SOURCES.md` 的来源）；Wan 用官网 favicon；LoRA 是自画的叠层小图标。
- 素材：小样里在 `.claude/mockups/home-v6/samples/`、`nai-*.jpg`，都是 512px 预览，施工时从图库换原图（编号见讨论记录第 47、49、52 轮）。

### 她

- 现在只有一张头像原图（`.claude/mockups/home-v6/her/her.webp`，2000×2000，左边和下边是裁开的）。表情和动作由 `.claude/mockups/home-v6/her.js` 驱动（WebGL 网格变形 + SVG 叠层），施工时搬进首页域的一个客户端组件；不支持 WebGL 时退成静态图。
- 表情跟着进度切：第一屏 `happy` → 推进时 `read` → 干活时 `work` → 每段结束 `wow` / `proud`；播语音时 `hum`。
- 性格：**元气，有偏心**。台词只有两种时刻，干活时不出声：

| 段       | 开头答应           | 结束时                                       |
| -------- | ------------------ | -------------------------------------------- |
| ① 出图   | 好嘞，马上画！     | 出来啦！第二只最像馆长，就是看起来有点凶～   |
| ② LoRA   | 换画风？交给我！   | 同一个她，四种画风！我偷偷最喜欢线稿那张。   |
| ③ 配音   | 三个声音，没问题！ | 配好啦，旁白那句我念了三遍才满意，快点开听！ |
| ④ 画布   | 好嘞，先写分镜！   | 做好啦！我最喜欢第三个镜头的绣球花～         |
| ⑤ 换角色 | 好呀，我去叫小鲸～ | （小鲸）……嗯，我是小鲸。说话慢，画画不慢。   |

台词要出日文、英文两版，语气照这一版；小鲸慢、安静，句首常带「……」。

### 顶栏

- 用 v4 留下来的那条（`HomeV6Topbar`，第 54 轮 owner：「直接用本地做好的那个」）：居中胶囊，宽 `min(100vw − 28px, max(50vw, 560px))`，半透明白底加模糊，钉在视口最上面；左边 ANTEI，右边语言切换和一颗门。
- 门的文案和行为照旧：未登录「登录」（打开 `AuthDialog`），已登录「进入工作台」（路由常量，⛔ 手写路径）。按钮在 Clerk 解析出来之前就画出来。
- ⛔ 舞台里再放「开始」；⛔ 头像、齿轮、额度、key 数、红点（owner 2026-09-20）：设置只有一个门（登录后侧栏最底，`settings.md` §入口 D3），个人主页也是壳里的东西；营销首页是未登录访客的门厅，把壳的 chrome 搬过来只会让「设置在哪」各多出一个答案。
- 服务端没有登录态，首帧一律画「登录」，页面接管后再按登录态换字（不然已登录的人一打开就是一次 hydration 不匹配）。

### 页脚

左栏对齐她那一列（名字 + © ANTEI），右栏对齐窗口左边；⛔ 不放语言切换和「开始」，顶栏一直在（owner 2026-11-11，小样 19）：

1. 三段说明并排，各一句：**页面上的作品**「都来自 ANTEI 画廊里公开的作品。」（不署名：公开就默认所有人可见，依据是服务条款第 6 节）· **AI 生成**「页面上的图片、视频和声音都是用 AI 生成的。」· **模型名称**：名单里八家的名称和标志属于各自的公司，没有隶属关系。
2. 服务条款 · 隐私政策 · 内容准则（`ROUTES.TERMS` / `PRIVACY` / `GUIDELINES`，三页都在 `Legal` 命名空间）。

### 手机（< 761px）

名字和那一句在最上面；窗口在它下面、到她头顶为止；她在左下（`S = min(28vh, 52vw)`），回话在她右边。作品墙两列，长带一次一张，LoRA 只留那一张，语音卡台词最多两行，画布是镜头带。名单每行竖排（图标、名字、找它、不找它各一行），素材条横向滑，三张猫横滑。施工时要单独过一轮。

### 减少动态效果

`prefers-reduced-motion` 下不钉、不推进，直接停在最后一段的结果；作品墙图片直接出现；她和小鲸不做动作；小鲸的话直接整句出现；片子不自动播。⛔ 取消滚动本身。

### 工程约束

1. 服务端优先：标题、台词、名单、页脚文案都在首个 HTML 里；舞台和名单各一个客户端边界；保持 `revalidate = 3600`。开场版面（她的大小、标题、窗口位置）同时写在 `home-v6.css` 和 `stage-engine.ts` 的 `layout()` 里，首帧就排好，JS 接管时不跳；改一边要同步另一边。
2. 滚动推进用原生滚动 + `position: sticky` + 一个按 rAF 合帧的滚动进度；不需要 GSAP。只动 `transform` / `opacity` / `clip-path` / `filter`。
