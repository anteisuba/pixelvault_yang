这句话同时修好文档和代码的吵架。今天文档说「名片不进提示词」，代码却把它连进视频时收割成参考图。改法：承认递照片是功能，把它说出口——不再有人猜。
另一条路：让连线只当占位、不递照片。那就得给「递照片」另开一个动作。不推荐——多一个动作，多一份要学的东西。

06 · 关系

三个动作，各一个意思。

四种说法收成三个动作，芯片退休当收据。

唯一绑法 拉线

供料、出演，都是它。视频、镜头图、名片，一视同仁。

同一条线 @ / 槽架

在右面里点名，落到画布还是那条线。入口两个，事实一个。

改意思 拖进名片

不再是连线，是归档：收进档案，计数跳一下。拖了必有回音。

从卡顶撤下 顶上芯片

它不是第五种绑法，是收据。收据搬进右面，只读。

先别动

这四条不是幸存者，是样板。

留视频：收着是窗，打开才下单
留打开详情时，节点不变形
留散图、参考视频：卡就是媒体
留身份卡只出不进（入线不画）

整套修法，就是让其它节点向这四条看齐。

动工顺序

三刀，一次扫尾。

第一刀

右面归一

一个位置，按物种出面，闸只写一处。声音的画图框在这一刀里死掉。

第二刀

镜头图、片盒换脸

收着改空窗，说明书和合并键搬进右面，声音芯片剪掉。

第三刀

身份卡换名片

名片脸、出演递照写明白、拖放给回执，一次改完。

扫尾

小修六件

空态、起名、进标、上限、回音、关键帧。

顺序就是依赖：先有右面，第二刀的说明书才有地方搬；名片的「出演」也要写在右面里，所以它排第三。
