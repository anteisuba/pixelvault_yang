## UI 需求卡

1. 页面 / 域： `/studio/image`（Studio Image，生成模式）· `<1024`（`useIsMobile`）。桌面 `≥1024` 不变（左参数栏 + 右结果区）。
2. 用户来这里完成的一件事： 说想要什么 → 出图 → 看图 → 继续（选模型/规格/参考图，输入提示词，点生成，看结果，改一改再生成）。
3. 改什么（范围）： 空态起手屏（示例卡 + 继续创作）、底部固定 composer（模型/规格/参考图 chip 行 + 提示词输入 + 生成按钮）、模型选择改为 `MainModelPicker layout="drill"` 抽屉、规格 sheet（含收纳的负面提示词字段）、生成后结果滚动与动作区。助手现走移动端 Sheet，收起头像位于顶栏下方，避免与账号入口重叠；不改视频/音频模式的验收范围（同壳可复用，未验证）。
4. 状态矩阵： 空（未生成，起手屏 + 教程轮播）· 加载（生成中，composer 占位不变、结果区占位格）· 有内容（结果已出）· 错误（生成失败 / 缺 API key）· 禁用（生成按钮：空提示词或未选模型）· 选中（模型/规格/参考图 chip 的已选态、抽屉/sheet 打开态）。

## 默认模型选型规则（owner 2026-09-03 拍板，写入 constants 层）

1. 优先取 localStorage 记录的「上次使用模型」（key 待定义于 `src/constants`，命名遵循现有风格）。
2. 若无记录，取当前可用图片模型中价格最低、且其 provider 已配置 API key 的一个。
3. 若两者都不满足（无历史、且没有任何已配置 key 的图片模型），保持模型为空态，生成按钮点击时路由到 `QuickSetupDialog`（Hard Rule 8：缺 key 不禁用 UI，走内联配置）。
4. 禁用态按钮文案与选择器占位文案必须不同——今天两处都写「请先选择模型」是需要修的重复，落地时改成本卡表 5 最后一行给的两句话（或等义替代，只要不同）。

## 备注

- 本卡的模型/规格/参考图 chip 状态仍归 `studio-context.tsx` 与既有 hooks 所有；chip 与抽屉/sheet 只是移动端呈现层，不新增独立 state 源。
- composer 高度由 `ResizeObserver` 实测回写 `--studio-mobile-composer-height`，舞台底部留白随内容和模型参数展开同步；高级模型参数默认收起。
- 标签台移动端按 2026-09-30 本会话确认，参考 PC 改为上方结果区、底部固定标签编辑框。默认只展开正向，负向点击展开并保留已有数量；整体／角色共用 PC 分页和编辑状态。工具分两行：图像／模板／查资料／角色构图／画中文字；模型／尺寸／参数／生成。模型与尺寸直接打开既有选择器，采样器、步数、CFG、UC 预设和种子进「参数」弹层，支持的模型单独显示「画中文字」入口和已填字数。长标签内部滚动，软键盘出现时编辑框避让；模板、资料与构图仍在上方舞台打开，返回后保留编辑内容。桌面布局和 provider 能力契约不变。
- 教程轮播与 composer 的层级顺序：教程轮播不得覆盖 composer 的点击区域，二者 z-index 需要显式约定（落地时在组件里写明，不在本卡展开像素值）。

## 2026-09-22 · 图片模型选择

桌面与手机共用同系列多选规则：GPT Image 的多个型号可同时出图；选择 Seedream 等其他系列时替换整份名单，并重置专属参数。系列以模型目录为准，不以渠道判断；未登记系列的型号独立处理。旧草稿的跨系列额外选择不进入费用计算、选中显示或生成请求，删除主模型时也不会重新启用这些旧选择。

## 2026-10-02 · 输入条改「Claude 式最简」（owner 拍板，取代上表 composer 两行与空态示例卡的写法）

- **输入条 = 一张输入框卡**：挂着的参考图条（有才出现）· 提示词整宽 · 一行 `＋ · 模型 ▾ · 规格 ▾ · 专属 ……… 生成`（36 圆键，出图后 ↻，多张时角标）。模型 / 规格是无边幽灵丸（卡自己有边，⛔ 框里套框）。
- **「＋」**（`StudioMobileAddSheet`）：上半截 = 参考图（上传 · 最近素材 · 素材库，与桌面 chip 同一份 `ReferenceImagePickerBody`）；下半截一行一项：模板（开舞台面板）· 角色（抽屉内推进一页）。选了角色时「＋」灰底。
- **模型参数（专属）在规格旁边一颗**（owner 2026-10-03，⛔ 不收进「＋」）：与桌面工具行同一颗 `StudioModelCapabilityChips variant="single"`，收成无边幽灵丸；这一轮没有可调项时不渲染，视频档不挂。
- **写法切换**（自然语言 / 标签 / 编辑）挪到舞台卡左上角，与标签台手机同一位置；⛔ 不再在输入条里，「模型参数」折叠行删除。
- **空态示例卡只有字**（标题 + 两行提示词），⛔ 不借「继续创作」的真图当封面；真图只在「继续创作」那一行。
- **助手头像**落在 `MobileShell` 顶栏右端那一格（`STUDIO_OPERATOR_MOBILE_SHELL` 上 4 / 右 12），⛔ 不再浮在舞台上压结果图与面板头部；各面板为它留的 `pr-12` 已撤。
- 视频台同一副输入条：「＋」上半截是与桌面「素材」chip 同一份菜单（图 · 参考视频 · 音频，挂满 / 不收灰着写原因），下半截 模板 · 剧本；素材排（`StudioVideoAssetRail`）在输入框卡顶上；出声开关只在规格抽屉里；费用行在卡上方一行。

## 2026-10-04 · 手机上下两张卡（owner：「像 PC 一样」）
