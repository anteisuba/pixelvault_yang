布局 1 / 2 / 3 同一件事：画橘猫馆长四张，再改一次。皮肤三版一样，只比摆法和用法。输入框能打字，回车出一组

A 她就是输入框

整个产品只有一个输入框：对话。台变成对话旁边的「舞台」，只放她做出来的东西和这次的设置，不再收字。像 Claude 的对话 + 右边面板。

试：在左边输入框里写一句回车；或者打开「照原话出」，她就不改写、原样去出。
跟现在比
  • 台上那个输入框没了，一屏只剩一个地方打字（解 U1）
  • 模型、比例、张数、LoRA 变成舞台顶上那一排设置，对话和台用同一套（解 U6）
  • 左栏只剩 对话 · 图 · 视频 · 声音 · 我的；标签 / LoRA 是「图」里的写法和挂件（解 U2）
  • 代价：想自己一字一字写提示词的人，要多开一个「照原话出」

B 台为主，她在旁边

台是主角，整块白板都给台；输入框只有台上那一个，里面一颗「帮我写」，点了她就地把这句改好。要聊天再从右上角叫她出来，从右边滑出，不占位置。像 Krea。

试：写一句，点「帮我写」看她改；点右上角头像叫她出来。
跟现在比
  • 对话不再常驻在台左边，一屏只有台的输入框（解 U1）
  • 工具行常年放得下，六颗都带字（解 U4）
  • 标签 / LoRA 变成输入框里的「写法」和「+ LoRA」，图只有一个台（解 U2）
  • 代价：助手退成配角，和现在「助手为核」的路线方向不同

C 一条流

不分台。顶上一条输入框，切图 / 视频 / 声音 / 3D；下面是你做过的所有东西，按那一句归成一组，最新的在上面。画廊、素材是这条流的筛选。像 Midjourney 的 Create。

试：顶上写一句回车，新的一组出在最上面；每组悬停有「再来 / 做成视频」。
跟现在比
  • 七个台、画廊、素材合成一页，左栏只剩 创作 · 我的 · 库（解 U2）
  • 首页就是这条流，来了就看到最近做的（解 U3）
  • 出图、找旧图、再用旧图在同一页做完
  • 代价：画布、剪辑这类长活儿放不进一条流，要另开；助手也要从右上角叫
