# 场景导航

按 [WORKFLOW](../WORKFLOW.md) 路由选择一个主场景，跨层任务再加相关场景。各 scene 保留领域特有契约、证据与禁改范围；澄清、授权和验证分级由 WORKFLOW 统一维护。

场景自查先由 agent 从对话、代码、官方资料回答，不与通用问题叠加为固定问卷。模板用于确有需要的新结构或交接，不要求机械填满；checklist 只执行本次变更适用项，发布另过完整 release 门禁。

具体场景：UI 内页、营销页、API、service、模型、数据库、测试、bug、研究、发布；文件与对应验证见 WORKFLOW 路由表。owner 起手示例见 [PLAYBOOK](../PLAYBOOK.md)。
