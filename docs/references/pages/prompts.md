## 职责与范围

查找、保存、编辑、复制模板，把模板送回对应的台。保留「我的模板 / 共享提示词库」两个 tab、权限、发布、clone 与作品血缘。

- **类型只有四格：全部 · 图片 · 视频 · 标签。** ⛔ 音频那一格去掉（owner 2026-09-28：音频有提示词没什么用）；已有的音频模板不删，留在「全部」里。新建弹窗也不再给音频，音频结果上的「存配方」一起拿掉。音频台自己的模板面板照旧。
- **标签模板 = 写 Danbooru 标签的三种来处合成一格**（owner 2026-09-28）：标签台存的（整组：标签 · 各角色 · 负面 · 模型与参数）、LoRA 台存的（整套，见下）、在这里新建的（只有标签与负面）。徽章都是「标签」，来处另写一小格：LoRA 台存的是反色「LoRA」角标，另两种写「存自标签台」「在这里新建」。
- **LoRA 模板存整套**（owner 2026-09-28）：挂载的几把（名字 · 链接 · 权重 · 触发词 · 来源，与装配台那一份记录同形）· 底模 · Runner 参数 · 提示词 · 负面。从 LoRA 台结果上的「存成模板」来（见下）。判据：模板的 `params.loraSetup` 在，或旧存的 `params.advancedParams.loras` 非空。
- 在这里新建的标签模板没有模型：库里记标签台默认的 NAI 型号只为占格，⛔ 界面不显示、套用时不换模型。
- 「共享提示词库」、手机、图片 / 视频模板这一轮不动。

## 结构（桌面）

- **一行筛选**：搜索（占满、打字就筛）· 类型 ▾ · 排序 ▾（最近用过 / 最近新建）；改过的那一格浅灰底（同库 B）。下面一行写真实数量「N 个模板」。
- **网格**：4 列，容器变窄时 3 / 2 / 1 列。卡片 = 类型（标签模板再加来处）· 名字 · （LoRA 模板多一行「名字 权重」）· 正文 · 元信息（模型或底模 · 第 n 版 · 日期；在这里新建的没有模型那一段）。标签模板的正文画成一格一格（前 7 个，多的写「+N」），有作品的另放封面；别的模板有作品放封面、不铺正文，没作品铺正文前五行。悬停出「复制 · 使用」。⛔ 卡片上不放删除 / 编辑（在详情里）。
- **详情是一页，从下往上升**（同库 B）：头部「‹ 返回 · 名字 · 类型 · 第 n 版 · 日期」，右上「使用 · 复制提示词（标签模板写「复制标签」）· 编辑 · ⋯」（⋯ = 发布 / 取消发布 · 删除）。左边这一套出过的作品（大图 + 一排缩略，没出过写「还没出过作品」）；右边一条窄栏：
  - 标签模板：（LoRA 台存的先放搭配「名字 权重 · 底模」与参数）标签 · N、负面 · N（负面只描边）、各角色（标签台存的、分了角色才有）各一墙格子；
  - 图片 / 视频模板：模型 · 提示词 · 负面。
- **编辑**：右栏换成表单，保存 = 新一版，取消还原。图片 / 视频模板 = 名字 · 提示词 · 负面 · 模型；标签模板的标签与负面用和新建一样的格子输入、没有模型（LoRA 台存的仍是原文框：它的提示词原样送回 LoRA 台，格子会改写括号与换行）。标签台存的改负面时，整组参数里那一份一起改。
- **使用**：
  - 图片 / 视频模板：跳回对应的台、只换提示词（沿用现有的预填）。
  - 标签模板：**每次问一句去哪**（owner 2026-09-28）。「使用」键长出一个小下拉，两行各写一句会换掉什么，存出来的那一台标「存自这里」：
    - 用在标签台：标签台存的 = 整组替换（标签 · 角色 · 负面 · 模型与参数）；另两种只换标签和负面，模型与参数不动。到了标签台照它自己的套用演，带「撤销」。
    - 用在 LoRA 台：LoRA 台存的 = 底模 · 挂载 · 权重 · 参数 · 提示词 · 负面原样装好，⛔ 不直接出图、⛔ 不带种子（种子回到随机）；另两种只换提示词和负面，挂载与底模不动，加过权重的标签按当前底模的写法换成 `(tag:1.2)`（不认权重的底模去掉权重）。
  - 每次「使用」记一次最近使用时间，「最近用过」按它排（没用过的按新建时间排在后面）。
- **空态**：搜不到 = 写明是哪个条件没有 + 放宽的出路（去掉类型 / 清空搜索 / 去共享提示词库）；「标签」一格一个都没有 = 说明三个来处（标签台、LoRA 台结果上「存成模板」，或在这里新建）。

## 新建

类型是三格分段：图片 · 视频 · 标签。图片 / 视频 = 名字 · 提示词 · 推荐模型（只列这一类的）· 服务商 · 负面。选「标签」后提示词大框换成两块格子输入（标签 · 负面标签），一格一个词，回车或逗号写进一格，边打边联想（本地标签表）；⛔ 没有模型那一行。底下一句「用在哪一台，点「使用」时再选」—— 角色分组在标签台存，LoRA 整套在 LoRA 台存。

## LoRA 台上的「存成模板」

结果图右上角、「问助手」旁边一颗同形的图标键。存的是**这一张出图那一刻**的整套（出图时就地记下，⛔ 读当前装配台 —— 出图之后动过的不算）；服务端核对挂载链接与这张图实际用的一致。存好了键换成「已存成模板」，toast 带「去看看」。结果条刷新即清空，所以素材库 / 画廊里旧的 LoRA 图走原来的「存为模板」只存得到链接与权重，名字按收藏记录补，补不到就写「LoRA」。

## 动效（照 `PmMotion` · `TgMotion`）

- 开详情：从下 32px 升上来并淡入，320；关：下沉 32px 并淡出，200，回到网格原来滚到的位置。
- 悬停卡片：「复制 · 使用」120 淡入，卡片投影 120；⛔ 不放大卡片。
- 筛选与搜索在本地，结果立刻换；⛔ 不清成白屏、⛔ 不转圈。
- 复制：那颗键的字换「已复制」1.2 秒再回来，⛔ 不弹 toast。
- LoRA 模板「使用」：装配列多出来的几行走到位（同装配列挂载的那一拍）。
- 「使用」下拉：从键长出来（以键为原点 0.72 → 1、由糊变清，spring-slot，同工具行 chip 弹层）；收起缩回键里 200 + ease-in，⛔ 直接消失。
- 格子输入与标签台同一颗组件、同一套动效：写进一格放大落进来、浅底褪掉；删掉一格缩小淡出 120，后面几格滑过去补位 200。
- 新建切类型：提示词大框与两块格子交叉淡入淡出 200，弹窗高度跟着内容走 200，⛔ 先塌再撑。
- 减少动态效果：位移、缩放换成 120 淡入淡出。

## 状态与验收

覆盖：没有模板、搜不到、有 / 无封面、封面失败、标签模板三个来处（LoRA 台新存的整套 / 旧存的只有链接）、详情加载 / 失败、编辑 / 取消 / 保存、复制失败、使用（图片 / 视频 / 标签模板两个去处）、新建三种类型。键盘可达、焦点返回卡片、reduced-motion。手机（<1024）这一轮不重做：同一套组件在窄容器下单列、详情页全屏。验证用定向组件测试、lint、typecheck 与浏览器证据；生成、发布、删除不在真实账号上执行来验证布局。
