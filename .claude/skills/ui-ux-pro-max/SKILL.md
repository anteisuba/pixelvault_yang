# UX 模式检索

用于交互模式、响应式、可访问性或设计方向确有缺口时检索本技能的数据；局部 bug 不强制生成设计系统。项目确认流程与外观归属见 `docs/scenes/ui-page.md`。

先从现有页面/域文档确定要解决的问题。按本技能实际路径运行 `python3 <skill-dir>/scripts/search.py --help`，选择对应 domain 或已安装技术栈的查询。只有方向探索才考虑 `--design-system`；检索结果是建议，不覆盖 owner 已确认规范。

- 可访问性：键盘、焦点、标签、对比度、非颜色表达。
- 交互：主要任务、可发现性、错误恢复、加载与空态。
- 响应式：内容优先级、触摸目标、长文本与窄屏重排。
- 性能：测量真实瓶颈后再修改，动效支持 reduced-motion。

不运行 `--persist` 生成另一套 MASTER/page 规则；稳定结论写到现有 `docs/references/`。不按示例自动安装 Python、UI 库或更换框架。只引用有助于当前决策的检索结果，最终验证实际页面。
