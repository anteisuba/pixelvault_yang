# OpenCLI 搜索路由

用户指定 OpenCLI 或需要其站点适配器时使用；不拦截已有官方文档搜索或浏览工具。

1. 首次使用核对 `opencli list -f yaml`，再读所选站点/命令的 `-h`。本会话已核且未变化的帮助可复用。
2. 用户指定来源就按指定来源；技术契约、价格与模型能力直接优先官方一手资料。AI 站点只作线索或用户明确要求的比较来源，不能替代原始证据。
3. 查询聚焦主题、目标和时间/范围；不足时按明确缺口补查，不无依据重复。遵守实际限流、登录和访问边界，来源失败时尝试适当替代并说明未覆盖内容。
4. 引用实际打开的来源与日期，区分事实、推断和未核实内容。通常不输出逐次调用台账，只有审计可追溯性需要时再提供。

按需在 `references/` 查找相应主题的站点线索（tech、social、media、info、shopping、travel、other、ai）；候选源以实时 registry 为准。
