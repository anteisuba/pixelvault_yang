## C · 「情感到位」怎么做

业界目前收敛出四种手段，且**互相叠加**而非替代：

1. **行内标记**（ElevenLabs v3 白名单 tag / Fish S2.x 自由词表 / Higgs 21 tag / Gemini `[whispers]`）——控**句内瞬时**表情，粒度最细。
2. **整段自然语言导演指令**（OpenAI `instructions` / Hume acting instructions / Gemini Director's Notes / 豆包 2.0 指令式）——控**通篇基调**，2026 的主流范式，正在取代 SSML。
3. **参考音频借情绪**（Fish reference audio / IndexTTS-2 情绪音频与 emo 向量、音色情绪解耦 / Seed-Audio 多模态参考）——最可靠的"像不像那个味儿"，也是唯一能把音色和情绪**分开**调的路子。
4. **LLM 先标注再合成**（把台词交给文本模型自动插 tag，产物过校验只准加标记不改词）+ **A/B 变体并排试听**——把"调情绪"从玄学变成可比较的选择题。

对照 `docs/references/domains/audio.md §2.1` 的四层栈：

- **L1 表现力三档**：ElevenLabs stability(1.0/0.5/0.0)、Fish temperature、Chatterbox `exaggeration`、IndexTTS-2 `emo_alpha` 都能直接编译；OpenAI / Gemini / Hume **没有数值旋钮**，三档得编译成指令句（「克制地朗读」/「自然」/「充满戏剧张力」），语义等价但不可精确复现。
- **L2 行内标记**：Fish S2.1-Pro 自由词表（含 `[slightly …]` 程度前缀）是目前最贴合本设计的；ElevenLabs v3 需白名单映射 + 剔除未知词（已定案）；豆包 2.0 **不吃标记语法**，得把 L2 降级编译成 L2' 指令句；OpenAI 同理。
- **L3 情绪导演（LLM 自动标注）**：与 provider 无关，任何吃标记或吃指令的模型都能受益；产物过 `llm-output-validator` 的约束不变。
- **A/B 变体**：全部模型可做；Fish free 档（`s2.1-pro-free` $0）让"4 变体并排"几乎零成本，这是现成的便宜实验台。
- **多人对话（播客/角色台词）**：真正**原生**支持的只有 ElevenLabs Text-to-Dialogue（v3）、Gemini multi-speaker、Fish S2.1-Pro multi-speaker、Seed-Audio 1.0。OpenAI / Hume / 豆包 TTS 只能逐句合成后拼接——正好是 audio.md §2.2 已定的编排 service 形态，不是阻塞项。
- **音色情绪范围元数据（§3）**：IndexTTS-2 的 8 维情绪向量是唯一能**量化**标注"这张卡能驾驭哪些情绪"的现成来源，自托管档若上，可用它给音色卡自动打情绪范围标签。

**推荐组合**

- **云端主档：Fish Audio S2.1-Pro 留任**。自由词表 + multi-speaker + 83 语 + $15/M 字节（比 ElevenLabs v3 便宜约一个数量级，1M 字节≈12 小时语音），既已是 BYOK 又同时满足 L1/L2/L3 和播客管线，没有换的理由。`s2.1-pro-free` 直接当 A/B 变体与回归测试的免费实验台。
- **云端情绪特档：ElevenLabs v3 保留**，只在"角色台词 / 多人对白出彩"时按 Text-to-Dialogue 走（stability 三档已是 A3 默认逻辑的落点）。价高，定位成高价档而非默认。
- **中文 / 方言特档：豆包语音合成 2.0（BYOK）**是最值得新接的一家——¥5/万字符（约合 $0.07/K 字符，低于 ElevenLabs 一档）、400+ 音色、粤/沪等方言、复刻 5–10s、首包 <300ms。代价是要把 L2 行内标记编译成指令句，属于 per-provider 编译层已规划的工作量。
- **观望：Seed-Audio 1.0**——一条 prompt 出对白+BGM+音效，正好覆盖 audio.md 的 speech/sfx/music 三个 kind，但仍在邀测且官方定价未公布，先记入远期插座（与 A4 的"MiniMax / ACE-Step 留远期"同档）。
- **自托管备档（RunPod 单卡 24G）：Qwen3-TTS-1.7B（Apache-2.0）为主 + Fun-CosyVoice3-0.5B（Apache-2.0）为副**。两者都是自由许可、中日英全覆盖、显存小、有 ComfyUI 集成，可商用无附加条款。情绪做到"到位"再上 **IndexTTS-2**（情绪控制最强，但 bilibili 许可商用需申请，上线前必须先拿授权）。**避开**：Fish-Speech 权重（研究许可）、Higgs v3（非商用）、F5-TTS（CC-BY-NC）——PixelVault 是收费产品，这三条在商用上都不干净。

## 「字节 sudo」核实结果

**owner 说的大概率是 `Seed-Audio 1.0`（音译近 "Seedo/sudo"）**，字节跳动没有任何叫 sudo 或 Seedo 的语音产品。当前对外的三条线：

1. **Doubao-Seed-Audio 1.0（豆包音频生成模型 1.0）** — 2026-06-23 FORCE 原动力大会发布，一条 prompt 端到端出多角色对白 + BGM + 音效 + 环境音，长时音色一致，支持文本/音频多模态参考，20 语言。火山方舟 **API 邀测中**，官方定价未公布（第三方 Segmind 报 $0.18/分钟，非官方口径）。→ [ByteDance Seed](https://seed.bytedance.com/seed_audio)、[发布报道](https://finance.sina.com.cn/tech/digi/2026-06-24/doc-inienieh3154674.shtml)
2. **豆包语音合成模型 2.0（Doubao-Seed-TTS 2.0）+ 声音复刻 2.0（Doubao-Seed-ICL 2.0）** — 2025-10 发布，这是**当前可直接接的生产 API**，指令式情感控制、400+ 音色、WS 首包 <300ms、¥5/万字符后付费。→ [产品页](https://www.volcengine.com/product/tts)、[计费说明](https://www.volcengine.com/docs/6561/1359370)、[音色列表](https://docs.volcengine.com/docs/6561/1257544)
3. **Seed-TTS** — 2024 年的研究模型/论文名，不是商品名；现在对外的商品名一律是"豆包语音合成"，模型 ID 前缀 `Doubao-Seed-`。

命名对照：Seedance = 视频；Seed-Audio = 音频；**Seedo / sudo 不存在**。要接的话，短期落地选 ②（豆包语音合成 2.0，走火山引擎 BYOK），①作为远期插座观察邀测转正式与定价。
