## 0. 范围 / 非目标

**范围**：四类节点的收起 / 选中 / 展开 / 生成中 / 快速看 五态；提示词栏与它的弹层；模型选择器；@ 引用；剪辑台；画布外壳（顶部 / 左侧 / 底部 / 助手 dock / 小地图）；随之而来的少量数据与服务改动（§8）。

**非目标**：助手 tool-loop 本身、剪辑台的渲染层选型之外的实现细节、移动端（本轮桌面优先，375 只保证不坏）。

## 1. 通用语言（四类节点共用，逐条都是硬约束）

1. **卡就是内容本身**。卡面上只有产物（文字 / 图 / 波形 / 封面）和名字，没有卡头、没有标签、没有按钮。名字是卡外上方一行小字，选中时变深。
2. **身份不上卡面**。角色 / 背景 / 镜头图 / 剧本 / 规则这类子型只在节点一览、连线落槽和 ⋯ 菜单里出现。
3. **上传的和生成的是同一张卡**。区别只在有没有提示词与版本。空卡是虚线框 + 一句提示「上传 · 粘贴 · 或写提示词」，粘贴不做按钮（⌘V）。
4. **选中 = 两件东西浮出**：工具条居中悬在卡上方（纯图标 + 悬停标签，3–5 键），提示词栏居中在卡下方（一条 44px 玻璃胶囊）。卡两侧永远留空给连线。
5. **提示词栏 = 加号 · 正文 · chip · 发送**。chip 数量上限 3，每颗都是一个弹层的入口，弹层贴 chip 出现，Esc / 点外关闭。正文超 4 行内部滚动并显示字数，不弹大编辑器。
6. **模型选择器走方案 A**：列表只有型号，系列退成分组标题，顶部「最近」+ 搜索；行第二行显示自动选中的渠道与单价（规则：自己的 key ＞ 平台免费额度 ＞ 最便宜）；多渠道的行尾出「N 渠道」点开行内单选并记住；chip 只显示型号名，手改渠道才附「· 渠道」；缺 key 的型号灰显可点，点了进内联配置。**同一套也替换 studio/image 的三栏对话框。**
7. **@ 引用**：正文里 @ 图 / 视频 / 语音 / 角色卡 / 文本节点，渲染成带 16px 缩略（语音为波形小标）的灰底 chip，可整体退格删除。@ 是把素材挂到槽上的主路径之一（§8.2）。
8. **版本 = 卡下一排小点**（选中态可见），←→ 或点切换；连线永远拿当前版本；旧版本可在 ⋯ 里拆成独立卡。
9. **生成中 = 裱框显影**（同 studio/image）：沿卡边描边进度环 + 中心大百分比 + 阶段文案，45s 后呼吸态，完成时描边收拢 → 停 → 内容缩放淡入；提示词栏收起变灰并可取消。矮卡（音频）例外：波形位置走一条进度线 + 百分比。
10. **双击 = 快速看**：原比例居中的大图 / 播放器 / 波形，只有版本、下载、关闭，没有参数；Esc 或点空白关闭。
11. **展开 = 画中框**（仅文本与视频）：节点原地不动并保持选中环，框居中浮起，画布压暗；框顶只有名字与关闭；框底是这类节点自己的生成行；最底一条只属于写作助手（LLM），**两种模型不混**。
12. 动效：展开 / 收起 / 让位走弹簧三档，hover 与颜色走 `--duration-fast|base`；浮层用玻璃材质，卡面不透明。
13. **「连到镜头」弹层**（音频 / 图片 / 文本三类卡工具条上的那颗键）：顶行「新建镜头」（在右侧落视频卡并连线，原「生镜头」行为），下面按镜头带顺序列出画布上已有的视频卡（缩略 · 名 · 时长），点一张即连——音频连成音轨，图片再选首帧 / 尾帧，文本连成镜头说明；目标槽已有内容时显示「替换」而不是静默覆盖；连完目标卡短暂高亮并滚到可见。与拉线（自动落槽）、视频卡 + 菜单 / @ 三条路汇到同一份槽绑定。

## 2. 文本节点

- 收起：名字 + 正文（成行截断，六行）；hairline 边；无卡头。
- 选中：工具条 `@ 提及 · 生图 · 生镜头 · ⋯`（⋯：改名 / 复制 / 拆成多段 / 删除）；助手栏 = 「让助手写一段…」+ chip `续写 · 改写 · 写作模型`；结果直接写进正文，可 ⌘Z。
- 展开（画中框，640 宽）：顶栏 名字 · 角色分段（剧本 / 风格 / 角色）· 关闭；正文即 Markdown 文档可编辑、可 @；框底 读数「N 字 · M 段」+ 快捷键；最底助手栏同上。失焦即存。
- 双击名字改名；单击选中；双击卡面展开；Esc 收起。

## 3. 图片节点

- 收起：卡即图，按真实比例，名字在卡外。空卡见 §1.3。
- 选中：工具条 `生镜头 · 编辑 · 下载 · ⋯`。生镜头 = 以这张图为首帧新建视频节点并连线；编辑 = 局部重绘 / 扩图 / 抠图 / 换背景，结果作为新版本回卡；⋯ = 改名 / 复制 / 拆出当前版本 / 设为角色卡 / 删除。
- 提示词栏：`+`（上传 / @ 角色风格 / 从素材库）· 词 · chip `画面`（比例 / 质量 / 分辨率 / 张数，底部实时算尺寸与单价）· chip `模型`。回车 = 生成新版本。
- 参考图三条路都进提示词栏：@、+ 上传、⌘V 粘贴。卡面不显示槽。
- 无画中框；双击快速看图。

## 4. 音频节点

- 一个节点；**音色是属性**，不是另一张卡。矮卡 72 高 = 左侧播放钮 + 波形 + 右侧时长；点钮播放 / 暂停、波形走进度；**不悬停自动播、不双击**（无快速听、无画中框）。配乐 / 音效是同一种卡。
- **三条来路**：上传；**选一段现成的**（声音库面板：平台样本 / 我的历史 / 配音间 / 素材库 / 收藏，每条 试听 · 「用这段」· 「设为音色」——「用这段」把原声直接落进这张卡，不生成、不扣积分）；写台词回车生成。直接落进来的声音没有提示词与版本，改台词并回车才第一次生成。
- 提示词栏：`+`（上传音频 ⌘U / 从素材库选… / 声音库… / @）· 台词 · chip `音色`（只管 TTS 用谁的声：我的音色 + 克隆，底部语速 / 音量，「更多…」进声音库）· chip `模型`（三组：语音 Fish S2.1 Pro / 配乐 ElevenLabs Music / 音效 ElevenLabs SFX——选了模型就定了类型；配乐 / 音效时没有音色 chip）。
- **语气写进台词，不做 chip**：选中一句 → 工具条「加语气」浮层（情绪 / 语气 / 强度 / 自定义描述），插成行内标记 chip；UI 是 Fish 方括号标记的编译器，克隆音色照用，一段可多情绪。
- 工具条 `加语气 · 裁剪 · 转文字 · 连到镜头 · 下载 · ⋯`。**裁剪** = 卡下方的提示词栏换成裁剪面板（大波形 + 两端手柄 + 入 / 出点读数 + 只播选区的试听；I / O 设入出点；Esc 取消），「裁剪为新版本」非破坏地落进版本点，原音留作上一版；音频裁剪在客户端做（WebAudio 解码 → 按入出点切 → 编成 WAV → 走现有上传管线落成新版本），不扣积分；视频裁剪走 S9 渲染 worker（同一套手柄）。转文字 = Fish ASR 转写后**派生一张文本节点并连线指回**（不写回本卡，转写中卡上走进度线）；生镜头 = 新建视频节点并把这段当音轨；⋯ = 改名 / 复制 / 拆出当前版本 / 归属角色… / 来源（只读）/ 删除。
- 台词里可 @ 文本节点（取正文当台词）或 @ 角色卡（取它绑定的音色）。同一条栏复用在视频卡的 @语音 与剪辑台的「加一句台词」。

## 5. 视频节点

- 一个节点兼上传 / 生成；16:9 空卡；有片时卡即封面，右下角只有时长；悬停静音自动播 + 底部细进度线 + 右上静音标。
- 连线自动落槽：连进来的第一张图 = 首帧，第二张 = 尾帧，视频 = 参考，语音 = 音轨。卡面不显示槽。
- 选中：工具条 `续拍 · 抽帧 · 下载 · ⋯`。续拍 = 以最后一帧为首帧新建下一段并连线；抽帧 = 截当前画面落成图片节点并连线指回。
- 提示词栏：`+`（上传 / 首帧 / 尾帧 / 参考视频 / 语音 / @ / 素材库）· 词 · chip `7s · 16:9`（时长按模型档位 / 比例 / 清晰度 / **生成声音开关**，开着时 chip 尾显示「· 有声」）· chip `模型`。已挂的首帧 / 尾帧 / 语音以栏首行小 chip 显示，可点开可退格删。
- 展开（画中框，720 宽）：上半大播放器（进度 / 声音 / 抽帧 / 下载，版本小点）；下半镜头说明文档，**@ 直接指定首帧 / 尾帧 / 语音 / 参考**（不设槽位行），可编辑；说明页脚 = 视频参数 chip + 视频模型 chip + 「重新生成 ⌘↵」；最底一条只属于写作助手（改写 / 续写 / 写作模型）。
- 生成中裱框显影，视频有真实进度就用真实的。
- 双击快速看片（播放器只有播放 / 进度 / 声音 / 下载 / 关闭，←→ 切版本）。
- **不做合成节点**。多段合成去剪辑台。

## 6. 剪辑台

- **形态**：画布的全屏模式（URL 只加 `?mode=edit`），不是节点、不是新页；退出回画布，项目上下文共用。皮肤走脊柱浅色，不强制 dark；密度按 HIG 取（段高 52）。
- **入口**：顶栏「剪辑台」；多选视频卡后工具条「进剪辑台」；视频卡 ⋯「加入剪辑台」；⌘K。
- **布局**：顶栏 48（回画布 · 成片名 · 时长/比例/清晰度 · 撤销 · 导出）；左 44px 图标栏（画布素材 / 素材库 / 音频 / 文字 / 转场）+ 236 面板（画布素材按卡拖进时间线）；中 预览；右 240 属性（选中段：来源节点 · 入点 / 出点 · 速度 · 原声 · 转场 → · 「回节点重生成这段」）；下 时间线（工具 分割 / 转场 / 文字 / 语音 / 配乐 / 删除 · 主轨道磁吸开关 · 标尺 · V / A / M 三轨 · 播放头）；最底一条「一句话排片」栏（写作模型 chip）。
- **片段永远记得来源节点**：段上显示来源 chip；上游节点出了新版本 → 段上出「上游已更新」徽标，一点换新。改画面的事交回节点，不在剪辑台再开生成入口。
- **一句话排片**：只摆时间线，不花积分；提案以虚线幽灵段落在轨道上；右上提案卡「采用 / 逐段看 / 撤销」；逐段看时右栏显示该段理由，可单段采用或跳过；采用后才写入时间线，整批一个撤销条目。
- **导出**：范围 整条 / I·O 区间 / 单段；「导出到画布」开关，成片落成一张视频卡（成片）并连线指回各段；断点续传。
- **快捷键**：空格播放 · S 分割 · ⌫ 删段 · I / O 入出点 · ⌘Z · Esc 回画布；PR / FCP 预设二选一。
- **渲染层**：换掉现有 fal `ffmpeg-api/compose`（只能尾裁、无转场 / 变速 / 字幕 / 混音）。一期 = Operator 输出时间线 JSON → 自建 ffmpeg 跑在 Cloudflare Container，CF Workflows 编排，R2 收发；xfade 前的规格化（同分辨率 / 帧率 / 像素格式 / timebase）单独一步。二期选段智能化（ffmpeg scdet / blurdetect 粗排 + Gemini Flash 精排）。三期生成式接镜 / 延长（Seedance 2.5 edit / extend，其次 Wan VACE）。调研：scratchpad `video-edit-models.md`。

## 7. 画布外壳

- **顶部**：左上项目胶囊（保存状态点 · 名 · ▾），点开 = 搜索 · 最近项目（缩略 · 节点数 · 时间）· 新建；重命名 / 复制 / 删除在 ⋯。右上只有「剪辑台」「助手」。
- **左侧**：44px 图标栏四项 节点一览 / 角色·风格卡 / 素材库 / 历史；面板 264 宽浮在画布上，再点图标收起。节点一览 = 搜索 + 四类分组，每行缩略 · 名 · 子型 · 引用数，点定位。
- **加节点没有常驻加号**：双击空白弹五颗小图标（文本 / 图片 / 声音 / 视频 / 上传）就地落空卡；右键空白菜单（新建四类 + **上传… ⌘U** + 粘贴 / 整理布局 / 适配视图）；⌘K 命令面板（搜节点定位 · 新建 · 上传 · 问助手 · 剪辑台 · 切项目）。上传 = 系统选文件（多选），按 MIME 落成图片 / 声音 / 视频卡，落点在双击 / 右键的位置。
- **底栏**：选择 / 手 · 缩放% · 适配 · 整理 ‖ 撤销 / 重做。
- **助手**：右上键开右侧 dock，可拖宽、可收成一条；小地图常显可收成右下一颗。
- **快捷键**：T / I / A / V 新建四类 · ⌘U 上传 · ⇧A 整理 · ⇧1 适配 · ⌘K · ⌘N 新项目 · Esc 收起。

## 8. 随之而来的数据与服务改动（最小）

1. **子型不再驱动渲染**：四类各一个组件按「空 / 有产物」两态渲染；`subtype` 保留为数据与落槽依据。
2. **@ 引用 → 槽绑定**：文本 / 镜头说明里的 @ 携带槽角色（`@首帧 xxx` / `@尾帧` / `@语音` / `@参考` / 无角色 = 参考），解析后写进 `slots` 并建边；退格删 @ 即断槽。与拖入、连线三条路汇到同一份 `reconcileStateSlots`。
3. **音色是音频节点的属性**：`audio` 节点数据带 `voiceProfile`（已有）；声音库读 `VoiceCard`；台词里的行内情绪标记编译成 Fish 文本（新增纯函数 `compileVoiceMarkup`），语速 / 音量走 `prosody`。
4. **模型选择器数据**：型号 × 渠道二维，`resolveChannel(model, userKeys, quotas, prices)` 一个纯函数；用户手选渠道按型号记住。studio/image 复用。
5. **剪辑台**：新增 `EditProject`（时间线 JSON：tracks / clips{sourceNodeId, sourceVersion, in, out, speed, transitionOut, muted} / audio / music）落在画布项目状态里；渲染任务走新 `render-video` worker（CF Container），进度与产物回 `Generation`；「上游已更新」= 对比 `sourceVersion` 与节点当前版本。
6. **视频合成节点 `video.merge` 退役**：迁移为剪辑台的 `EditProject`（每个 merge 节点 → 一个时间线），旧组件删除。

## 9. 排片

原则：一片一个代理、一片一提交；每片过 `full-gate` + `verify-real`（真机三张：1440 / 展开或弹层 / 375 不坏）；共用文件按片分家；设计已过门，代理**按画板落**，不得自行改布局。**对稿验收**：每片提交前把真机截图与对应画板并排比对，逐项列偏差（尺寸 / 间距 / 圆角 / 材质 / 字号字重 / 文案 / 各状态），偏差不清零不提交；画板确有问题时先改画板再改代码，不允许代码单方面偏离。
