## 1. 页面职责

角色页是**她的档案 + 她的生活记录**：她是谁（设定）、长什么样（造型 · 图 · LoRA · 声音）、最近做了什么（出门带回的见闻 / 观点 / 表情包、日记、和你的关系、她改了自己的什么）。

不负责：聊天本身（只给「和她聊」入口）、出图 / 训练（2026-10-30 起 ⛔「用她 ▾」，「和她聊」= 换成她）、LoRA 挂载（只读她收了哪些）、工作助手的记忆（设置 › 助手）。表情包 ⛔ 进素材库，素材库也 ⛔ 看到它们。

最高频任务：① 看她最近带回什么、删掉不想要的；② 改设定、撤回她自己改坏的；③ 换造型 / 加图；④ 和她聊。

## 2. 骨架（电脑 ≥1024）

外壳照 ui-spec §1（64 图标栏 + 白板）。白板左右两栏，中间一道 `line` 分隔，两栏各自滚：

- **左栏「她」**（380 宽）：栏头 52 = ← 返回书架 · 名字 （「用她 ▾」2026-10-30 已删）。下面依次：立绘（当前造型主图，4:5，左下「图\_N」）→ 造型药丸一排（当前那套黑底，末尾「＋」）→ 这套的图一行 5 格（最后一格「+N」，点开走查看器）→ 声音 / LoRA 药丸（声音点了试听，LoRA 只读）→ 设定行。
- **右栏「最近」**（余下宽，内容最宽 760 居中）：栏头 52 = 「最近」 · 「和她聊」（本板唯一黑色主按钮）。下面依次：出门卡 → 筛选切换条 → 按天分组的时间河。

### 2.1 设定行（左栏）

- 一行 = 灰字标签 + 一行截断的值；顺序：身份 · 说话方式 · 底线 · 心情 · 和你的关系 · 经历 · 示例对话 · 开场白 · 外观（跟着当前造型，标签写「外观 · 雨天」）。酒馆字段（简介、系统提示词、世界书等）收在最后一行「更多」里，照现有 `SettingTavernGroups` 的分组（电脑端 2026-10-30 起是常开的「酒馆」组）。
- **点哪行哪行原地展开**（owner 10-28）：撑成输入框（焦点环），一次只开一行；「完成」或点外面就存。⛔ 整栏切编辑模式、⛔ 弹窗。
- 她自己写的格（和你的关系、学到的说法）照常能改，标签后带灰字「她自己写的」。

### 2.2 「现在」卡 + 出门调查（角色大项目第 ⑤ 步，owner 10-29/10-30 定）

电脑 / 平板在详情左栏「现在」下面（`CharacterOutingCard.tsx`），手机仍在「最近」顶上。**你点一次去一次**：⛔ 开关、⛔ 每天定时、⛔「7 天聊过才去」那几条规则（定时任务 `/api/internal/characters/browse`、`browse*` 列、`PUT …/browse`、`POST …/browse/now` 都已删）。

- **没出门**：「上次调查：昨天」（从没出过 =「还没出过门」）+ 白钮「出门调查」（「和她聊」才是这块板唯一的黑钮）。
- **调查中**：「在 B 站看『古籍修复』· 12 / 30 点」+ 进度条 + 白钮「结束」。页面每 3 秒悄悄重读一次（`CHARACTER_OUTING.pollMs`），收工就停。
- **弹框**（一次性，`ResponsiveDialog`）：
  - 模型：助手同一颗 `StudioOperatorModelChip`（缺 key 就地 `QuickSetupDialog`），记住上次那个（下架了回落「自动」，「自动」存成当时挑中的具体型号）；下面小签写它能看什么（文字 / 图片；Gemini 多「视频 / 声音」——只让 Gemini 听，owner 10-30）。按钮在弹框里是一颗药丸（`inDialog`），选单往下弹、自己挡滚动（外层弹框锁滚轮会让它滑不动，owner 10-30 反馈）。
  - 来源：「自动」（这个模型去得了的都去）+ B 站 · YouTube · Danbooru · Civitai ·（Grok 才有 X）· 网页 + 她常去的网址（最近几趟加过的）+「＋ 添加网址」（规整成域名，用模型自带网搜 `site:域名`，最多 8 个）。YouTube 和网页一样要模型自带网搜（`site:youtube.com`）。
  - **指定视频**（第 ⑥ 步，owner 10-30「一起贴更好」）：「＋ 添加网址」里贴 B 站 / YouTube / X 的视频链接 = 黑色「▶ 指定视频」小块（可点 × 去掉），后面可写 `3:00-5:00` 只看那一段（YouTube 的 `t=` 当起点）；b23.tv 短链认不出。最多 4 个，⛔ 记住上次。一趟开头先看这几个，她一定写一句（已看过的那条见闻改成这次的）。共用 `lib/outing-video-link.ts`，服务端再认一遍。
  - **看视频**（第 ⑥ 步，owner 10-30 选 C）：来源下面单独一块，只列选中（自动 = 全部）且能看视频的来源（B 站 / YouTube / Grok 的 X），每行名字 + 常驻提示 + 开关（`ui/switch`），记住上次。开 = 真看：Gemini 下 B 站 360P（不登录）整段看 + 听、YouTube 直接交链接；别家看得了图的看 B 站 24 格分帧拼图（预览雪碧图）；X 由 Grok 的 X 搜索开 `enable_video_understanding`。关 = 只看评论区（B 站热评 + 弹幕；YouTube 拿不到评论，只看标题简介）。YouTube 不是 Gemini → 开关灰着「换 Gemini 才能看」；看不了图的模型 B 站同样灰着。
  - 额度（点）：10 · 30 · 60 · 自定（5–200）；下面一行「约 N 篇文章」（1 篇 ≈ 1.5 万 token）。
- **额度一点都不超**（owner 10-30「额度不能超」）：1 点 ≈ 1 万 token，跟模型无关。每次调模型前按上限估一把（字数当 token、每张图 1600、回答留 1500，模型自带网搜一次按 8000），估得超了就收工；provider 报回来的才是实扣。回来写日记那一份（8000）从一开始就留着。看视频按「秒数 × 每秒 token（每帧 258 + 声音 32）」估（`CHARACTER_OUTING_VIDEO`）：逛到的最多看 5 分钟、每秒 0.5 帧、一轮最多 2 个，估得超了退回只看评论；指定的最多 30 分钟、每秒 1 帧，额度不够截短到够的那么长（少于 20 秒才不看）。Grok 看 X 视频一段按 3 万算、估时按一次最多 3 段。
- **中途「结束」**：看到的照样留着、照样写日记（owner 10-30「2 对的」）。
- **收工**：额度到顶 / 你点结束 / 连着 2 轮一条新的都没有或 15 轮到顶 / 出错（key 被删等）。回来写一篇日记（`writeJournal`，同聊天整理那一篇）、记一笔用量（`ApiUsageLedger`，`requestCount` = 调了几次模型）。
- **一段跑不完**（Vercel 300 s）：跑满 230 s 放掉占位、自己调 `/api/internal/characters/outing`（`Bearer CRON_SECRET`）接着跑；没接上的话角色页读状态时发现占位过期也会接上；30 分钟没动静记失败。
- **细看带图**（owner 2026-10-29）：图先由服务端取下（B 站封面带 Referer）再交给模型，取不到的那张单独去掉、只看标题。每轮一行 `character browse outing` 日志、每趟收工一行 `character outing finished`。

### 2.3 时间河

- 筛选切换条六格：**全部 · 见闻 · 观点 · 表情 · 日记 · 改动**（`liquid-segmented`）。筛到哪类，出门那条里只露这一类；整条一类都没有就不画。
- 按天分组（今天 / 昨天 / 周二 / 10 月 24 日，照 ui-spec §2 相对时间），组内新的在上；每条左边一列等宽时间 `HH:MM`。
- 河里四种事件：

| 事件 | 头一行                                                                               | 内容                                                                                                       | 动作                                                        |
| ---- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 出门 | 「出门逛了 B 站 · Danbooru」+ 灰字「5 条见闻 · 2 个观点 · 3 张表情」+ 箭头           | 见闻（她口吻正文 `reading` + 「站名 · 域名 ↗」）· 观点（`fill` 浅底一行「观点：……」）· 表情（72 方格一排） | 见闻 / 观点「删除」；观点「改」原地变输入框；表情点一下拉黑 |
| 改动 | 「改了自己的「说话方式」」+ 灰字理由（对话里改的写「对话里改的」）                   | 旧值划线一行 + 新值一行                                                                                    | 「撤回」→ 换成「已撤回」，⛔ 再撤                           |
| 日记 | 「写了日记」                                                                         | 正文                                                                                                       | —                                                           |
| 失败 | 挂在那次出门里，`danger-soft` 一行「X 没连上，这次没扣额度。其余几站照常带回来了。」 | —                                                                                                          | 「重试」                                                    |

- **一次出门 = 一条，可折**（owner 10-28）：最新那次默认展开，其余折着只露头一行；点头一行开合。⛔ 平铺全部、⛔ 未读计数。第 ⑤ 步起一趟 = `CharacterOuting` 一行：头一行「出门调查 · B 站 · pixiv.net」+ 灰字「3 条见闻 · 12 点」（不是额度到顶收的工再加一句：你让她回来了 / 没找到新东西 / 半路出了问题），一条没带回也照样有一条；有这张表之前的见闻按天折。
- 没看过的见闻 / 观点 / 那次出门前面一颗 `highlight` 6px 小点；滚进视口看过就消。
- 撤回改动：左栏对应那一格同时换回旧值。
- 删除见闻 / 观点走 `ConfirmDialog`（宽 340）：「删除这条见闻？」+「删了她就不记得了。」/「删掉这个观点？」+「她以后聊天不会再这么说。」。拉黑表情不确认，再点恢复（变淡 + 斜线圈）；删除表情在「更多」里、走同一个确认弹窗。
- 河底一行灰字说保留多少（日记最近 100 篇、改动最近 200 条，照 `CharacterJournal` / `CharacterCardRevision` 的上限）；往下滚接着取。

## 5. 状态

| 状态             | 页面                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------- |
| 出门关（默认）   | 河顶空态卡（`EmptyState`）：「她还没出过门」+ 一句说明，⛔ 按钮；日记 / 改动照常在河里 |
| 开了、还没出去过 | 出门卡写「明早 9 点第一次出门」，河里只有日记 / 改动                                   |
| 今天出去过       | 默认展开今天那次，新东西带小点                                                         |
| 暂停（7 天没聊） | 开关仍开，状态行写暂停原因                                                             |
| 某站缺 key       | 那站小签变淡，点了就地配 key                                                           |
| 出不了门         | 型号那一行下面写原因（没选 / 下架 / key 没了）+「换一个型号」                          |
| 某站失败         | 那次出门里一行失败 + 重试                                                              |
| 河整个是空的     | 没出过门也没日记 / 改动：只留空态卡                                                    |
| 加载             | 两栏各自静止骨架 → `load-reveal`；河的骨架 = 一个日期 + 两条事件的高度                 |
| 出错             | 河的位置换成 `EmptyState` 出错那一档 +「重试」；左栏照常能改                           |

## 6. 动效

| 交互                   | 怎么动                                                                  | 配方                                 |
| ---------------------- | ----------------------------------------------------------------------- | ------------------------------------ |
| 书架 → 她的页          | 点中的封面长成左栏立绘；河从下往上进场（前 12 条错开）                  | `spring-expand` · stagger .03        |
| 折 / 展一次出门        | 内容全高排版、高度跟同一根弹簧，箭头转 90°；下面事件同一根弹簧让位      | `spring-expand`                      |
| 左栏一行展开 / 收起    | 那一行撑成输入框，下面让位；收起反向                                    | `spring-expand`                      |
| 筛选                   | 白格两边弹簧滑过；被筛掉的缩 0.98 淡出、留下的补上                      | `liquid-segmented` · `duration-fast` |
| 出门开关               | 圆钮滑过；来源一排淡入                                                  | `spring-slot` · `duration-base`      |
| 删除                   | 弹窗从「删除」键长到正中（`growFromPointer`）；确认后那条淡出，下面补上 | `duration-fast`                      |
| 撤回 / 改观点 / 换造型 | 换内容一糊                                                              | `BlurSwap`                           |
| 她刚回来（页开着）     | 河顶插入新的一次出门，由糊变清，下面整体下移                            | `load-reveal`                        |
| 手机长按               | 按住 0.98，抽屉推上                                                     | `duration-fast` · vaul               |

同一时刻只动一样；减少动效时全部直接到位。

## 7. 书架总览

不改骨架。唯一改动：有没看过的见闻 / 观点 / 表情的角色，封面右上角一颗 `highlight` 小点（ui-spec §3.1「有新结果的小点」）。

## 8. 别处跟着改

- 设置 › 助手 › 她（`assistant-settings/AssistantHerPane.tsx`）：日记和改动搬走（owner 10-28），每个角色只留一行「在她的页里看 ›」，撤回只在角色页一处。
- 页面要后台给的数据（后台在主会话施工，接口名以落地为准）：出门设置（`browseEnabled` · `browseModel` · `browsePausedReason` · `browsedAt`，主会话已写、迁移待 owner 授权）；出门记录（时间、去了哪几站、哪站失败及原因、扣没扣额度、下次时间、暂停原因）；见闻（正文、站名、链接、看过没有、属于哪次出门）；观点（文字、属于哪次出门，聊天里长出的不挂）；表情包（图地址、拉黑标记、属于哪次出门）。

## 9. 本页不能长得像

- 不像 LoRA / 素材库：⛔ 格子墙、⛔ 库骨架左栏。角色页是一个人，不是一堆资产。
- 不像设置页：设定 ⛔ 表单分组卡、⛔ 一屏输入框；平时只是字，点了才变框。
- 不像对话：河里是她做过的事，⛔ 气泡、⛔ 输入框。

三个标志性组件：**出门卡**（开关 + 状态一行 + 来源小签 + 出门用的型号）、**可折的出门事件**、**原地展开的设定行**。

## 10. 施工切片（每片可单独验证）

1. 两栏骨架 + 左栏（立绘 · 造型 · 图 · 声音 / LoRA · 设定行原地展开），右栏先只放日记 + 改动（数据已有）；设置里的「她」改成跳转。
2. 出门卡（开关 · 状态 · 来源 · 出门用的型号与「出不了门」· 缺 key 就地配）。
3. 出门事件：见闻 / 观点 / 表情包挂进河，折叠、小点、删 / 改 / 拉黑。
4. 筛选条、加载 / 出错 / 空态、动效补齐。
5. 平板、手机。

现有代码对应：详情宿主 `cards/CharacterRoster.tsx`；头 / 正文 / 设定 `cards/CharacterDetail.tsx`（`CharacterDetailHeader` · `CharacterDetailBody` · `CharacterSettingModule` · `SettingTavernGroups`）；造型 `cards/CharacterLookStrip.tsx`；电脑 / 平板详情外壳 `cards/CharacterDetailDesk.tsx`（左栏 + 页签）；总览「最近」卡 `cards/CharacterRecentCards.tsx`；手机顶栏 `cards/CharacterPhoneBar.tsx`。组件 ⛔ 自造：开关 / 切换条 / 删除确认 / 空态 / 查看器 / 抽屉照 ui-spec §9。
