# 角色大项目：设计与分步

施工单 `p-character-redesign`。2026-10-29 owner 逐项定稿。看样子以可点样件为准：<https://claude.ai/artifact/QRhLcqAzUpnBicYAXrLdjE>（设计画布 v4，owner「就这样」）；方案稿 <https://claude.ai/artifact/DHYiacSBZCYQA91rPHoyHe>（循环图与每块改法）。样件是探索稿，代码长相仍照 `references/ui-spec.md`。

## 主旨

角色是**会自己迭代的 agent**：自己出门调查感兴趣的东西，记住看到的，说话按调查结果慢慢变，不靠固定语气模板。角色页只负责**配置她**（⛔ 放到画布等「用她」的动作）。先做电脑端，平板与电脑同一套；手机归 `d-mobile-redesign`。

## 已定

**骨架**

- 助手和工作台对齐放左：对话收起后，页左上只剩一颗头像。点头像，助手从头像展开；缺东西时头像上有一个小点。
- 不做角色列表。详情页左上「← 角色」回总览。
- 总览（O4）：顶上是「角色」、搜索、导入酒馆卡，以及黑色「新角色」。往下依次是：
  - 「最近」三张卡（谁在做什么）
  - 作品切换条（全部 · 原创 · 各作品 + 张数）
  - 作品扇形卡
  - 全部角色格（一行最多 8 张，3:4）
  - 切到某个作品时只留这个作品的角色格。⛔ 去掉「用得最多」。
- 详情左栏只放这些：一个头像、名字（旁边 ⋯ 里是「删除角色」）、一句介绍、「和她聊」（这块板唯一的黑钮，= 换成她）、「她在意的东西」、「现在」卡。⛔ 分割线；⛔「用她」键，和「和她聊」是同一件事。
- 右边六个页签：最近 · 人物 · 图片 · LoRA · 记忆 · 表情包。⛔「出门」页签。

**各页**

- **最近**：按天排日记，日记是主角，用户能「编辑 · 删除」。每天下面挂几条小条：
  - 调查：点开看来源和记下的话
  - 改了自己：带「撤回」
  - 有了观点
  - 收了表情
- **人物**：分人物 / 对话 / 酒馆三组，每组套一个灰框（owner 10-29）。每格都有「钉住」和「编辑」，钉住的格子她改不了。
  - 声音放在人物组里。
  - 世界书放在酒馆组里，现在已经生效，「只保存不生效」的文案要改掉。
  - 酒馆卡的系统提示和后置指令只在聊天里生效，⛔ 进工作台。
- **图片**（方案 B）：
  - 顶上是造型切换条，旁边 ＋ 和 ⋯（设为默认 · 删除造型）。
  - 「一句外观 + 标签」套灰框。
  - 「卡上的图」：主图 + 设成主图 / 移除 + 虚线加图。
  - 「用她出过的」：挑好的图「设成卡上的图」。
  - ⛔「找立绘」空状态（owner 10-30）：没图只留虚线加图，自己配或叫助手找。
  - ⛔「用她的图训练」，先放着，LoRA 训练那边还没好。
- **LoRA**：复用 LoRA 库的格子（封面 + 名字 + 底模 · 下载数）。第一格是虚线「添加 LoRA」，弹挑选框；悬停出「卸下」。⛔ 筛选、⛔ 训练入口。
- **记忆**：从设置挪到她页上。
  - 切换条：全部 · 记得的 · 见闻 · 观点；可以「记一条」，每条能改、能删，见闻只能删。
  - 加「有效期 / 沉睡」：
    - 带日子的计划，过期后不再注入。
    - 常被提到的记忆更难被挤掉。
    - 满 200 条时，挤出去的转进「沉睡」，单独一栏、可以唤回。
    - 钉住的永不过期。
    - 过没过期在注入时现算。
- **表情包**：
  - 显示「N / 上限」，可以「喂给她」，每张能「拉黑 / 恢复 · 删除」。
  - 她逛来的直接收，⛔「待收」一栏。
  - 入库要去重，同图或相似图只留一张。

**出门调查**

- 每次手动点一次去一次，⛔ 每天自动出门。随之舍弃的有：定时任务、开关、7 天聊过才去、隔 20 小时、每人每天 3 个角色这几条规则。
- 弹框：
  - 模型：记住上次用的，模型下面挂小签，写它能看文字 / 图 / 视频 / 声音。
  - 来源：「自动」+ 她常去的站 + ＋添加网址。⛔ AnySearch。
  - 额度（点）：10 · 30 · 60 · 自定。
  - 开始。
- 「现在」卡：
  - 没出门时：「上次调查：…」+「出门调查」。
  - 调查中：在看什么 + 用了几点 / 共几点 + 进度条 +「结束」。
- 计费：点数按真实 token 用量折算，1 点 ≈ 1 万 token，跟用哪个模型无关。出门的用量记进用量表。
- 多模态：
  - 视频和声音只有 Gemini 能直接看、直接听。
  - 别的模型看视频：取关键帧 + 字幕。
  - 别的模型听声音：先用 Fish / OpenAI 转成文字。
  - 这些费用都从本次额度里扣。

**角色页上的助手**

- 只在缺东西时冒出对应的按钮，补完就消失：补全设定、整理导入的卡、找立绘、帮她想兴趣。
- 助手的回复用卡片：每条「采用 / 不要」，多条时可以「全部采用」。

**不做**：主动找你聊天、群聊、每天自动出门、放到画布、LoRA 训练（先放着）。
