## 1. 页面职责

Generate 把已选的 LoRA、底模、来源证据、参考图、提示词和真实生成参数组织成一次可检查、可迭代的出图。唯一主工作流：

**装配 → 写一句 → 出图 → 看结果、再改**

来源配方与助手是按需辅助：只能改写或解释装配与输入里的真实内容，不另起第二套生成骨架。发现与收藏归「库 / 收藏」，训练归「训练」，长期资产归素材库。

## 2. 桌面结构

与图片台同一副外壳：灰底地台上，**顶上一行 → 舞台白卡 → 输入框白卡**，自上而下。

1. **顶上一行**：「LoRA 工作台」+ 生成 / 库 / 收藏 / 训练 四格液态分段（与图片台写法切换同一颗 `LiquidSegmented`，同一个位置）。右端留给助手头像（头像由助手外壳画，这一行只让位）。行高与行距同图片台，助手面板按它们对齐舞台顶边。
2. **舞台**：左边一列装配（§2.1），右边自上而下 来源图带（§2.2）→ 结果（§2.3）。
3. **输入框**：搭配状态条 → 参考图 → 提示词 → 没写进去的触发词 → 负面词 → 工具行（§2.4）。

库 / 收藏与生成台**共用这一张舞台卡**：切过去时装配列收成竖条、输入框收起、库占满舞台右侧，生成台不卸载（见 `lora-library.md` §2）。训练仍是一整张白卡。

### 2.1 装配列

- 宽 272，右上一颗收起键；收起 = **48px 竖条**：展开键 · 底模小封面 · 挂了几个 · 每个挂载一张小封面（停用的变淡）。点竖条上任何一处都回到整列（在库 / 收藏里是整列浮在库上面，见 `lora-library.md` §2）。
- 自上而下：**底模 → LoRA 行 → ＋ 添加 LoRA → 常与它同挂 → Runner 次数**。触发词写在输入框的正文里、参考图挂在输入框上（owner 09-28），⛔ 不回到这一列。
- **底模卡**：封面 + 名字 + 「家族 · 通道」一行，右端换底模键；点整张卡开换底模弹层。缺可用 key 时卡下一颗琥珀「需要 API key」，点它走 `QuickSetupDialog`。
- **换底模弹层**（2026-09-28，进度表 45 ④ 画板）：SDXL 系 / DiT 系两组卡，每卡 = 封面 + 名字 + 家族一行 + 「推荐」与「快出」（只步数蒸馏档，CFG 1 · 少步数）+ 选中勾。没挂 LoRA：列纯底模能出图的那些（⛔ 不列「来源图底模（自动）」，它靠来源图配方才有意义），默认 **Anima Turbo v1.1**、「推荐」落在它身上，没有「只看兼容的」开关；挂了 LoRA：默认只看兼容的、推荐按家族，关掉开关看全部、装不上的写「和当前挂载装不上」。开关与 ✕ 分开排。手机走底部抽屉、卡片一列、选中那组在前。⛔ 云端档、「忠实 / 快」的说法与页脚那句（09-17 托管通道退役，界面不暗示有另一条更快的通道）。
- **LoRA 行**：封面 · 名字 · 兼容点 · 权重数 · 启停开关，下面一条权重滑杆（底模不给权重值域时只写 `×1.00`）。
  - 停用 = 这一行变淡，它的触发词同一拍从正文里拿掉（§2.4）；⛔ 不把这一行挪走。
  - 卸下与排序是次要动作：悬停（或键盘聚焦到这一行）才出现右上 ×；**按住封面拖**换顺序。第一行是主 LoRA —— 还原、来源图默认分组都取它。
  - **装不上**（跨家族）：整行琥珀浅底 + 琥珀点 + 行内一句「{家族} · 和底模装不上，出图时不生效」；⛔ 不弹窗、不拦出图。
- **＋ 添加 LoRA**：整宽虚线键，切到「库」（库 B 定案：⛔ 另开库弹窗；旧的库弹窗 2026-09-28 删掉）。
- **常与它同挂**：一行小标题「常与它同挂」+ 一排小 chip（已挂的打 ✓、补挂失败的可重试、其余点「＋」补挂），多了收成「+N」；数据不足整块不出现。
- **Runner 次数**：列底一行等宽小字「Runner 剩 N/M 次（全站共享）」；总闸关 / 用完换琥珀那句。只 Runner 底模有。
- 列内容超高时列自己滚，⛔ 不把舞台顶出一屏。

### 2.2 来源图带

- 只在挂了 LoRA 时出现。
- **还没出过图 = 展开**：标题「这套 LoRA 出过的图」+ 按挂载分组 +「N 张」+「点一张看完整配方 · 做同款」+ 一排大缩略图。
  - **分组**：每把一颗浅色 chip，**封面在前**、名字截断（悬停看全名）；选中那颗浅底 + 细描边，⛔ 近黑实底（那一档留给页头的分段）。张数写在组外，⛔ 跟在被截断的名字后面。
- **出过图 = 收成一行**「「{名}」出过的图 N ›」（带三张小图）；点它长回整条，整条右上多一颗「收起」。
- 点一张 → 舞台里开样例大图（§5）。Hugging Face 挂载换成它的样例图 + 提示词；只有示例图没有配方时摆成纯预览（点开看大图），作者描述收成一行「作者描述 … 展开 · 复制全部」，⛔ 整段 markdown 铺在带子里；都没有写一句「没有公开样例」。

### 2.3 结果

- 图按舞台剩下的地方**等比放到最大**；点图看大图；右上一颗「问助手」（把这一张挂进助手输入区，不自动发送）。
- 「问助手」左边一颗同形的「存成模板」（owner 2026-09-28，契约见 [`prompts.md`](prompts.md)「LoRA 台上的「存成模板」」）：存这一张**出图那一刻**的整套（挂载 · 权重 · 底模 · 参数 · 提示词 · 负面），出图时就地记下，⛔ 读当前装配台；存好换成 ✓「已存成模板」，toast 带「去看看」。
- 从提示词页「使用」一个 LoRA 模板回到这里（`?template=<id>`）：挂载栈整个换成模板那几把、底模 · 参数 · 提示词 · 负面照存的装好，种子回到随机，⛔ 不出图；装一次就拿掉那个参数。模板打不开（已删）说一句，台上不动。标签台存的与提示词页新建的标签模板「用在 LoRA 台」只换提示词和负面：挂载 · 底模 · 参数不动，正文里原有的触发词留着；加过权重的标签按当前底模的写法落（`(tag:1.2)`，不认括号的底模去掉权重）。
- 生成照「加载态 A」：还没有旧图 = 一块素底框，框边就是进度线 + 百分比 + 阶段词 + 参数行，右上取消；有旧图（重出）= 旧图盖白纱 + 边线 + 百分比。出图：合拢 → 停一拍 → 线淡出。
- **失败就地说**：框里「没出图 · 原因」+「重试」，线停住变灰；已有旧图时旧图留着、那句话与重试排在图下。⛔ 不弹 toast、⛔ 不写进输入框。
- 图下一行：左「这一轮」缩略（本会话，刷新即清，点一张换主图）· 右等宽元信息（尺寸 · 采样 · 步数 · CFG · Seed，缺项省略）。
- 没出过图：舞台中间一句话（挂了 LoRA：「写一句提示词，出图后结果在这里」；没挂：「可以直接用底模出图，也可以去「库」挂 LoRA」）。
- Runner 线路生成中给一句耗时预估；本会话第一次换成「先加载底模」那句。

### 2.4 输入框

- **搭配状态条**（做同款 / 助手改过、或有装不上的 LoRA 时才有）：「● 搭配 已应用来源配方」；有装不上的多一段「· 1 个 LoRA 和底模装不上，这次不生效 · 换底模」；末尾「查看 / 收起」。点「查看」在状态条下**原位展开**：做同款带来的改动、助手改的，各一行，能撤销的带「撤销」；做同款待审阅时多一颗「应用」。⛔ 触发词不在这条上报（它就在正文里）。
- **参考图**（只在底模吃参考图时）：挂了才在提示词上方出一排缩略（与图片台同一排：点开看大图、悬停出 ×）。三条来路落到同一份：工具行「参考图」、粘贴进提示词、拖进输入框（拖着时输入框描一圈）。
- **提示词**：15/24 的正文，封顶 4 行后内部滚动；标签补全照旧。**触发词就写在正文里**（owner 09-28「直接放到提示词框」），在正文里高亮；⛔ 出图时不再往正文前面另拼一遍——看不见的那一份会让人自己再写一次。
  - 挂上作者认过触发词的 LoRA（自训 / 精选 / Civitai `trainedWords`）→ 触发词写到正文开头；停用 / 卸下 → 从正文里拿掉；停用再启用照原样写回。别的时候正文完全归你：删掉的触发词不会被写回来。
  - 做同款 / 还原 / 助手整段改写正文时，原来在正文里的触发词留着（缺了补回开头）；同一个词的不同写法（`\(` 转义、下划线、`(词:1.2)`）认作同一个，⛔ 不写第二遍。
- **没写进去的触发词**：生效中、但正文里没有的（猜出来的挂上时不自动写，或被你删掉的），在提示词下面一小行「触发词 ＋词」，点一下写到正文开头；写进去这一行就收起。
- **工具行**：左「参考图」「还原」「负面」；右「比例」「参数」、出图圆键。
  - **参考图**：写「参考图 N」；弹层里 已挂几张 / 上限 + 参考强度（有能用的参考图才出现）+ 上传 / 最近素材 / 素材库，挂满了说为什么。
  - **还原**：用这个 LoRA 推荐的提示词、负面词和权重；没挂 LoRA 时虚线、点不动，悬停说为什么。
  - **负面**：点它在提示词下原位展开一行负面词；写了内容就一直在。底模 CFG 恰好是 1（Anima Turbo 一类；或参数里把 CFG 调成 1）时负面词不起作用：chip 虚线、灰字、点不动，悬停（手机点一下，2 秒自己收）说「这个底模 CFG 1，负面词不起作用；写的内容留着，换回来还在」；那一行收起、内容留着，出图不带它；CFG 调到 1 以上或换回普通底模，原样展开回来。判据只有一个：`isRunnerNegativePromptInert`（`constants/runner-checkpoints.ts`），助手的 CFG 1 方言用同一个。
  - **比例**：写当前比例；弹层里选比例，Runner 底模再多一格精确宽高。本域一次出一张，⛔ 不画张数。
  - **参数**（只 Runner 底模有）：写「采样器 · N 步」（CFG 改过再跟一段「CFG N」），都没改过时写「默认参数」—— 底模清单自带默认的（Anima Base / Turbo）写它的默认，如「euler · 10 步」，滑杆也从它起；弹层里 采样器 · 调度器 · 步数 · CFG · Seed（固定 / 随机）· 放大，末行「留空 = 底模默认」。参数不合法时弹层里就地说、出图键点不动。
  - 三颗弹层都**从 chip 长出来、关上缩回 chip**，与图片台工具行同一套。
  - **出图**：36px 圆键；生成中变停止键（外圈走进度），点一下取消这一轮。缺 key 仍可点，点了走 `QuickSetupDialog`。

### 2.5 助手

- 打开 = **工作台让位**：地台右内边距与面板同一根弹簧；装配列宽度不变，只有结果区与输入框变窄，结果图等比缩小。收起反过来。⛔ 不盖住输入框、⛔ 不收起装配列。
- 头像留在顶上一行右端当开关（点开、再点或 Esc 收回）；点舞台与输入框不收。
- 助手搭好一套（新挂 / 卸下 / 权重 / 参数）或给权重、参数建议时出一张**搭配卡**「应用这套搭配」（owner 09-28「一张卡全包」，契约见 `lora-assistant.md` §12）：点了左列对应滑杆与数字走到新值，这一轮过程行上的「撤销」一次撤回；⛔ 不直接出图。⚠ 画板里「搭配条同一拍记一条可撤销」不做 —— 撤回只留过程行上那一个入口（owner 09-24）。

## 4. 动效

曲线一律 `--ease-standard`；颜色、数字、滑块线性或跟手；时长只取 120 / 200 / 240 / 320，让位那根弹簧与图片台同一根。每一个「开」都有对应的「关」，关也要真的演。

| 动作                  | 怎么动                                                                          | ⛔ 不做                  |
| --------------------- | ------------------------------------------------------------------------------- | ------------------------ |
| 换页（四格）          | 分段选中块两条边各一根弹簧；内容淡入                                            | 不整页左右滑             |
| 挂上 / 卸下一个 LoRA  | 新行高度 0 → 一行、内容淡入；卸下先淡出再收拢                                   | 不跳位、不留空行         |
| 停用 / 启用           | 开关 120 线性；行变淡与正文里的触发词拿掉 / 写回同一拍                          | 不挪走这一行             |
| 装配列收起 / 展开     | 同一个容器 272 ↔ 48（560），两块内容交叉淡；结果图按新宽度等比放大 / 缩小       | 列不压在结果上           |
| 来源图收起 / 展开     | 同一个容器换高度（320），两样交叉淡；结果图同一拍变高 / 变矮                    | 来源图不直接消失         |
| 搭配展开 / 收起       | 原位展开 200 淡入、输入框跟着长高；收起 120 淡出、200 收回                      | 不弹对话框、收起不直接跳 |
| 「触发词 ＋词」一行   | 与负面词同一套原位展开 / 收起；收起那一拍留着上一排字                           | 不直接跳                 |
| 样例大图开 / 关       | 从那张缩略图放大（320）；关上缩回那张（240），焦点回到它                        | 不从屏幕中间弹           |
| 比例 / 参数弹层       | 以 chip 为原点 0.72 → 1、由糊变清；关上缩回 chip                                | 不从屏幕中间弹           |
| 助手开 / 收           | 工作台让位与面板同一根弹簧；结果图等比缩放                                      | 不直接跳回               |
| 应用这套搭配          | 左列滑杆与数字 240 线性走到新值（拖滑杆时跟手）                                 | 不直接出图               |
| 换底模：点一张卡      | 勾与描边 120 线性淡入，弹层随即关                                               | 不先关弹层再换卡         |
| 「只看兼容的」开 / 关 | 离开的卡 120 淡出，剩下的 200 位移到新格子，进来的 200 淡入；弹层高度同一拍补间 | 不整块闪一下重排         |
| 负面 chip 让开 / 恢复 | 边框实线 ↔ 虚线、文字变灰，120 线性；那一行走负面词同一套原位收起 / 展开        | 不抖、不闪、不直接消失   |

减少动态效果：高度走位、放大、模糊一律换成 120 淡入淡出；滑块与数字照旧跟手；应用权重直接跳到新值。

## 5. 样例大图（生成台）

owner 09-28「这边是不是也一起优化」：生成台点来源图不再开居中弹窗，改成**在舞台右侧就地展开**（库 B 画板「样例大图」同一形）：

- 从那张缩略图放大出来，盖住来源图带与结果区；装配列与输入框不动。
- 左：大图等比放到最大（框 = 图的比例）+ 左右切换 + 底下一排缩略轨。右：340 宽的「这张的配方」—— 提示词 / 负面 / 底模 / 采样 / 尺寸，每格可复制；「这张还叠了」列出配方里别的 LoRA（已挂载 / 一起挂 / 不挂）；底部「做同款」+「用原图 seed」，再下一行「复制配方 · 打开来源」。
- 「做同款」只把真实可用的内容写回装配与输入并关掉大图，⛔ 不自动出图；已有输入时进搭配条的待审阅，⛔ 不静默覆盖。
- Esc / 关闭键退出、← → 换张；关上缩回那张缩略图，焦点回到它。
- 库的样例图仍走原来那个居中弹窗，随库 B 那一片再换。

## 6. 手机（<1024，2026-09-03 契约，本轮不动）

1. 顺序 = 结果卡 → 提示词输入条 → 来源证据；装配在输入条顶上一行摘要 chip，点开近全屏抽屉（整条装配 + Runner 参数）。
2. 生成**开始**时结果卡滚到视口顶，一轮一次，减少动态效果直跳。
